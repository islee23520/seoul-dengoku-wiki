# 거점과 영토 규칙

> 출처: docs/game-logic/Strongholds-and-Territory.md — 계약 수치는 구현 상수를 우선한다.

## 개요

역은 점령만으로 완성되는 깃발이 아니다.
사람·시설·연결을 다시 켜야 전략 거점으로 선다.
점유 뒤 안정화와 영토 통합은 4방향 시야와 연결이 맡는다.

## 핵심 수치

| 항목 | 값 | 범위 |
|---|---:|---:|
| 권위 `A` | 점령 직후 최대 45 | 0~100 |
| 협력 `L` | 강제 점령 기본값 20 | 0~100 |
| 시설 상태 `R` | — | 0~100 |
| 연결도 `K` | — | 0~1 |
| 부족도 `S` | — | 0~1 |
| 과확장 `O` | — | 0~2 |
| 일반 역 시설 슬롯 | 2 | 1~4 |
| 환승역 시설 슬롯 | 3 | 1~4 |
| 주요 사업 작업량 | 100 | 40~240 |
| 통합 권위 | 65 | 0~100 |
| 통합 협력 | 55 | 0~100 |
| 통합 시설 | 60 | 0~100 |
| 통합 유지 기간 | 3일 | 1~7일 |
| 안정화 진입 권위 | 50 | — |
| 안정화 진입 협력 | 35 | — |
| 통합 연결도 | 0.5 | — |
| 통합 부족도 상한 | 0.25 | — |
| 부족 판정 | 식량 또는 전력 75% 미만 | — |
| 압박 부채 기본값 | 0 | 0~100 |
| 압박 부채 사건 임계 | 100 | — |

## 조항

### RSTRONGHOLDS-01 거점의 성격

역은 점령 즉시 완성되는 깃발이 아니다.
사람·시설·연결을 다시 작동시켜야 전략 거점으로 선다.

### RSTRONGHOLDS-02 권위 A

권위 `A`의 범위는 0~100이다.
점령 직후 최댓값은 45로 고정한다.
순찰·협약 집행·적대 활동 억제에 권위를 쓴다.

### RSTRONGHOLDS-03 협력 L

협력 `L`의 범위는 0~100이다.
강제 점령의 기본값은 20으로 둔다.
노동·정보 제공·통치 수용은 협력에 따른다.

### RSTRONGHOLDS-04 시설 상태 R

시설 상태 `R`의 범위는 0~100이다.
지역 서비스와 노선 서비스가 이 값에 묶인다.

### RSTRONGHOLDS-05 연결도 K

연결도 `K`의 범위는 0~1이다.
식은 `K = clamp(max_path(min_edge_capacity), 0, 1)`을 따른다.
합법 보급 경로마다 가장 좁은 연결의 처리율을 구한 뒤 그중 가장 큰 값을 `K`로 쓴다.

### RSTRONGHOLDS-06 봉쇄 연결

봉쇄된 연결은 삭제하지 않는다.
`K=0`의 원인과 복구 조건을 보존한다.

### RSTRONGHOLDS-07 부족도 S

부족도 `S`의 범위는 0~1이다.
충족률은 수요가 0이면 1이고 아니면 `clamp(공급/수요, 0, 1)`을 쓴다.
`S`는 `1 - min(충족률(식량공급, 식량수요), 충족률(전력공급, 전력수요))`로 계산한다.

### RSTRONGHOLDS-08 0나누기 금지

수요가 0인 자원은 충족률 1로 둔다.
부족 기여는 0이며 어떤 경우에도 0으로 나누지 않는다.

### RSTRONGHOLDS-09 과확장 O

과확장 `O`의 범위는 0~2이다.
물류와 기반 시설의 공유 척도를 그대로 가져온다.
통치부담과 행정역량은 `부담비율(통치부담, 행정역량)` 항으로 들어간다.

### RSTRONGHOLDS-10 과확장 산식

통치부담 4.5와 행정역량 3이면 부담비율은 `4.5/3=1.5`이다.
물류·귀환 부담 비율이 그보다 작으면 `O=clamp(1.5-1,0,2)=0.5`가 된다.
과확장은 모든 거점의 안정화와 수송에 감점을 남긴다.

### RSTRONGHOLDS-11 시설 슬롯

일반 역 시설 슬롯의 기본값은 2다.
환승역 시설 슬롯의 기본값은 3이다.
둘 다 최솟값 1 최댓값 4를 지킨다.

### RSTRONGHOLDS-12 주요 사업 작업량

주요 사업 작업량의 기본값은 100이다.
최솟값 40 최댓값 240을 벗어나지 못한다.

### RSTRONGHOLDS-13 단계 사슬

점령지는 `분쟁 → 점령 → 안정화 → 통합`을 거친다.
전투·협상 결과가 분쟁에서 점령으로 넘긴다.

### RSTRONGHOLDS-14 안정화 진입

점령에서 안정화로 가려면 `A>=50`과 `L>=35`를 동시에 만족해야 한다.

### RSTRONGHOLDS-15 통합 조건

통합은 `A>=65` `L>=55` `R>=60` `K>=0.5` `S<=0.25`를 3일 연속 채워야 성립한다.
통합 권위 기본값은 65 협력 55 시설 60으로 둔다.
통합 유지 기간 기본값은 3일이고 범위는 1~7일이다.

### RSTRONGHOLDS-16 단계 후퇴

통합에서 부족·고립·과확장이 겹치면 안정화로 물러난다.
권위가 붕괴하면 안정화는 점령으로 떨어진다.
수비·통치를 잃으면 점령은 분쟁으로 되돌린다.

### RSTRONGHOLDS-17 부족 상태

식량 또는 전력이 75% 미만이면 부족 상태가 붙는다.
권위와 협력은 그때 하락한다.

### RSTRONGHOLDS-18 완전 고립

완전 고립이면 수입과 수출은 0이다.
현지 비축과 발전은 계속 작동한다.

### RSTRONGHOLDS-19 과확장의 원인

과확장은 영토 상한이 아니다.
담당자·주둔군·연결 부족에서 발생한다.

### RSTRONGHOLDS-20 동일일 정산 순서

같은 날 여러 거점이 임계치를 넘으면 안정된 거점 ID 순서로 정산한다.

### RSTRONGHOLDS-21 무전력 시설

무전력 시설만 있는 역은 전력 수요를 0으로 둔다.
전력 충족률은 1이라 부족도 `S`에 보태지 않는다.
전력 서비스 발생은 인정하지 않는다.

### RSTRONGHOLDS-22 압박 부채

압박 부채 `PressureDebt`의 기본값은 0이며 범위는 0~100이다.
권위·협력 저하와 가시성·적대 인접·과확장으로 쌓이고 주둔 커버와 연결도 `K`로 줄어든다.
부채가 100에 도달하면 원인에 맞는 사건을 하나 예약하고 부채 100을 뺀다.

### RSTRONGHOLDS-23 결정론

동일한 입력은 항상 같은 결과를 낸다.
현지 식량·발전·수리반이 남아 있으면 복구는 계속된다.

### RSTRONGHOLDS-24 부족도 예시

식량 40/100 전력 60/100이면 `S = 1 - min(0.4, 0.6) = 0.6`이 나온다.
합법 경로가 없으면 `K=0`을 쓴다.
세 조건이 겹친 역은 통합 조건을 만족할 수 없다.

## 판정 순서

1. 자원 배분을 수행한다. 충족률과 부족도 `S`·연결도 `K`를 이 단계에서 확정한다.
2. 전투 결과를 반영한다.
3. 권위·협력·시설을 갱신한다.
4. 단계 전이를 적용한다. 같은 날 여러 거점이 임계를 넘으면 안정된 거점 ID 순서로 정산한다.
5. 사건을 예약한다. 압박 부채가 100이면 원인에 맞는 사건 하나를 넣고 부채 100을 뺀다.

## 금지 사항

- 점령 즉시 완성된 깃발로 역을 취급하지 말 것
- 봉쇄된 연결을 삭제하지 말 것
- 수요 0에서 0으로 나누지 말 것
- 과확장을 영토 상한으로 쓰지 말 것
- 무전력 시설만 있는 역에 전력 서비스가 생긴 것으로 보지 말 것
- 동일 입력에 다른 결과를 내지 말 것
- 통합 조건 미달 거점을 통합으로 유지하지 말 것
- 설계 가정 수치를 구현 상수보다 앞세우지 말 것
