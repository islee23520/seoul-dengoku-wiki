# 레퍼런스 게임 조사 — 무엇을 누구에게서 빌렸나

이 게임의 설계는 실존하는 15개 이상의 전략·전술 RPG를 역분해한 결과 위에 서 있다. 2026-09-07 소유자 결정으로 목표 형태가 **4X + RPG, 실시간 진형·카드 전투**로 재규정됐다. 이에 따라 Songs of Silence가 목표 형태의 기준 레퍼런스로, 라벨렌 전기가 턴제 SRPG 쪽의 마지막 정밀 참조로 추가됐다. 이 페이지가 정리하는 것은 두 가지다. 각 레퍼런스에서 어떤 요소를 차용했고 그것이 어떤 시스템으로 조합되었는지, 그리고 의도적으로 가져오지 않은 것이 무엇인지다. 상세 조사 원문은 저장소 내부 `docs/game-logic/reference/` 디렉터리(16종·출처 514개 이상)에 영구 보관되어 있으며, 각 항목은 `[REF:게임-메커니즘]` 형식으로 추적할 수 있다.

> 이 페이지의 잔선 적용은 설계 방향과 구현 제안이다. 여섯 프리셋, 16국 전략 지도,
> 포획·영입, 지속 부상 등이 현재 런타임에 모두 구현되었다는 뜻이 아니다.
> 현재 완료 상태는 개발 로드맵과 저장소 ToDo.md를 확인한다.

## 차용 원칙

1. 모든 차용은 원문 출처와 함께 기록한다 — 추측으로 채우지 않는다.
2. 여러 게임이 같은 문제에 다른 해법을 제시하면 선택지로 병기하고 잔선의 선택 이유를 명시한다.
3. 가져오지 않은 것도 명시한다 — 부정확한 연상을 막는다.

## 일곱 차원 종합

교차 종합 보고서(CROSS-GAME-SYNTHESIS.md, 내부)가 각 차원에서 최고 모델을 선정한 결과:

| 차원 | 최고 모델 | 잔선 권고 |
|---|---|---|
| 무에서 시작 | K-시스템 | 결핍의 종류를 축으로 시작 설계 — 밴드 3인 + 손수레 + 3일 식량 |
| 경제 압박 루프 | 배틀 브라더즈 | 확정한 이동·휴식만 시간 진행 — 식량 + 수당 + 회복의 3중 압박 |
| 사망·부상 처리 | 배틀 브라더즈 + K-시스템 | 회복 가능한 실패 — 쓰러짐 ≠ 사망, 부상은 정산 영수증에 표시 |
| 전략↔전술 연결 | 배틀 브라더즈 / FFT | 세 지도를 다른 질문·시간·통제권으로 분리 |
| 세계 진화 | K-시스템 + 배틀 브라더즈 | 핵심 인물 상태 전이 + 지역 상황 변화의 두 속도 |
| 난이도 철학 | 트라이앵글 + FE | 무레벨스케일링 + 실패 시 진척 보존 병용 |
| 포획·모집 | K-시스템 + 배틀 브라더즈 | 구조→신뢰→가입의 관계 기반 — 즉시 구매 없음 |

## 세 표면 구조

장르 조사가 확정한 핵심: 지도는 크기가 아니라 플레이어의 동사로 구별한다.

| 표면 | 질문 | 형태 | 차용 |
|---|---|---|---|
| **S 전략 노선도** | 누가 어디를 지배하며 무엇을 우선할 것인가? | 서울 전체 → 16국 세력권 · 2D 평면 도식 | CK3 정보 모드, 신장·삼국지 영토 |
| **W 역간 여행** | 일행은 어디로, 어떤 대가로 갈 것인가? | 현재역→목적역 · 경로·보급·사건 | FFT 이동일, 배틀 브라더즈 지속 비용 |
| **B 전투 하이트맵** | 지금 누가 어느 칸에서 무엇을 할 것인가? | 역 내부 B1/B2 · 사각 칸 · 고저차 | FE·FFT 전술, BB 지형, ITB 위협 표시 |
| N 비지도 관리면 | 누구를 준비시키고 무엇을 정산할 것인가? | 인터미션·조우·배치·정산 | 창세기전 인터미션, CK3 이벤트 |

## 시작 프리셋

결핍의 종류가 난이도를 만든다 — 숫자 조정이 아니라 "무엇이 없는가"가 다르다. 자세한 수치는 `Starting-Presets.md` 참조.

| 프리셋 | 난이도 | 핵심 결핍 | 장기 규칙 |
|---|---|---|---|
| 떠돌이 삼인조 | ★★ | 거점·보급 | 없음 (표준) |
| 전직 자치 순찰대 | ★ | 관계 (배신자 취급) | 신도림 자치회 회복이 첫 관문 |
| 상인 잔존자 | ★★ | 전투력 | 교역 이윤 +20% / 전투원 비용 +50% |
| 탈영 소대 | ★★★★ | 광역 적대 | 추격자 주기 스폰 |
| 고아 무리 | ★★★★★ | 모든 것 | 성장 ×2 / 사기 타격 ×2 / 보상 −30% |
| 마지막 역장 | ★★ | 역 책임 | 영등포 부분 통제 · 상실 시 망명 (게임오버 아님) |

## 의도적으로 가져오지 않은 것

- CK3식 전투 추상화·봉건 계승 — 격자 위의 실시간 진형 전투가 이 게임의 계약이므로
- FE·FFT·라벨렌의 턴·페이즈·되감기·유닛 단위 명령 — 2026-09-07부로 전투는 실시간 진형·카드이므로(예측 표시·무소모 취소의 투명성 원칙은 진형 편집과 카드 예측로 이어간다)
- Songs of Silence의 카드 랜덤 드로우·카드 부활 경제 — 투명성과 부상 이행 계약과 충돌하므로
- 배틀 브라더즈의 육각 격자·9AP·대규모 용병단 수치 — 사각 3AP·소수 파티 유지
- K-시스템의 초반 반복 노동 — 흥미 곡선 보호
- FE식 자동 원상복구 — 부상 이행이 계약이므로
- 전면 시뮬레이션형 4X — 4X 골격(탐사·확장·개발·정복)은 채택하되, 제한된 상태 전이로 인과를 읽을 수 있게 유지(Songs of Silence식 경량 4X에 가까움)

## 포획과 영입

전투에서 적 대표를 생포하면 심문·인도·고용 협상 중 선택한다. 모집은 세 경로로 분리된다: 구조→신뢰→가입(핵심 동료) / 계약 인력(유료·기간제) / 역 내 인력 시장. 즉시 돈으로 사는 핵심 동료는 없다 — 관계가 게이트다.
