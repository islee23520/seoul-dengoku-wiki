# 시나리오 타임라인

## 연대기의 원칙

이 타임라인은 정해진 역사를 재생하는 각본이 아닙니다. 사건은 조건을 만들고, 결론은 살아 있는 인물의 야망, 공포, 관계, 기억과 직위에 따라 달라집니다. 핵심 인물이 죽거나 포획되거나 설득되면 같은 사건도 다른 행위자가 다른 결과로 이끕니다.

정본은 아래 **상대 시각 제목**과 사건 순서를 유지합니다. 서기 연도는 정본이 아닙니다.

## 달력 제안 (CALENDAR PROPOSAL)

이 절은 **달력 제안**입니다. 역사 사실이 아니고, 소유자 승인으로 잠긴 정본도 아닙니다. 채택하려면 인물 전기·출생연·연령과 서기 연도를 먼저 맞춰야 합니다. 맞추기 전에는 개막 나이를 정본처럼 쓰지 않습니다.

제안 앵커: 기준 열람 2026, 붕괴 0년 대정전 **2036** (기준 +10), 캠페인 개막일 **2146** (붕괴 +110).

| 상대 시각 (제목 유지) | 제안 서기 | 비고 |
|---|---|---|
| 붕괴 5년 전: 연결된 도시 | 2031 | 붕괴 −5 |
| 붕괴 0년: 대정전과 단절 | 2036 | 붕괴 0 |
| 붕괴 1년: 첫 급수협약 | 2037 | +1 |
| 붕괴 2년: 군사호적 논쟁 | 2038 | +2 |
| 붕괴 3년: 열여섯 깃발 | 2039 | +3 |
| 붕괴 4년: 공신의 겨울 | 2040 | +4 |
| 붕괴 5년: 둘째 급수협약 | 2041 | +5. 건국기 끝 |
| 공백의 세기 | 2042–2145 | 붕괴 +6부터 +109. 사건 제목 없음. 장부·구술만 남음 |
| 개막일: 세 번째 급수계약 | 2146 | 붕괴 +110. 건국기 **다음 세기**. 제목은 「붕괴 6년」이 아님 |

이전 판은 개막을 붕괴 +6(2042)에 두어, 성인 생존자가 현대 사회를 기억하는 구도였다. 이 판은 붕괴 이후 **한 세기 이상**이 지난 개막을 쓴다. 개막 세대는 대정전을 살지 않았고, 2026 과학은 장부·공방 전승으로 남는다.

지정 레퍼런스 《일본삼국》의 小学館 소개는 「문명 붕괴 후 근미래」만 적는다 ([小学館 도서](https://shogakukan-comic.jp/book?isbn=9784098510306), 열람 2026-09-14). 작품 고유명·연표 문장·지도는 잔선에 옮기지 않는다. [AU 고지](Unofficial-Fan-AU-Notice.md). 세기 간격은 잔선 소유자의 독서 확인과 기존 건국기 연혁을 맞추기 위한 창작 앵커다.

첫해 사계절과 둘째 해 패권전은 개막 이후 캠페인 시간입니다. 서기 숫자를 제목에 넣지 않습니다.

기술·법령 출발점은 2026입니다. [이 시대의 기술과 무구](Era-Arms-and-Tech-Level.md). 총수 일가·구 정부·외부 전구·변혁 가문은 [재벌 가문과 세기의 세력](Chaebol-Houses-and-Century-Factions.md).

## 붕괴 이전

### 붕괴 5년 전: 연결된 도시

- 행위자: 총수 일가가 지배하는 기업집단의 계열 실무, 중앙 행정·징집 명부, 주둔·교역의 외부 창구, 기록관과 배차 담당
- 조건: 정상적인 도시 행정과 기반시설. 총수 일가는 적은 지분으로 계열을 지배한다.
- 행동: 물, 철도, 시장, 의료, 통신, 냉각·열원·방호 면허를 기관과 일가 장부가 함께 운영한다.
- 즉시 결과: 훗날 국가를 만드는 전문 인맥과, 가문이 쥐는 키·원장이 쌓인다.
- 분기: 누구와 함께 일했고 누구의 실수를 덮었는지가 붕괴 뒤 비상위원회와 일가 면허의 비밀이 된다.
- 후속 사건: 대정전

### 붕괴 0년: 대정전과 단절

- 행위자: 여의도 정수, 뚝섬 공방, 암사 경비, 기록 전신의 비상 책임자들
- 조건: 광역 전력과 통신의 연쇄 중단
- 행동: 정수·배급·철도·기록 책임자들이 자기 관할을 살리기 위해 비상권한을 행사한다.
- 즉시 결과: 공동 지휘망이 끊기고 생활권별 비상위원회가 생긴다.
- 분기: 비상권한을 언제 반환했는지에 따라 각 국가의 법통, 개발, 군사 정통성이 달라진다.
- 후속 사건: 첫 급수협약

## 건국기

아래 고유명(한재목, 임하준, 배우진, 윤서린, 강민서, 백온)은 **개막 세대**다. 건국기의 행위는 직위와 전신 조직이 한다. 가문 장부가 창건자로 적는 이름과 개막에 살아 있는 사람을 같은 몸으로 읽지 않는다.

### 붕괴 1년: 첫 급수협약

- 행위자: 여의도 정수 책임자, 뚝섬 펌프 총괄, 초기 상수 기술자들
- 조건: 남은 정수 기능과 펌프 부품이 서로 다른 권역에 분산
- 행동: 물과 부품을 교환하는 임시 협약을 맺는다.
- 즉시 결과: 여의신정, 뚝섬, 암사가 급수 강국으로 성장한다.
- 분기: 협약을 공공권리로 본 인물과 보호계약으로 본 인물이 갈라진다.
- 후속 사건: 군사호적 논쟁

### 붕괴 2년: 군사호적 논쟁

- 행위자: 암사 군사파, 북한산보국문 난민대표, 제기동 쪽 의무 대표
- 조건: 외곽 약탈과 복구 인력 부족
- 행동: 암사 군사파가 가족 단위 복무등록을 요구하고 북한산보국문 난민대표가 거부한다.
- 즉시 결과: 안정된 병력을 얻는 대신 가족 분리와 탈주가 늘어난다.
- 분기: 자발적 성인 복구복무와 시민권 계약이 성립하면 제기동·북한산보국문 선대의 연대가 생긴다. 강제등록이 유지되면 암사 선대의 장교망이 커진다.
- 후속 사건: 열여섯 깃발

### 붕괴 3년: 열여섯 깃발

- 행위자: 16개 권역의 초기 지도자
- 조건: 중앙 비상위원회의 최종 해산
- 행동: 각 권역이 독자 헌장과 직위를 선언한다.
- 즉시 결과: 총 16국, 강국 5·약소국 11. 이 깃발 배치가 공백의 세기를 지나 개막까지 이어진다.
- 분기: 서울역기록청의 인준을 받은 국가는 법통을 얻지만 기록청에 정치적 빚을 진다.
- 후속 사건: 공신의 겨울

### 붕괴 4년: 공신의 겨울

- 행위자: 각국 창건 공신, 경비대와 기록관
- 조건: 건국 직후 직위와 물자 보상
- 행동: 공신들이 관직, 배급권과 세습권을 요구한다.
- 즉시 결과: 일부 국가는 공동통치가 되고 일부는 창건자 친위국이 된다.
- 분기: 보상을 제한하면 쿠데타 위험, 과도하게 주면 관작과 배급권이 분산된다.
- 후속 사건: 둘째 급수협약

### 붕괴 5년: 둘째 급수협약

- 행위자: 여의도·뚝섬·암사·제기동의 당시 책임자들
- 조건: 첫 협약의 임시 펌프와 열차 부품이 수명을 다하고 강국별 급수 책임이 충돌
- 행동: 물 공급 최저선, 부품 규격, 비상 호송과 계약 종료 조건을 새로 정한다.
- 즉시 결과: 뚝섬 총괄이 중앙부 급수·부품 계약의 보증인이 되고 세 강국의 상호 의존이 제도화된다. 이 보증 문구가 개막의 세 번째 계약까지 장부에 남는다.
- 분기: 최소 급수권을 넣으면 약소국의 지지가 늘고, 보호조항을 강화하면 암사 선대의 군사 개입 근거가 커진다.
- 후속 사건: 공백의 세기

## 공백의 세기

건국기(붕괴 0–5년)와 개막일 사이에는 **한 세기 가까운 간격**이 있다. 이 기간의 사건 제목은 정본이 아니다. 생활권 깃발과 급수 장부는 이어지지만, 창건 공신의 얼굴과 현대 서울의 일상은 구술·사본·신화가 된다. 층별 매핑은 [재벌 가문과 세기의 세력](Chaebol-Houses-and-Century-Factions.md).

- 행위자: 총수 일가 장부를 물려받은 법인 후계, 도장을 필사하는 기록 길드, 관문·곡창·해협의 외부 당직, 수문·배차·의료를 세운 직능 가문
- 조건: 대정전을 산 사람이 거의 없고, 둘째 급수협약의 문구와 일가 면허만 남음
- 행동: 상호는 간판으로 남거나 헌장 이름으로 굳는다. 장부를 필사하고 부품 규격을 전승한다. 빠진 해를 새로 쓰지 않는다.
- 즉시 결과: 개막 세대는 십육국과 급수 계약, HC·HP 가문, XT 전구를 당연한 세계로 받는다. 창립 총수의 얼굴은 구술이다.
- 분기: 원본 장부를 열 세력은 창건기의 빚과 일가 면허를 캐내고, 사본만 가진 세력은 현재 헌장을 유일한 법으로 삼는다.
- 후속 사건: 세 번째 급수계약

## 캠페인 개막

### 개막일: 세 번째 급수계약

- 행위자: 임하준, 임초원, 한재목, 서이안, 배우진, 윤서린, 강민서, 백온, 남윤경. 이들은 개막 세대이며 대정전을 살지 않았다.
- 조건: 뚝섬공방연합 총관 임하준 실종, 건국기부터 이어 온 중앙 급수·부품 계약 동시 만료
- 행동: 강국들이 뚝섬의 후계와 새 계약에 개입한다.
- 즉시 결과: 물 가격 상승, 의료호송 지연, 약소국 중복계약과 장교 이동이 시작된다.
- 분기: 임하준 생존 확인, 임초원 즉위, 공방 공동통치, 암사 보호정부, 뚝섬 분열 중 하나로 진행될 수 있다.
- 후속 사건: 봄의 세 유언

## 첫해 사계절

### 봄: 세 유언

- 행위자: 윤서린, 문가람, 임초원, 공방대표 한소미
- 조건: 서로 다른 세 개의 임하준 유언장과 편집된 음성기록 발견
- 행동: 기록청이 인준 심사를 열고 송신공사가 원본 증거를 찾는다.
- 즉시 결과: 후계 후보별 지지 연합이 생긴다.
- 분기:
  - 윤서린이 진본을 확정하면 기록청의 인준권이 강화된다.
  - 문가람이 조작을 먼저 방송하면 폭동과 공개 재선거가 일어난다.
  - 플레이어가 증거를 숨기면 강국과 비밀 거래를 할 수 있지만 이후 폭로 위험이 남는다.
- 후속 사건: 여름의 탁수

### 여름: 탁수와 가짜 약

- 행위자: 서이안, 류은비, 한재목, 오해린
- 조건: 폭우 뒤 일부 수질 검사 실패와 가짜 약품 유통
- 행동: 연구평의회는 검사 공개를, 급수총재는 혼란 방지를 위한 지연을 주장한다.
- 즉시 결과: 물·의료 신뢰가 흔들리고 노량진 냉동재고가 위기에 빠진다.
- 분기:
  - 즉시 공개하면 단기 폭동과 장기 신뢰 회복.
  - 은폐하면 공급은 유지되지만 문가람의 폭로 사건이 열린다.
  - 공동 조사에 성공하면 제기동·마곡·상암의 비군사 동맹이 생긴다.
- 후속 사건: 가을의 북한산보국문 행렬

### 가을: 북한산보국문 행렬

- 행위자: 백온, 강민서, 배우진, 장세화
- 조건: 북부 식량 부족과 복무계약 만료
- 행동: 난민 가족들이 남하하고 암사는 급수권과 복무 재등록을 묶는다.
- 즉시 결과: 환승시와 제작동맹이 난민 수용 문제로 압박받는다.
- 분기:
  - 시민권과 자발복무 협약은 약소국 연대를 강화한다.
  - 강제등록은 암사의 병력을 늘리지만 탈주·반란·가족구출 사건을 연다.
  - 국경 폐쇄는 북한산보국문의 산악 공격과 겨울 기근을 부른다.
- 후속 사건: 겨울의 검은 배차표

### 겨울: 검은 배차표

- 행위자: 박태겸, 김도윤, 장세화, 배우진
- 조건: 의료열차에서 암사제 무기 발견, 북부 후계시험 부품 조작
- 행동: 약소국들은 공식 명령망과 비밀 장교망 중 누가 열차를 움직였는지 조사한다.
- 즉시 결과: 배우진의 쿠데타 준비 의혹과 박태겸의 양자 승계안이 동시에 떠오른다.
- 분기:
  - 배우진이 장교를 처벌하면 제한적 공동방위가 가능하다.
  - 사후 승인하면 동부 보호전쟁이 시작된다.
  - 무기가 조작된 증거가 나오면 제3의 인물이 전쟁을 유도한 사실이 드러난다.
- 후속 사건: 둘째 해 약소국 회의

## 둘째 해 패권전

### 봄: 열한 자리 회의

- 행위자: 정유라, 장세화, 류은비, 백온과 11개 약소국 대표
- 조건: 세 강국의 상충하는 급수·보호계약
- 행동: 약소국 공동교섭권과 상호호송조약을 논의한다.
- 즉시 결과: 강국5 대 약소국11의 구도가 강국5 대 약소국연합1로 바뀔 가능성이 생긴다.
- 분기: 공동헌장, 강국별 분할 복속, 내부 매수와 암살, 회의 결렬.
- 후속 사건: 수문전쟁 또는 서울 협약

### 여름 이후: 다섯 통일안

게임은 하나의 정복 결말을 강제하지 않습니다. 살아 있는 인물과 체결된 조약에 따라 다음 질서가 경쟁합니다.

1. 윤서린의 기록연방: 법통과 공개 원장을 중심으로 통합
2. 한재목의 수문동맹: 최소 급수권과 배급계약으로 통합
3. 강민서의 제작동맹: 수리규격과 노동 시민권으로 통합
4. 서이안의 공동기술원: 지식·의료·검증기관의 연합
5. 배우진의 상수보호권: 군사 지휘와 개발 실적으로 통합
6. 정유라의 다국가협약: 약소국 공동교섭과 제한된 중앙권력

각 통일안은 평화적 연방, 느슨한 동맹, 패권적 보호국, 군사 정복으로 변형될 수 있습니다.

## 지역 사건: 같은 장소, 다른 과거

계절 사건이 권역 전체의 연대기를 만든다면 지역 사건은 한 장소에 남은 과거가 돌아왔을 때의 계획을 바꾼다. 연대기와 별개로 캠페인 시간 어느 때나 열릴 수 있고, 장소가 기억하는 것은 플레이어가 실제로 남긴 상태뿐이다. 방향은 [같은 서울, 다른 모험](../../GDD/proposals/Narrative-Direction.md)을 따른다.

### 신도림 연결부: 문을 닫지 않는 공성전

상태: 연혁 등록. 사람 플레이테스트는 아직 시행하지 않았고, 실험 절차·기록지는 [이슈 #86](https://github.com/islee23520/seoul-kenshi/issues/86), 배역·공간·정산 설계는 [설계 제안](../../GDD/proposals/Scenario-Hold-the-Gate.md)이 소유한다.

- 행위자: 원정대(플레이어)와 동료, 현장 책임자와 근무조, 수송 책임자와 운반 인부 둘, 무장 회수대. 배역은 역할 계약이지 정본 캐스트 지정이 아니다.
- 조건: 영등포에서 받아 구로에서 끝낸 개인 운송 의뢰의 귀환길에 추가 수송 의뢰를 제안받는다. 두 사람이 여과재 한 짐과 구리 부품 한 짐을 옮기려 하고, 현장 근무조는 여과재를 기다리며, 무장 회수대는 구리의 소유권을 주장하며 도착 시각을 알려왔다. 그 주장의 진위는 아직 확인되지 않았다. 이번 일을 맡지 않아도 처음 받은 보수는 당신 것이다. 공간은 한 역의 창작 연결부로 바깥 대기점–주 화물문–안쪽 집결점과 사람·등짐만 지나는 정비 통로가 있고, 실제 신도림 시설을 재현하는 뜻은 아니다. 정비 통로는 짐수레가 못 지나가고 여과재 한 짐은 등에 나눠질 수 있지만 구리 짐은 장비 없이는 옮길 수 없다. 회수대는 세 과거 모두에서 이미 존재하며, 출발 시점에 공개한 의도·시간·통로를 결말에 맞춰 바꾸지 않는다.
- 행동: 오늘 이행, 다음 수송 창 연기, 일부 인도, 권한 있는 합의, 거절 중 하나로 계획한다. 문을 고쳐도 제3자의 통행권이 생기지 않고, 구리는 소유권 확인 전까지 봉인 보관할 수 있다. 이때 사람과 여과재 이동에 회수대가 이의를 제기하지 않는다는 서면 조건의 권한·진위를 확인하지 못하면 협상 성공으로 판정하지 않는다. 추가 보수는 여과재 인도분과 구리 인도분을 따로 약속하고, 구리를 인도하지 못하면 그 몫을 받지 않는다. 연기하면 화물은 확인된 바깥 창고에 남는다. 수송 책임자가 다음 근무조와 허가·호위를 다시 마련하며, 이 카드는 연기로 참사나 원한을 새로 만들지 않는다.
- 즉시 결과: 남은 문 상태와 허가, 인도된 사람·화물, 이행된 약속이 아래 세 과거와 계획에 따라 갈린다.
- 분기: 세 과거는 서로 다른 출발 이력의 비교 조건이며 순차 연결이 아니다. 각 과거가 다음 계획을 어떻게 바꾸는지가 이 사건의 본체다.
- 후속 사건: 재방문.

#### 세 과거

| 과거 | 현재 확정된 상태 | 귀환 시 첫 문장 |
|---|---|---|
| A · 수리와 합의 | 문이 조작 가능하다. 파티와 지정 수송대의 주 통로 허가가 모두 유효하고 수리비는 출발할 때 이미 지불했다. | “고친 문이 아직 움직인다. 이번 수송대도 허가서에 올라 있다. 문을 언제 열고 닫을지 정할 수 있다.” |
| B · 강행 파괴 | 문은 열린 채 파손됐다. 파티는 통과했지만 지정 수송대 허가는 없고 현장과의 손해 다툼이 남는다. | “문을 닫을 수 없다. 수송 책임자는 열린 구멍을 보면서도 허가 확인 없이는 짐을 보내지 않겠다고 한다.” |
| C · 정비 통로 우회 | 주 문은 고장 난 채 닫혀 있고 정비 통로가 발견됐다. 허가는 파티의 경량 통행뿐이다. | “큰 문은 그대로다. 당신이 지나간 통로로 사람과 여과재는 옮길 수 있지만 수송대의 사용 허가를 새로 받아야 한다.” |

B·C의 기본 조건에는 지정 수송대 허가가 없고 그 허가를 대신할 유효한 위임장도 없으며, 일반 창구의 신규 허가 발급은 오늘 수송 창을 넘긴다. 파괴 피해 정리는 별도 약속으로 남아서 통행 허가를 받았다고 사라지지 않는다.

#### 고정 시간표

D0는 사건 당일이고 D1은 다음 날이다. 틱·이동 속도·경제 시간으로 환산하지 않는다. 기본 비교는 전령·기록관 모두 없는 조건이며 공개 일정표와 구리 봉인 보관 합의의 진위·권한은 확인된 상태로 둔다.

|---|---|
| 제안·일정표 열람 | D0 13:30 |
| 오늘 수송 출발 | D0 14:00. 그때까지 허가·경로·참여 결정 확인 |
| 주 통로의 한차례 운반 | 20분. 출발하면 D0 14:20 완료 |

| 일반 창구 확인 완료 | D1 09:00. 기본 B/C의 새 허가가 이때 발급, 파손 피해 합의는 별도 |

#### 계획과 결과

| 상태 | 검토할 계획 | 먼저 알려줄 대가 | 교전 없이 확정되는 결과 |
|---|---|---|---|
| A | 허가와 도착 시각을 이용해 회수대 도착 전에 수송한다. 문 조작은 통과 순서·퇴로 계획에 포함한다. | 당일 출발 창을 맞추기 위해 파티가 다른 일정을 포기한다. 실제 시간 여유는 동료/일정표로 확인한다. | 시간·허가 조건이 확인된 경우 두 사람과 두 짐 인도. 추가 약속 모두 이행. 조건이 불충족이면 성공을 확정하지 않고 연기/협상/교전 검토로 돌아간다. |
| B | 먼저 수송 허가를 확인하고, 구리를 봉인 보관해 분쟁을 잠시 분리한다. 문을 닫는 계획은 사용할 수 없다. | 일반 창구를 쓰면 다음 수송 창. 구리 몫 추가 보수는 아직 없음. 파손 피해 해결도 남는다. | 권한 있는 합의가 성립한 뒤 두 사람과 여과재 인도. 구리는 창고에 보류. 허가가 없으면 이동시키지 않는다. |
| C | 정비 통로 사용 범위를 수송대까지 넓히고, 여과재를 나누어 운반한다. | 일반 창구를 쓰면 다음 창. 파티가 운반을 도우며 구리 짐은 창고에 남는다. | 허가 확인 후 두 사람과 여과재 인도. 큰 문과 대량 운송 문제는 그대로. 주 통로 공성전 없음. |
| A/B/C | 권한 있는 당사자와 구리 보관·후속 심사를 합의한다. | 구리 인도분 추가 보수 보류. 후속 수령자를 정해야 한다. | 합의만으로 문·허가·운반 능력이 바뀌지는 않는다. 각 과거의 실제 통로 조건까지 갖춘 뒤 사람·여과재를 옮긴다. |
| A/B/C | 오늘 수송을 연기하거나 추가 의뢰를 거절한다. | 이번 인도 실적과 추가 보수 없음. | 원래 의뢰 완료는 유지. 두 사람과 두 짐은 창고에 대기. 수송 책임자의 후속 조정으로 장면 종료. |

전투를 선택하면 따로 묻는다. A에서는 왜 열린 문을 유지해야 하는가, B에서는 무엇으로 닫을 수 없는 접근로를 대신 통제할 것인가, C에서는 주 통로 전투를 벌일 이유가 있는가. 같은 적을 같은 순서로 죽이는 것만 답으로 남으면 목표의 차이가 부족한 것이다. 교전 계획은 기록하지만 이 연혁 카드는 승패·사상자·화물 이동을 확정하지 않는다. 그 검증은 별도 전투 프로토타입의 몫이다.

#### 동료 변형

세 과거 기본 비교는 동료 조건을 동일하게 둔다. 별도 변형은 B 또는 C 하나에서 “허가 없음”을 “허가 서류 미확인”으로 바꾸고, 지정 수송대·해당 통로·D0/D1 시간을 포함한 유효한 위임장을 처음부터 수송 책임자의 서류철에 둔다. 문 상태는 그대로다. 동료는 정보를 바꾸고, 그 정보가 계획을 바꾼다.

| 조건 | 확인 가능한 도움 | 바뀔 수 있는 계획 |
|---|---|---|
| 전령 동행 | 직접 전달한 통지서로 회수대의 도착 창과 담당 창구를 확인한다. | 확인된 시간 여유 안에서 오늘 이동을 검토한다. 통행 허가를 대신 발급하지는 못한다. |
| 기록관 동행 | 기존 위임장에 이번 수송대·통로·시간이 포함되는지 10분 동안 대조한다. | D0 13:40 확인 뒤 오늘 창을 쓸 수 있다. 파손된 문을 복원하거나 구리 소유권을 판결하지는 못한다. B의 피해 다툼과 C의 화물 제약은 유지된다. |
| 둘 다 없음 | 공개 일정표와 일반 창구를 이용한다. | 다음 수송 창으로 연기해 허가를 확보하거나 추가 의뢰를 거절한다. 사건 전체가 막히지 않는다. |

전령의 정보를 기록관의 권한처럼 쓰거나, 기록관이 있다는 이유만으로 없는 위임장을 만들어 주면 실패다. 동료 관계·동기의 캐스트 대조는 별도 과제.

#### 결과 여섯 칸

결과는 한 문장 대신 여섯 칸에 남긴다.

| 기록 칸 | 구분할 값 |
|---|---|
| 사람 | 인도 완료 / 창고 대기. 교전 시 포획·부상·사망은 별도 검증 전까지 미정. |
| 화물 | 여과재 인도 여부 / 구리 인도·봉인 보류 여부 / 보관 장소·수령 권한 |
| 원래 보수 | 이미 지급. 추가 의뢰 결과로 회수하지 않는다. |
| 추가 약속 | 여과재 인도분 / 구리 인도분 / 약속한 오늘 또는 다음 수송 창 / 실제 이행 시점 |
| 시설·권리 | 문의 조작·파손 상태 / 허가 대상·통로·시간 / 해결하지 않은 피해 다툼 |
| 직접 관계 | 누가 무엇을 보았는지, 누구와 어떤 약속을 지켰는지. 자동 국가 동맹·전역 원한은 없음 |

재방문은 결과에 맞춘다. A에서 전량 인도했다면 근무조가 새 여과재를 쓰며 약속한 대금을 준다. B에서 구리가 보류됐다면 수송 책임자는 인원 귀환에 고마움을 표하면서 봉인 해제 때 다시 만나자고 한다. C에서는 정비 통로가 실제로 쓰였어도 큰 화물문 수리는 여전히 다음 일이다. 최초 인도 때 추가 보수를 이미 받았다면 재방문 정산은 수령 확인으로 바뀌고 두 번 지급하지 않는다. 거절한 경우 오늘 하지 않은 구조를 칭찬하는 대사를 재생하지 않는다.

#### 반례

| 투입할 변경 | 기대하는 처리 |
|---|---|
| A의 허가가 파티만 대상으로 바뀜 | 당일 지정 수송 불가. 별도 권한 확인이나 연기로 복귀 |
| B에서 “문을 닫는다” 선택 | 물리적으로 불가능함을 안내하고, 다른 접근통제·협상·철수로 유도 |
| C에 회수대 전투를 자동 삽입 | 거부. 수송이 움직이지 않거나 다른 길을 택하면 주 통로 공성전을 강요하지 않음 |
| 현장 책임자가 사망·부재 | 공동 방어 대사와 개인적 도움 없음. 이미 유효한 허가의 효력과는 별개로 판단한다. 변경 권한이 필요한데 적법 대행이 없으면 연기. 새 배역 즉석 생성 금지 |
| 원래 의뢰 보수 회수 / 같은 결과 재전달 | 회수하지 않음. 같은 결과는 기존 영수증에서 확인할 뿐, 새 지급과 관계 사건도 없음 |
| 같은 전투에 상충하는 결과가 뒤늦게 도착 | 병합하지 않음. 상태 변경 없이 충돌로 기록 |
| 전투 시작 뒤 바깥에서 허가·분쟁 조건 변경 | 시작할 때 확정한 전투 입력을 몰래 고치지 않음. 다음 캠페인 판단에서 처리 |

후계 생성은 [세계 원장](Heirs-Names-and-World-Ledger.md)의 별도 규칙에 맡긴다. 이 사건이 후계 생성 시스템을 호출하거나 죽은 책임자의 기억을 새 사람에게 옮기지 않는다.

#### 구현 경계

- 여과재와 구리는 비교용 창작 화물이고 기존 아이템 ID나 경제 밸런스가 아니다. 운반 인부 둘도 정본 캐스트·분대 생존수와 무관한 표식이다.
- 종이 카드의 표식·처리 순서는 [RTFC 계약](Realtime-Formation-Card-Battle.md)의 전투 턴·분대·카드 수가 아니고, 전령·기록관이 새 전투 카드를 만들지 않는다. 정산은 [왕복 계약](Strategy-Battle-Roundtrip.md)의 한 번의 ResultId를 유지하며 비전투 결과를 전투 결과로 가장하지 않는다.
- 발생 조건은 [이동·조우](Travel-and-Encounters.md)의 위치·시간·소음·통제·최근 사건·파티 입력과 이어지고, 문·허가·일정·분쟁의 지속 상태와 소유권은 이 사건이 보존한다.
- [월드맵 구성](World-Map-Construction.md)의 334역과 무관하게 이 사건의 장소는 신도림 창작 연결부 하나다. [역 내부 구성](Station-Interior-Construction.md)은 내부 입장·시설 슬롯이 아직 없음을 명시한다.
- 관계 변화는 직접 목격·보고 범위의 소수 인물에만 남고, 문서만으로 전역 평판·동맹 변화를 자동 적용하지 않는다.
