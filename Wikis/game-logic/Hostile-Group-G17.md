# G17 · 감시궤도군

여의도 수변 마스트는 안개 속 의료 침대의 금속 난간을 침입 표적으로 잡는다.

적색 플래그가 올라가면 S01 수문 옆 이송로가 닫히고, 서울역 기록청 옥상의 헤드가 같은 임계표를 받아 S06 회랑까지 잠근다.

감시궤도군은 사람을 추적하는 전능한 감시망이 아니라 오래된 임계 테이블을 돌리는 마스트 헤드, 짧은 이동 레일과 송신 무리의 생태다.

XT02 해상 잡음이 강해지면 서남 반경이 넓어지지만 건물 안이나 마스트 열 밖의 신호를 합칠 수 없다.

저해상 열화상, 금속 반사 근거리 광학 무선 버스트와 기둥 진동이 감각의 전부다.

냉각탑 증기를 화재로, 금속 침대를 무장 이동으로 만조 때 흔들리는 난간을 침입으로 오인한다.

얼굴이나 소속을 식별하지 못하고 영상도 경보 교대가 끝나면 지운다.

F01 냉각탑지기는 증기 시간과 온도를 기록해 오탐을 소거하지만 플래그를 내리는 권한은 없다.

HP03 수변 당직이 의료 이송 명부를 헤드 앞에서 대조해야 적색이 황색으로 내려간다.

에너지는 마스트 태양 트릭클, 옥상 축전과 수문 분전의 작은 몫에서 얻는다.

짐벌 베어링, 광학 돔 대역 필터와 플래그 액추에이터가 닳으면 헤드는 같은 방향을 오래 본다.

축전 하한이나 돔 오염에 닿은 마스트는 황색으로 굳어 송신열에서 빠진다.

새 위성을 띄우거나 도시 전역 헤드를 연결하지 못하며, 방치 헤드를 가까운 레일에 올리는 정도로만 수를 유지한다.

의료 이송 표식과 수문 계측이 같은 분전을 쓰므로 전면 차단은 다음 홍수와 화재의 경고까지 없앤다.

출현은 임계표가 마스트에 다시 적재될 때, 확산은 인접 헤드가 같은 경보표를 받을 때 일어난다.

오염과 축전 고갈이 정체를 만들고 화이트리스트가 공개되면 협상 상태가 된다.

와해는 적색 플래그 레일을 고정하고 오탐 헤드를 황색 대기로 보내는 일이다.

수위 계측 채널을 남긴 채 경보 채널만 분리하고, 다음 만조에 실제 경보가 울리는지 다시 시험해야 공존이 성립한다.

### G17-SC1 · 안개와 금속 난간

이송 중인 병상이 적색 플래그 아래 멈춘다.

플레이어는 오염된 돔을 가리고 F01의 증기 기록과 만조 진동을 대조해 오탐의 근원을 찾는다.

헤드를 부수면 길은 열리지만 수문 수위 파형도 사라지므로, 환자가 기다리는 시간과 계측 보존 사이에서 순서를 정해야 한다.

### G17-SC2 · 회랑 명부

HP03은 의료 비콘을 화이트리스트에 올리려 하지만 해상 잡음이 같은 대역을 덮는다.

플레이어는 마스트마다 대역 필터를 갈며 이송 명부를 직접 읽힌다.

한 회랑씩 여는 동안 다른 환자가 우회해야 하고 축전도 소모된다.

비밀 예외를 넣으면 빠르지만 다음 당직이 이유를 알 수 없어 다시 봉쇄한다.

### G17-SC3 · 다음 만조의 경보

여러 마스트가 일괄 적색으로 바뀌기 전에 플래그 레일을 고정하고 계측 전원을 별도 회로에 남긴다.

마지막 병상이 기록고를 건넌 뒤 오탐 헤드를 황색으로 둘지 철거할지 결정한다.

철거는 감시 공포를 즉시 줄이지만 실제 수위와 옥상 화재의 위험을 다른 주민에게 넘긴다.

공존은 공개된 지속 시간 상한, 반복되는 돔 정비와 사람의 현장 대조를 요구한다.
