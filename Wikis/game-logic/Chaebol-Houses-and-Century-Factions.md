# 재벌 가문과 세기의 세력

붕괴 전 한국에서 대기업집단은 회사 상호만으로 움직이지 않았다. 총수 일가가 적은 지분으로 계열 전체를 지배하는 구조였다. 이 페이지는 그 **사실 층**과, 붕괴 후 110년 개막의 **창작 운영가문**을 나눈다. 현직 임원·로고·구호를 개막 인물로 옮기지 않는다.

상세 가문 필드와 외부전구 산문은 [세계 서사 총람](World-Narrative-Atlas.md)이 정본이다. 어느 가문도 16국 한 나라를 통째로 소유하지 않는다.

## 사실 층 — 총수 일가 지배

공정거래위원회 「2026년 공시대상기업집단 주식 소유 현황」(2026-09-03 공개, [연합뉴스 보도](https://www.yna.co.kr/view/AKR20260903085000002)):

- 총수(동일인)가 있는 공시집단 89개, 소속 회사 3,293개사.
- 총수 일가 평균 직접 지분 3.5%, 계열회사 보유 55.5%, 내부지분율 61.4%. 직접 지분과 내부지분의 격차 약 58%p.
- 공정위 설명: 총수 일가가 **적은 지분으로도 전체 집단을 지배**한다.
- 사익편취 규제 대상: 총수 일가가 20% 이상 지분을 가진 회사, 또는 그 회사가 50%를 넘는 지분을 가진 회사.

창립 가문은 공개 전기로만 적는다. 개막 캐스트의 얼굴이 아니다.

| 집단 (붕괴 전 상호) | 창립 가문 (공개 전기) | 잔선에서 가져올 것 | 가져오지 말 것 |
|---|---|---|---|
| 삼성 | 이병철 창업, 이후 총수 일가 승계 ([Lee Byung-chul](https://en.wikipedia.org/wiki/Lee_Byung-chul)) | 일가 지분·계열 출자로 냉각·전산·부품 면허를 쥐는 습관 | 현직 실명, 제품명, 구호 |
| 현대 | 정주영 창업, 이후 자동차·중공업 등으로 일가 분가 ([Chung Ju-yung](https://en.wikipedia.org/wiki/Chung_Ju-yung)) | 분가해도 같은 성씨 장부가 유치선·리깅·접합 도면을 나누는 일 | 분가 소송의 실명 당사자 |
| LG | 구인회 창업 ([Koo In-hwoi](https://en.wikipedia.org/wiki/Koo_In-hwoi)) | 화학·생활·연구 키를 가문 원로와 법인 이사회가 함께 잠그는 습관 | 현 구씨 일가 실명 |
| SK | 최종건 창업으로 공개되는 최씨 총수 일가 | 에너지·열원 접속권을 일가 지정 후계가 닫는 습관 | 현직 실명 |
| 롯데 | 신격호 창업의 신씨 일가 | 유통 창고와 의전 물자를 일가 장부로 나누는 습관 | 형제 분쟁의 실명 |
| 한화 | 김씨 총수 일가 | 방호키·차단문을 일가 지정과 군 잔존이 겹쳐 쥐는 습관 | 현직 실명 |
| CJ | 이씨 일가 (삼성에서 분가한 계열의 공개 서사) | 식자재와 운송을 같은 일가 장부에 묶는 습관 | 현직 실명 |
| 포스코 | 창립은 국가 주도 제철. 전문경영인 비중이 큰 집단 | 합금 레시피가 가문 성씨보다 직능 면허에 남는 예외 | 「포스코 가문」을 이씨·정씨처럼 꾸미는 일 |

열람일 2026-09-14. 지분 숫자는 2026년 공시이며 2146년 장부가 아니다.

## 창작 층 — 개막의 운영가문

붕괴 이후 상호는 간판으로만 남거나 헌장 이름으로 굳는다. [세계 서사 총람](World-Narrative-Atlas.md)의 `HC01`–`HC14`가 법인 후계, `HP01`–`HP10`이 시민·직능·기반이다. 지정 후계(허은찬, 유세진 등)는 개막 세대 창작 인물이며 창립 총수와 같은 몸이 아니다.

| 층 | 붕괴 전 | 건국기 (붕괴 0–5) | 공백의 세기 | 개막 (붕괴 +110) |
|---|---|---|---|---|
| 재벌 가문 | 총수 일가가 계열 출자로 집단을 지배 | 비상위원회에 냉각·펌프·열원 키를 들고 앉음 | 상호는 지워지고 일가 장부는 면허·당직함으로 바뀜 | HC 운영가문이 16국을 소유하지 않은 채 기반을 임대 |
| 구 정부 | 중앙 행정, 징병 명부, 기록원 | 비상권한. 반환 시점이 법통이 됨 | 도장과 명부만 필사. 부대 이름은 생활권 군사로 갈림 | 도성기록청, [징집 잔존](Conscription-Remnants.md), HP04 도성기록법가 |
| 외부 세력 | 주둔·교역·이주의 사실 층 | 시외 기지·관문이 16국 슬롯 밖 압력 | 검역·곡창·해협·극동·원양 신탁이 생활권을 누름 | XT01–XT05, [이주민 회랑](Diaspora-Corridors.md) |
| 변혁 세력 | 없음 | 열여섯 깃발 | 법인 후계와 직능 길드가 헌장을 다시 씀. 총수 성씨는 구술 | 십육국 + HP 시민 가문 + 개막 세대 지도자 |

### 법인 후계가 잇는 기반 (HC)

개막에 상호가 남아 있어도, 지배 단위는 총수 일가의 **장부·면허**다. 국가 슬롯을 사지 않는다.

| 가문 ID | 붕괴 전 상호 (사실 출발) | 개막에서 쥐는 것 | 생활권 |
|---|---|---|---|
| HC01 | 삼성전자 | 야간 냉각, 봉인 전산동 | 여의신정·상암 |
| HC02 | 현대자동차 | 배터리 셀 순환, 유치선 | 여의신정·수서·용산 |
| HC03 | LG생활건강 | 생체 데이터셋 격리 키 | 마곡·약령 |
| HC04 | SK에너지 | 지하 열원 접속권 | 뚝도·암사·여의 |
| HC05 | 북문지식원 | 옛 기록 원본 상자 | 북산·도성 |
| HC06 | 쿠팡 | 근거 없는 배송 순번을 막는 창구 | 가락·노량진 |
| HC07 | 포스코 | 내열 합금 레시피 (직능 비중이 큼) | 서남·뚝도 |
| HC08 | 한화에어로스페이스 | 통합 방호키 | 창동·신내·암사 |
| HC09 | 롯데쇼핑 | 의전·창고 접근 | 도성·노량진·가락 |
| HC10 | CJ제일제당 | 식자재 규격 | 마곡·상암·가락 |
| HC11 | CJ대한통운 | 운송 순번 | 용산·신내·수서 |
| HC12 | 현대중공업 | 대형 리깅 자격 | 서남·아차·뚝도 |

HC05 북문지식원은 붕괴 전 상호가 아니다. 공백의 세기에 기록 금고를 지킨 창작 가문이다.

### 시민·직능 가문 (HP) — 변혁의 산물

HP는 총수 일가가 아니다. 수문·배차·의료·원장처럼 생활권이 한 세기에 걸쳐 만든 길드다.

| 가문 ID | 이름 | 개막에서 쥐는 것 |
|---|---|---|
| HP01 | 아리수수문가 | 수문 키 분할 보관 |
| HP02 | 환승선로문 | 중립 배차표 |
| HP03 | 공동의료원가 | 면허 당직표 |
| HP04 | 도성기록법가 | 원본 해시 봉인 |
| HP05 | 북산귀환회 | 가족 재결합 명부 |
| HP06 | 약령치유문 | 처방 이중확인 |
| HP07 | 한강교량공회 | 풍속 폐쇄 기준 |
| HP08 | 시장냉동상단 | 전력 슬롯 순환 |
| HP09 | 데이터신탁가 | 모델 카드 공개 |
| HP10 | 외교통역문 | 언어 쌍 당직 |

## 구 정부 잔존

중앙 정부는 붕괴 0년에 끊긴다. 남는 것은 도장, 징집 명부, 기록원, 비상 소집권이다. 개막의 도성기록청은 나라를 다시 세운 것이 아니라 **필사된 인준권**이다. 수방사 잔편·용산 주둔 기억·동원잔존은 [징집 잔존과 군 장부](Conscription-Remnants.md)를 따른다. 2026 예비군 규정을 2146 제도로 옮기지 않는다.

## 외부 세력

16국 슬롯을 대체하지 않는 다섯 전구.

| ID | 이름 | 개막에서 하는 일 |
|---|---|---|
| XT01 | 임진관문전구 | 북녘을 단죄하지 않고 검역·귀환 명부만 지킴 |
| XT02 | 서해곡창전구 | 하구 부두·냉동·곡물 순번 |
| XT03 | 해협삼로전구 | 용산·수서 쪽 해협 통행 세 갈래 |
| XT04 | 두만극동전구 | 동북 회랑의 극동 중계 |
| XT05 | 원양신탁전구 | 원양 계약고와 송신 신탁 |

이주민 회랑의 시드 인물은 [이주민 회랑](Diaspora-Corridors.md)이 정본이다. 민족이 충성을 예측하지 않는다.

## 넣지 말 것

- 현직 총수·임원을 개막 캐스트로 기용
- 삼성·현대 로고·구호·제품명을 국호처럼 쓰기
- 운영가문이 16국을 매수한 설정
- 포스코를 이씨·정씨와 같은 「창립 가문」으로 단정
- 원작 픽션의 연표 문장을 잔선 사실처럼 옮기기
