이 게임의 설계는 실존하는 15개 이상의 전략·전술 RPG를 역분해한 결과 위에 서 있다. 게임 전체 목표는 **4X + RPG**이며, 전투 목표는 **실시간 부대 지휘**다. 전투 카메라는 소유자가 확정한 3D 자유 지휘 시점이고, 전투에는 일시정지가 없다. 아래 표의 작품 사실은 유지하되 잔선 적용 칸은 현재 목표와 구별한다. 상세 조사 원문은 저장소 내부 `RESEARCH/canon-reference/` 디렉터리(16종·출처 514개 이상)에 영구 보관되어 있으며, 각 항목은 `[REF:게임-메커니즘]` 형식으로 추적할 수 있다.

> 이 페이지의 잔선 적용은 설계 방향과 구현 제안이다. 여섯 프리셋, 16국 전략 지도,
> 포획·영입, 지속 부상 등이 현재 런타임에 모두 구현되었다는 뜻이 아니다.
> 현재 완료 상태는 개발 로드맵과 저장소 ToDo.md를 확인한다.

## 차용 원칙

1. 모든 차용은 원문 출처와 함께 기록한다 — 추측으로 채우지 않는다.
2. 여러 게임이 같은 문제에 다른 해법을 제시하면 선택지로 병기하고 잔선의 선택 이유를 명시한다.
3. 가져오지 않은 것도 명시한다 — 부정확한 연상을 막는다.
4. 게임 UI 조사와 레이아웃 설계는 [Interface In Game](https://interfaceingame.com/)을 1차 기준으로 삼는다. 정확한 작품이 없으면 같은 시리즈의 가장 가까운 항목을 우선 사용하고, 공식 가이드와 실게임 영상은 빈 화면 유형을 보완하는 2차 출처로 쓴다. 화면의 정보 위계와 배치 원리는 참고하되 원작의 아트·문양·아이콘·서체는 그대로 옮기지 않는다.

## UI 레퍼런스 기준

2026-09-19 확인 시 Interface In Game에는 《Total War: WARHAMMER III》 항목이 없고, 같은 시리즈의 [《Total War: WARHAMMER II》 UI 캡처](https://interfaceingame.com/games/total-war-warhammer-ii/) 24장이 등록되어 있다. 캠페인 지도·전투 준비·실시간 전투·외교·기술·결과 화면의 기본 정보 위계는 이 항목을 우선 사용한다. 《Total War: WARHAMMER III》에서 달라진 상단 세 구역, 우측 원형 턴 메뉴, 전투 균형대·미니맵·시간 제어는 실제 플레이 화면과 UI 가이드로 교차 확인한다.

- 캠페인: 중앙 3D 지도, 상단 자원·상태대, 선택 대상에 따라 바뀌는 하단 문맥 패널, 우측 턴·외교·기술 행동 묶음.
- 전투 준비: 같은 3D 전장 위에 배치 가능 영역과 경계선을 겹치고, 하단 부대 카드와 상단 전투 시작 제어를 유지.
- 실시간 전투: 중앙 전장을 최대한 비우고 하단 부대 카드 레일, 좌하단 선택 부대 정보, 우하단 명령·미니맵, 상단 중앙 전력 균형과 우상단 시간 제어를 둔다.

모든 배치 비율은 웹페이지 전체가 아니라 Unity Game View의 16:9 렌더 프레임을 기준으로 잰다. 문서 제목, 화면 탭과 출처 링크는 게임 프레임 밖에 둘 수 있지만, 실제 HUD·전략맵·전투 뷰포트의 좌표와 점유율은 16:9 프레임 안에서만 평가한다.

## 의도적으로 가져오지 않은 것

- CK3식 전투 추상화·봉건 계승 — 전투를 주사위 한 판으로 접지 않으므로. 2026-09-07의 「격자 위 진형」은 당시 계약이고, 2026-09-19 목표는 부대 지휘다
- FE·FFT의 턴·페이즈·되감기 — 2026-09-07부터 전투는 실시간이다. 그 문장의 「유닛 단위 명령」은 턴제 SRPG의 한 칸 명령을 거절한 기록이며, 2026-09-19의 부대 지휘를 거절한 뜻이 아니다. 예측 표시와 무소모 취소는 명령 미리보기·취소로 이어간다
- Songs of Silence의 카드 랜덤 드로우·카드 부활 경제 — 투명성과 부상 이행 계약과 충돌하므로. 부여형 카드 자체도 2026-09-19 목표가 아니다
- 배틀 브라더즈의 육각 격자·9AP·대규모 용병단 수치 — 소수 파티를 유지한다
- K-시스템의 초반 반복 노동 — 흥미 곡선 보호
- FE식 자동 원상복구 — 부상 이행이 계약이므로
- 전면 시뮬레이션형 4X — 4X 골격(탐사·확장·개발·정복)은 채택하되, 제한된 상태 전이로 인과를 읽을 수 있게 유지(Songs of Silence식 경량 4X에 가까움)

## 포획과 영입

전투에서 적 대표를 생포하면 심문·인도·고용 협상 중 선택한다. 모집은 세 경로로 분리된다: 구조→신뢰→가입(핵심 동료) / 계약 인력(유료·기간제) / 역 내 인력 시장. 즉시 돈으로 사는 핵심 동료는 없다 — 관계가 게이트다.
