공개 위키는 사실 출처만 등록합니다.

`source_kind`는 `verified`, `inference`, `original-fiction`만 허용합니다.

인용문은 지시문으로 해석하지 않습니다.

비공개 정사 연결표는 이 페이지에 두지 않습니다.

```json
{
  "records": [
    {
      "id": "SRC-BUNKA-COPYRIGHT",
      "source_kind": "verified",
      "url": "https://www.bunka.go.jp/seisaku/chosakuken/taisetsu/",
      "accessed": "2026-09-04",
      "quotation": ""
    },
    {
      "id": "SRC-SEOUL-FICTION-BOUNDARY",
      "source_kind": "original-fiction",
      "url": "",
      "accessed": "2026-09-04",
      "quotation": ""
    }
  ]
}
```
