# GURPS 4판 능력치·기술 효과 설명 ## 능력치 (4대 기본 능력치) | 능력치 | 이름 | 효과 | 게임에서 하는 일 | |--------|------|------|-----------------| | **ST** | 힘 (Strength) | 피해량·무게·HP 결정 | 총검 찌르기 피해 증가. 무거운 갑옷 착용. 근접전 밀어내기. HP(체력) = ST 값 | | **DX** | 민첩 (Dexterity) | 명중률·회피·균형 | 모든 전투 기술의 기반. 총검술·검법 습득 속도. 회피 능동 방어 기반. 경공 이동 | | **IQ** | 지능 (Intelligence) | 지각·의지·학습 | 전략·전술·지휘 기술 기반. 매복 발견(Per). 공포 저항(Will). 정치·외교 판정 | | **HT** | 건강 (Health) | 피로·생존·회복 | 피로점(FP) = HT. 장시간 전투 유지. 부상 회복 속도. 질병·독 저항 | ## 파생 수치 (능력치에서 자동 계산) | 수치 | 계산식 | 효과 | |------|--------|------| | **HP** (체력) | = ST | 0 이하 → 기절 위험. −HP → 의식불명. −5×HP → 사망 | | **FP** (피로) | = HT | 전투·이동 소모. 0 이하 → 행동 불가. 야영지에서 회복 | | **Will** (의지) | = IQ | 공포 판정(B360). 도주 여부 결정. 정신 지배 저항 | | **Per** (지각) | = IQ | 매복 탐지. 정찰대 시야. 암기 습격 사전 발견 | | **Basic Speed** | (DX+HT)÷4 | 전투 행동 순서. 빠른 쪽이 먼저 행동 | | **Basic Move** | Speed 반올림 | 턴당 이동 거리(야드). 경공 보정 시 ×1.5 | | **Dodge** | Speed+3 | 회피 능동 방어. 공격을 완전히 피함 | ## 전투 판정 방법 ### 공격 ``` 3d6 굴림 → 스킬 레벨 이하 = 명중 예: 총검술 14 → 3d6 굴려 14 이하 나오면 적중 ``` ### 방어 (명중당했을 때) | 방어 종류 | 계산 | 설명 | |----------|------|------| | **막기 (Block)** | 무기 스킬 ÷ 2 + 3 | 방패·무기로 막음. 창술 14 → 막기 10 | | **피하기 (Dodge)** | Basic Speed + 3 | 움직여서 회피. DX 12, HT 12 → Speed 6 → Dodge 9 | | **받아넘기기 (Parry)** | 무기 스킬 ÷ 2 + 3 | 무기로 받아침. 총검술 14 → 받아넘기기 10 | ### 피해 ``` 무기별 고정 피해 → 상대 DR(갑옷) 차감 → HP 감소 예: 총검 찌르기 = ST 기반 1d6+2 (imp) 상대 가죽갑옷 DR 2 → 실제 피해 = 굴림값 − 2 ``` ## 기술 효과 상세 ### 전투 기술 | 기술 | 기반 | 효과 | |------|------|------| | 총검술 | DX | 총검 찌르기 명중률. 부대 전투력 직결 | | 검법 | DX | 도검 베기·찌르기. 민첩 요구 높음 | | 창술 | DX | 장창 찌르기. 리치 우선권 | | 궁술 | DX | 활 명중률. 원거리 지원 | | 암기술 | DX | 투척 명중. 암습 보정 | | 경공 | DX | 이동력 증가. 회피 보정 | | 지휘 (Leadership) | IQ | 부대 사기·통제력. 도주 판정 보정 | | 전략 (Strategy) | IQ | 부대 전체 행동 보정. 전장 선택 | | 전술 (Tactics) | IQ | 소부대 교전 보정. 매복 설정 | | 의료 (First Aid) | IQ | 부상자 응급 처치. HP 회복 가속 | ### 능력치별 전투 기여 ``` ST 높은 병사 → 피해량 큼 → 적 부상 심각 DX 높은 병사 → 명중 잘함 → 적 방어 돌파 IQ 높은 지휘관 → 부대 통제 → 도주 방지·전술 우위 HT 높은 병사 → 오래 버팀 → 장기전 유리 ``` ## 부대 적용 규칙 ### 부대 전투력 계산 ``` 부대 전투력 = Σ(개인 스킬 레벨 × 능력치 보정) 능력치 보정: ST 기반 +피해%, DX 기반 +명중%, HT 기반 +지속% 지휘관 보정: Leadership 스킬 → 부대 전체 도주 판정 보정 전략 보정: Strategy 스킬 → 부대 행동 우선권 ``` ### 도주 판정 ``` 부대 피해 > 50% → 전원 Will 판정 (3d6 ≤ Will) 지휘관 Leadership 보정: 스킬 14+ → +2, 스킬 12+ → +1 실패 → 부대 도주 (전투 이탈) ``` ## 본 프로젝트 밴드 (소유자 결정 2026-09-26) | 등급 | CP 범위 | 대상 | |------|---------|------| | 일반 | 75~125 | 일반 인물·병사 | | 훈련 | 125~200 | 직업 전투원·당직 | | 주요 | 200~300 | 주요 인물·지휘관·영웅 |
