1. 해당 솔루션은 본인이 다니는 회사의 게임 서버 개발 시 사용하는 Template 프로젝트의 일부입니다.

2. 이 프로젝트는 .NET 8 기반입니다. Visual Studio 2022(17.8 이상) 또는 .NET 8 SDK가 설치되어 있어야 빌드가 가능합니다.

3. 기본 프레임워크는 CoreWCF(.NET Core용 WCF) 및 자체 제작 라이브러리(Y2K.Core)로 구성되어 있고, DB는 MySQL(MySqlConnector + Dapper/Dapper.Contrib), 캐시는 Redis(StackExchange.Redis) 기반입니다.

4. 외부 라이브러리는 모두 NuGet 패키지로 관리되며, 자체 제작 라이브러리(Y2K.Core.Util / Log / Crypt / Network / DataBase / Web / Cache)는 `..\Y2K` 폴더에 미리 빌드된 DLL로 포함되어 있습니다.
   참조 오류로 빌드가 되지 않는 경우, 해당 프로젝트에서 `..\Y2K` 폴더의 DLL을 수동으로 참조 추가하시면 됩니다.

5. 기본적으로는 Kestrel 기반으로 동작하므로 관리자 권한 없이도 실행 가능합니다. 다만 방화벽에서 포트 허용이 필요할 수 있습니다.

6. 기획 데이터 및 GlobalDB는 포함되어 있지 않기 때문에, 서버 실행 시 DB 연결 및 Redis 초기화 부분은 주석 처리되어 있을 수 있습니다. 실제 구동을 원하시면 로컬 MySQL / Redis와 스키마 준비가 필요합니다.

7. 서버 설정값은 `GameServer/appsettings.json`에서 조절할 수 있습니다(.NET Framework 시절의 App.config / Settings1.settings 는 제거되었습니다).
   기본 포트는 게임 포트 1219, 운영(GMS) 포트 1003 입니다.
   환경별로 `appsettings.QA.json`, `appsettings.Live.json` 을 두어 오버라이드할 수 있으며, 연결 문자열은 `ConnectionStrings` 섹션의 `GlobalDB` 값을 수정하세요.

8. 서버 실행 시 콘솔 출력과 함께 `bin\Local\Log\` 아래의 log4net 로그 파일을 함께 확인하시면 디버깅에 도움이 됩니다.

9. 클라이언트 개발자와의 API 공유용으로, WCF 기본 Help 페이지 대신 자체 제작한 Custom HelpPage를 사용하고 있습니다.
   기본 접속 주소는 `http://{localIP}:{게임 포트}/Help/DefaultPage` (기본값: http://localhost:1219/Help/DefaultPage) 이며,
   서버 실행 시 콘솔에 안내되는 주소로 접속하시면 됩니다.
