# 유니티 구조

현 Unity POC의 2026-09-07 아이소 기록이다. 결정 11의 3D 자유 지휘 카메라나 새 전투가 Unity에 구현됐다는 증거가 아니다.

## 기준선

현재 기반은 Unity `6000.7.0a5`입니다. 시험판이므로 편집기 판본과 패키지 잠금 파일을 함께 고정하고, 판본을 올리기 전에 따로 검증합니다.

현재 구현된 기반은 다음입니다.

- Unity `6000.7.0a5` 프로젝트
- 장르 계약 JSON과 상수, EditMode 장르 계약 테스트
- URP, Input System, Test Framework, VContainer `1.19.0`
- `Bootstrap.unity` App scope와 FSM, `Foundation.unity` 화면 child scope
- 단일 scene-load 권한과 정적 아키텍처 게이트

이 기반 위에 `Unity POC 통합 코어 루프`가 실렸습니다. `MainTitle` 화면 lease, 세 역 노선, 교섭·우회, 30Hz 실시간 진형·카드 전투(`rtfc-owner-cards-v2`), 정확히 한 번 정산, uGUI HUD가 `Janseon.Core`와 `Janseon.Foundation`에 있습니다. 이는 현재 구현 이력이며 새 목표 전투가 아닙니다. 새 목표는 부대 선택과 이동·공격·방향·진형·정지 명령, 미리보기·확인·취소, 확인된 현재 명령 교체를 문서로만 정합니다. 카드, 명령 큐, 웨이포인트와 속도 제어를 새 런타임 계약으로 올리지 않습니다.

답변 없이 기한이 지난 카메라·일시정지 질문에는 3D 자유 지휘 카메라와 이 파티 전투에 한정한 일시정지 명령을 설계 기본값으로 채택합니다. 이는 소유자 직접 결정이나 현재 POC 구현 주장이 아닙니다. 카메라는 팬·오빗·줌을 제공하되 각도와 시야각 수치를 정하지 않습니다. 일시정지 중 명령 미리보기·확인·취소를 허용하고, 확인된 교체 명령은 재개 뒤 다음 시뮬레이션 스텝에서 결정론적 순서로 적용합니다. 공유 캠페인 월드와 다른 파티는 멈추지 않습니다.

POC 화면은 [UI가 코드로 들어오는 길](../Ui-Implementation-Pipeline.md)을 따랐습니다. HTML 목업을 동결한 뒤 uGUI로 옮겼고, 클릭 대상은 목업과 같은 그림입니다. 생성 아트 슬롯·16국 캠페인·집계 사상자 표현은 아직 완료가 아닙니다.

## 영역별 책임

현재 저장소 어셈블리는 `Janseon.Core`(엔진 금지), `Janseon.Foundation`, `Janseon.Data`, `Janseon.Art`입니다. 전투 계약과 시뮬레이션은 Core 안의 `Battle.Contracts`·`Battle.Sim` 네임스페이스이고, 별도 `Janseon.Battle` 어셈블리는 없습니다.

| 모듈 | 책임 | UnityEngine 참조 |
|---|---|---|
| `Janseon.Core` | ID, 시간, 명령, 사건, 노선, 캠페인, 정산, 현재 카드 전투 POC | 금지 |
| `Janseon.Data` | Unity 저작 데이터 | 허용 |
| `Janseon.Foundation` | 씬 흐름, 화면, uGUI, 전투 드라이버 | 허용 |
| `Janseon.Art` | 런타임 슬롯·후보 | 허용 |

## 규칙

- 엔진 독립 모듈에는 전역 가변 상태를 두지 않습니다.
- 화면은 상태를 직접 수정하지 않고 명령을 보냅니다.
- 모든 상태 변화는 사건 원장에 기록합니다.
- 고급 패키지는 실제 사용처와 실패 테스트가 생긴 뒤 추가합니다.
