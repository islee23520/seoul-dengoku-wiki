# #101 UI/UX 화면 계약 — 확정 결정 1–3

- 상태: 확정
- 기록일: 2026-09-16
- 근거 이슈: [#101](https://github.com/islee23520/seoul-kenshi/issues/101)
- 적용 범위: HTML 목업의 화면 구조와 정보 표현
- 비적용 범위: Unity 구현, 서버·네트워크, 수치 공식, 데이터 저장

이 문서는 #101을 진행하기 위해 소유자와 합의한 화면 계약을 기록합니다.
검토 과정의 생성 이미지는 화면 구조와 정보 우선순위를 판단하기 위한 예시로만
사용했습니다. [Intent](../../Intent.md) 결정 8의 이미지 생성 금지와 UI 제3 표면
계약에 따라 해당 이미지를 저장소 아트 또는 Unity 실행 증거로 채택하지 않습니다. 실제 목업은
[UI가 코드로 들어오는 길](../../Wikis/game-logic/Ui-Implementation-Pipeline.md)과
[온라인 사용자 여정](../../Wikis/game-logic/Online-User-Journey.md)을 따라 별도로 갱신합니다.

## 결정 1 — 상위 화면은 열 면으로 고정한다

플레이어 여정에서 독립적으로 판단해야 하는 상위 화면을 다음 열 면으로 고정합니다.

| 순서 | 상위 화면 | 화면이 답해야 하는 질문 |
| --- | --- | --- |
| 1 | 캐릭터 생성·착생 | 나는 세계의 어떤 인물로 시작하는가? |
| 2 | 시작 프리셋 | 어떤 결핍과 장기 규칙을 감수하는가? |
| 3 | 세계 인물 모집 | 누구를 만나고 동행을 제안할 수 있는가? |
| 4 | 거점 허브 | 현재 거점에서 누구와 무엇을 할 수 있는가? |
| 5 | 캐릭터 대화 | 상대와의 관계 및 선택 결과가 어떻게 달라지는가? |
| 6 | 전략 노선도 | 알고 있는 세계에서 어디로 향할 수 있는가? |
| 7 | 역간 여행 | 목적지까지 어떤 경로·비용·위험을 감수하는가? |
| 8 | 조우 | 마주친 상황에 어떻게 대응하는가? |
| 9 | 전투 | 진형·카드·일시정지로 전투를 어떻게 지휘하는가? |
| 10 | 정산 | 선택과 전투가 인물 및 세계에 무엇을 남겼는가? |

계정·로그인은 상위 화면에 추가하지 않고 `열쇠` 자리만 둡니다. 무작위/커스텀은
캐릭터 생성·착생 화면의 내부 갈래이며, 진형/실시간/일시정지는 전투 화면의 내부
상태입니다. 화면 수를 늘리지 않습니다.

## 결정 2 — 상태와 장소는 지속하고, 상황은 맥락이 생길 때만 연다

- **상태**: 플레이어 인물의 현재 상태를 평상시에도 지속적으로 보여줍니다.
- **장소**: 현재 위치를 평상시에도 지속적으로 보여줍니다.
- **상황**: 사건이 예고되거나 실제로 직면했을 때만 추가로 보여줍니다.
- **화면 맥락**: 평상시와 예고 상태를 전투 화면으로 표현하지 않습니다. 예시 화면은
  사용자가 다음 행동을 판단할 수 있도록 해당 맥락의 실제 플레이 시점을 사용합니다.

따라서 평상시에는 상태·장소만 조용히 유지하고, 예고 시에는 기존 플레이 화면 위에
주의와 남은 시간을 추가하며, 직면 시에는 선택 가능한 상황 패널을 엽니다. 실제 상황이
전투일 때에만 전투 화면과 전투 HUD를 사용합니다.

## 결정 3 — 사실은 활동으로 얻고, 예측은 능력으로 넓힌다

전략 노선도와 거점 정보는 전지적 세계 지도가 아닙니다.

- 플레이어가 직접 알게 된 역과 노선만 정확한 사실로 표시합니다.
- 미발견 영역에는 정확한 역·노선·세력 정보를 제공하지 않습니다.
- 직접 활동하여 수집한 정보는 확인된 사실로 승격합니다.
- 전언 등 간접 정보는 사실과 구별되는 소문으로 표시합니다.
- 예측 가능한 범위와 정확도는 플레이어의 레벨 및 관련 능력치에 따라 달라집니다.
- 예측은 확인된 사실처럼 보이지 않도록 범위·가능성·신뢰도를 함께 표시합니다.

화면상 최소 정보 상태는 `미발견`, `소문`, `직접 확인`입니다. 시간이 지난 정보의
노후화 기준, 정보 출처와 공유 범위는 다음 의사결정에서 확정합니다. 능력치별 계산식,
저장, 동기화, 서버 권위는 #101의 HTML 화면 계약이 아니라 후속 구현 이슈의 범위입니다.
