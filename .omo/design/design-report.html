최종 판정: 게임성 미충족 — PASS 2 / PARTIAL 3 / FAIL 3

기술 루프(결정론·정산·연속 원정)는 통과했으나, 플레이어가 내리는 결정이 전투에 없고(자동 명령 버튼 하나) 선택 비용이 보이지 않으며(비용·보상 미표시) 세계·인물이 전달되지 않는다(아트 차단 슬롯). 아래 설계는 이 3개 FAIL과 3개 PARTIAL의 처방이다.

1 · 영역별 판정 (8영역 루브릭)

영역판정핵심 근거 (720p/1080p 캡처 · 로그)
1 루프 완결성PASS단일 PID, 키보드만으로 협상→우회→전투 3루프 정산·복귀 완료 (cua/043·053·077)
2 선택 의미PARTIAL분기별 결과 ID·Core 수치(100/0→95/3→93/2→103/7→88/2)는 다르나 UI에 비용·보상·위험 없음
3 전투 결정FAIL"전투 명령" 단일 버튼 = 코드가 첫 합법 명령 자동 선택. 수동 이동·공격·대상 선택·턴 순서 전무 (cua/060)
4 상태 연속성PARTIAL자원·평판·중복 정산 방지는 DLL 프로브(469단언)로 검증. 단 파티 HP가 다음 전투 10으로 초기화(HP7→10) — 부상 미이행
5 목표와 긴장FAIL출정 목적·의뢰·실패 비용·다음 준비가 화면에 없음 (cua/010·013)
6 세계/인물FAIL타이틀·인물·아이콘·환경 5슬롯 "아트 차단", 전투 칸도 역할명+차단 문구 (cua/001·060)
7 조작/UXPARTIAL키보드 도달 OK·잘림 없음. 그러나 영등포→구로 직접 이동 거부 피드백 없음(cua/020), 미리보기 마커 잘림, HP/AP 저대비 3.70:1, 정산 카드 폭 계약 위반
8 안정성/결정론PASS빌드 exit 0, 세션 예외 0, 동일 seed/input 전체 replay hash 동일

2 · 확정된 설계 방향 (사용자 결정)

렌더링3D 하이트맵 복셀 타일 — 레퍼런스 iso_botw_rain_sim 구조(상면+절벽 측면·높이별 재질·(x+y) 정렬·픽셀 룩). 2D 스프라이트 대안 금지
카메라고정 직교 yaw 45° / pitch 26.57°(2:1) — GenreContract 35.264°에서 변경. 시점 조작 UI 금지
수직 구조Z-레이어(지상/B1/B2/B3) × 층내 하이트맵(0~8) 2축. 계단 등 연결 타일에서만 층 이동(정상/막힘/침수). LayerId는 Core 결정론 hash 포함
규칙하이트맵은 Janseon.Core에 — 오르막 +1AP, 고지 원거리 사거리 +1 (BB 문법)
UI 스택uGUI(Canvas) + TextMeshPro. UI Toolkit 금지 (기존 UXML/USS 교체)
UI 구조풀스크린 게임뷰 + 오버레이 — 뷰포트/컬럼 분할 금지, 유닛 정보 월드 부착, 툴팁은 대상 앵커
POC 범위3역 × B1+B2. 신도림 B2 침수→정산 확보. 지상·건물·B3 비목표

3 · 재질 시스템: 잔선 비상운영판

폐쇄역 운영 표지판·정비 단말·승차권이 비상전력으로 연결된 은유. interfaceingame 24장에서 도출한 13개 문법 규칙 기반 — 웹 룩(플랫 카드·rounded-2xl·부유 그림자·pill) 금지.

요소규격
금속 패널반경 0 · 우상/좌하 8px 45° 컷 · 외곽 2px 강철 + 2px 안쪽 1px 접합선 · 한 대상 한 외피 + 내부 분할선(카드 나열 금지)
명령 버튼≥168×54 · 4px 컷 · 상단 밝게/하단 어둡게 베벨 · 내장 키캡(28×24) · 불가=사선 해치+사유 유지
HP/AP트록 18px+2px 틀 · HP=연속+1px 노치+수치 · AP=이산 셀 · 빈 트록 잔존
초상 홀더96×112 + 4px 매트 + 이름판 + 우상단 22px 상태 아이콘 + HP 부착 · 아트 없어도 동일 프레임 실루엣(art-blocked 라벨 금지)
툴팁소유 대상에 8px 부착 + 연결선 · 제목→종류→비용/효과 · "왜 불가?" 직접 사유 (CK3 문법)
정산 승차권밝은 종이+금속 클립+펀치+절취선 · result-id가 아니라 ±증감·후유증·세계 변화
전장 레이어이동=route-A / 공격=danger 사선 / 위협=warn / 선택=focus 브래킷 — 색+형태 이중 코딩
지도연결 4px 실선 / 미리보기 6px+목적지 브래킷 / 불가 2px 점선 · 현재 토큰≠목적지 표시

4 · 승인된 목업 v4 — 풀스크린 월드 + 오버레이

화면 1 목업 원본 열기 — 생성 캡처 대신 공유 HTML 원본을 참조한다.

1 · 거점 준비(영등포 B1) — 풀스크린 월드. 좌하단 파티 스트립(초상 홀더·HP 노치바), 우하단 임무 콘솔, 부상 콜아웃은 초상에 직접 부착, 월드 내 역명 명판+파티 토큰, 상단 자원 스트립(카드 없음)+층 칩 B1.

화면 2 목업 원본 열기 — 생성 캡처 대신 공유 HTML 원본을 참조한다.

2 · 원정 지도 — 노선 연결 4px / 신도림 미리보기 6px+목적지 브래킷(route-B) / 구로 2px 점선 도달불가. 콘솔: 경로·비용(−2)·예상 조우·B2 침수 상태. "왜 불가?" 콜아웃이 구로 노드에 앵커. 현재 위치는 채운 토큰으로 목적지와 구분.

화면 3 목업 원본 열기 — 생성 캡처 대신 공유 HTML 원본을 참조한다.

3 · 조우 — 하단 중앙 이벤트판이 월드 씬(승강장·순찰대) 위에 오버레이. 상대 초상+상황+3 선택 행이 한 외피의 내부 분할(카드 아님). 각 행: 비용·효과·위험 표시 — 선택만으로 비용 없음, 확정 1회.

화면 4 목업 원본 열기 — 생성 캡처 대신 공유 HTML 원본을 참조한다.

4 · 전투(신도림 B2) — 풀스크린 5×5 하이트맵(승강장 단 h+1). 유닛 이름+HP 바가 월드에 부착(BB식). 상단 페이즈판, 좌측 순서 레일(AP 포함), 대상 옆 공격 예상 콜아웃(피해 −5·고도 보정 +1 사거리·반격·AP 후), 우하단 명령 콘솔(스킬 소켓·HP/AP·확정/취소/대기). 지형 정보: 이동 2AP·사거리 +1. 이동(청)/공격(적)/위협(황) 레이어 분리.

화면 5 목업 원본 열기 — 생성 캡처 대신 공유 HTML 원본을 참조한다.

5 · 정산 — 월드(확보된 승강장) 지속 + 우측 승차권 영수증: 승패·자원 증감(±)·인물 후유증(중상 HP 3/10 → 다음 원정 이행)·세계 변화(구로 도달 가능). 파티 스트립 상태 동기화.
