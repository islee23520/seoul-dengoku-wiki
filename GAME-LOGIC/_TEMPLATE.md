# 문서 제목

이 문서는 `docs/game-logic`에 새 페이지를 등록할 때 쓰는 템플릿입니다. 상단 YAML에서 `domain`을 `design`(기획서), `world`(세계관), `rules`(게임로직) 중 하나로 고르고, 제목과 한 줄 요약을 채운 뒤 본문을 작성합니다. 파일 이름 접두 규칙에 없는 문서도 `domain` 태그가 있으면 문서 사이트에 올라갑니다.
