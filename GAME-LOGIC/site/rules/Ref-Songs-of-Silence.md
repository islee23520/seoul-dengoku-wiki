## 1. 개요

- **장르 정체**: 스토어 장르 태그는 Adventure·Indie·RPG·Simulation·Strategy. 싱글 캠페인 8맵, 온라인 PvP·협동, 풀 컨트롤러 지원, 난이도 조절·마우스 전용·시간제한 입력 없음 접근성 옵션. 메타크리틱 81, Steam 추천 2,362건(2026-09-07 조회). [S-01][문서]
- **두 층 구조**: 넓은 4X 층(격자 없는 지도에서 군대 이동·정착지 점령·업그레이드·시야 개방)과 좁은 교전 층(RTS식 자동 전투, 일시정지 후 카드 사용, 한쪽이 궤주·전멸할 때까지). [S-03][문서]
- **자동 전투의 정의**: 전투가 시작되면 부대는 자동으로 싸우고, 플레이어는 개별 유닛을 조작하지 않는다. 대신 **전투 전 편성·배치**와 **전투 중 카드 타이밍**이 입력이다. 자동 해결(auto-resolve)은 없다. [S-02][S-04][문서]
- **세 세력**: 문화·외교·교역 / 신성 정복·무용 / 기술·실험. 세력 정체성이 이야기 사건·유닛·영웅 카드 설계에 스며 있다. [S-05][문서]
- **비판 지점**: 카드가 사소해 전투 결과가 **전투 전 수치·위치 우위**로 거의 정해진다는 평(Game8), 중반 페이스 지연·AI 반복성·카드 랜덤 드로우가 계획을 희석한다는 평(Drastik). [S-03][S-05][문서]

## 2. 코어 루프

1. **지도 턴**: 군대를 이동해 정착지를 점령하고 경제·모집을 키운다. 정착지는 전문화(성벽 유무·수비대 생성)와 자원 산출률이 다르다. [S-02][문서]
2. **거점 관리**: 우호 거점 안에서 유닛 구매, 베테랑 업그레이드, **예비대**(동행하되 전투에 불참) 관리, 수비대 배정. [S-03][문서]
3. **접촉 → 편성**: 적 부대를 공격하기 전에 아군 배치를 재정렬한다(적 우익이 보병을 잡아먹는 괴수라면 기병을 맞세우는 식). [S-02][문서]
4. **실시간 자동 전투**: 일시정지 가능. 영웅 카드로 기병 돌격·치유·소환·광역 피해·상태 효과를 건다. [S-03][S-04][문서]
5. **정산과 성장**: 영웅은 매 교전 후 복귀(소모품이 아님), 레벨업으로 카드가 강화·해금된다. [S-03][문서]

결정 지점은 세 곳 — **지도에서 어디를 칠 것인가, 전투 전에 누구를 어디에 세울 것인가, 전투 중 어느 카드를 언제 낼 것인가**. [추론]

## 3. 4X 층

- **자원 3종**: 골드(모집), 자재(주로 건설), 세력 고유 마법 자원. [S-02][문서]
- **정착지 1건물**: 정착지마다 건물 하나만 세우며, 건설 가능 목록은 **영웅 레벨업으로 해금**한 유형에 종속된다. [S-02][문서]
- **경량 4X**: 4X·TBS 어느 것보다 단순하다는 평. 확장은 "제국 건설"보다 **고립 지역 통제** 위주(Game8이 약점으로 지적). [S-02][S-03][문서]
- **지도 옵션**: 크기 S/M/L, 배치 2종(1-sided …). [S-01][문서] 정확한 배치 종류명은 스토어 텍스트가 잘려 [미확인].
- **탐사 보상**: 8개 캠페인 맵이 매우 크고, 지도의 절반을 건너뛰어도 승리 가능 — 샛길의 정착지·전승·유물이 탐사 동기. [S-02][문서]
- **매복**: 위키 요약은 "치명적인 매복 설치"를 특징으로 든다. [S-06][문서(스니펫)] 구체 규칙은 [미확인].

## 4. 유닛 모델 — 두 수치와 특성

- **기본 수치 2개**: HP와 **파워(power)**. 파워 하나가 공격력과 방어력을 겸한다. [S-02][문서]
- **특성이 나머지를 결정**: Armor(피해 전부를 회피할 확률), Annihilate(한 타격에 1 이상의 피해), 대상별 Slayer 특성, 보병을 먹어 회복하는 괴수, 돌격 기병, 원거리 소환사·마법사, 피해 편향 등. [S-02][S-03][문서]
- **설계 철학**: "토탈 워를 20개 스탯 대신 2개 스탯으로 하고 특성이 나머지를 처리하는 것" — 의미 없는 스탯 줄 대신 특성 조합으로 깊이를 낸다. [S-02][문서]
- **로스터 규모**: 100종 이상 유닛. [S-06][문서(스니펫)]
- **영웅**: 고유 능력·카드 보유, 교전 후 항상 귀환, 레벨업 시 카드 강화. [S-03][문서]

## 5. 진형과 실시간 전투

- **배치가 입력**: 전투 전 부대 재정렬이 플레이어의 주된 전술 행위. 좌우익·전면 편성으로 적 조합에 대응. [S-02][문서]
- **실시간 진행 + 일시정지**: 전투 중 일시정지해 명령(카드)을 낸다. 편성 관리도 실시간이라는 표현(Drastik). [S-03][S-05][문서]
- **종료 조건**: 한쪽이 **궤주(routed)** 또는 전멸. 도망치는 궁병을 보병이 쫓는 데 시간이 걸릴 수 있다. [S-02][S-03][문서]
- **회복 경제**: 전투 중 카드로 되살리거나 치유한 병사는 정착지 보급(드문 기능)이나 유료 전략 카드 없이 대열에 복귀한다 — 카드가 곧 병력 보존. [S-02][문서]
- 진형의 격자 형태·열 수·부대 슬롯 수는 [미확인].

## 6. 카드 시스템

- **카드의 정의**: 덱 구축·핸드 드로우가 아니라 **영웅과 장소가 부여하는 고유 행동**. 캠페인 지도 또는 실시간 전투에서 부대 명령·상태 효과·직접 피해로 결과에 개입한다. [S-06][문서(스니펫)]
- **두 맥락**: 전략 카드(지도 — 군대 강화, 구조물 건설, 유닛 모집), 전술 카드(전장 — 광역 피해, 전 기병에게 특정 지점 돌격 명령 등). "조금이라도 대등한 전투에서는 카드가 승리의 열쇠". [S-02][문서]
- **재충전**: 로렐라이의 Divine Spark(치유·부활)는 재충전 타이머가 허용하는 한 여러 번 사용. [S-02][문서]
- **트리거 카드**: 앞선 능력 사용 후에만 발동하는 조건부 카드가 장기 시너지를 보상. [S-05][문서]
- **랜덤성**: 카드 드로우에 무작위성이 있어 콤보가 불발될 수 있다는 평. [S-05][문서] 드로우 규칙·핸드 크기·비용 자원은 [미확인].
- **평가의 양면**: "각 영웅이 다르게 느껴지는 가장 즐거운 부분"(indiegames.wtf) vs "카드가 사소해 전투가 정적"(Game8). [S-03][S-04][문서]
- 개발 일지 #1 「Cards of Faith」(2023-04-16, ModDB/Steam)가 카드 체계의 1차 출처이나 이번 조사에서 본문 열람이 차단됐다. [S-08][미확인]

## 7. 캠페인·진행

- 8개 스토리 캠페인 맵, 3단계 난이도(이야기 모드 캐주얼 ~ 상위 난이도 전용 도전과제·퀘스트), 사이드 퀘스트·비밀. [S-01][문서]
- 분기 경로·세력 엔딩·영웅 관계가 초반 결정으로 크게 달라지고, **New Game+**로 카드·업그레이드·대체 분기 이월. [S-05][문서]
- 콘텐츠 해금이 도전과제에 묶여 초반 선택지가 제한된다는 불만. [S-05][문서]
- 튜토리얼은 시스템을 점진적으로 풀어 4X 비숙련자도 진입 가능. [S-04][문서]

## 8. 잔선 적용 기록 (소유자 방향 2026-09-07, 결정 11로 대체)

아래 판단은 2026-09-07 카드 전투 POC의 채택 기록이다. 작품 사실은 유지하지만 카드·4방향 진형·재충전·항복 수치를 현재 제품 목표로 승격하지 않는다.

| Songs of Silence | 잔선에서의 형태 | 판단 |
|---|---|---|
| 지도 턴 + 실시간 자동 전투 두 층 | 전략 노선도·역간 여행은 확정 명령 단위, 전투는 실시간 틱 시뮬레이션 | 채택 — 세 표면 구조 유지 |
| 두 수치(HP·파워) + 특성 | 인물 스탯은 유지하되 **전투 판정은 소수 파생 수치 + 특성**으로 압축 | 채택 후보 — 라벨렌식 9스탯 공식과 비교 후 결정 |
| 전투 전 배치 = 주 입력 | 진형 편집(전열·후열·측면, 4방향 정면)이 출격 준비의 핵심 화면 | POC 채택 기록 · 현 목표 비채택 |
| 영웅·장소 카드, 전략/전술 두 맥락 | **인물 카드**(관계·생업·특기)와 **거점 카드**(보급·통행권·설비) | POC 채택 기록 · 현 목표 비채택 |
| 일시정지 후 카드 | 일시정지 허용, 카드 플레이는 틱 스탬프 명령으로 원장에 기록 | POC 채택 기록 · 현 목표는 부대 명령 |
| 카드 부활·치유 = 병력 보존 경제 | 부상 이행 계약과 충돌 — 잔선은 **쓰러짐 방지·후송**까지만 | 부분 채택 |
| 궤주 종료 | 사기 붕괴 → 궤주·항복(라벨렌 3조건과 결합) | POC 채택 기록 · 수치 결합은 현 목표 비채택 |
| 카드 랜덤 드로우 | 채택하지 않음 — 카드는 부여·재충전형, 드로우 없음 | POC 비교 기록 |
| 자동 해결 없음 | 소규모 조우는 예측 표시 후 즉시 정산 허용 | 부분 거부(시간 = 비용 원칙) |
| 경량 4X(자원 3종·정착지 1건물) | 16국 노선 경제는 이미 별도 설계 — 4X 골격은 유지하되 단순화 정도는 별도 결정 | 보류 |
