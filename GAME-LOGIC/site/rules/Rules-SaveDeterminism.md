# 저장과 결정성 규칙

> 출처: docs/game-logic/Save-and-Determinism.md — 계약 수치는 구현 상수를 우선한다.

## 개요

같은 시작값과 선택 기록은 같은 세계와 같은 사건 검사값을 강제한다.
난수는 전투·조우·세계 사건으로 가른다.
저장은 원장과 전투 중간 지점을 담되 검사값 확인 뒤에만 원본과 바꾼다.

## 핵심 수치

| 항목 | 값 | 비고 |
|---|---|---|
| 재현 입력 | 시작값과 선택 기록 | 세계 상태와 사건 기록의 검사값이 같아야 함 |
| 난수 스트림 | 전투, 조우, 세계 사건 | 쓰임새별 분리 |
| 성명 난수 | 인물 스트림만 | 다른 스트림을 쓰지 않음 |
| 원장 기록 | 원인 ID와 명령, 세계 시간, 변경 주체와 대상, 변경 전후 요약 해시, 규칙과 콘텐츠 버전 | 모든 상태 변경 |
| 인물 행위 | 면담·거래·후계 지지 | 미시 줄. 합이 임계를 넘을 때 세계 사건 |
| 저장 내용 | 판본이 붙은 세계 상태, 명령·사건의 위치, 콘텐츠 판본, 진행 중인 전투의 중간 지점 | |
| 원자 쓰기 | 임시 파일에 쓴 뒤 검사값 확인, 원본과 교체 | |
| 거부 조건 | 지원하지 않는 버전, 잘린 파일, 잘못된 체크섬 | 명확한 오류. 이전 백업 보존 |
| 전투 저장 시점 | 전투 컨텍스트 발행 전, 전투 상태와 수락된 명령 기록이 함께 확정된 체크포인트, 결과 정산 완료 뒤 | 새 턴·저장 주기를 만들지 않음 |
| 체크포인트 내용 | 불변 전투 컨텍스트, 일시정지·재개 상태, 결정론적 수락 순서가 붙은 명령 기록, 정산 영수증 | |
| 중간 저장 읽기 | 저장된 불변 컨텍스트와 수락된 전투 명령 기록 | 캠페인을 다시 조회하지 않음 |

## 조항

### RSAVE-01 재현 계약

같은 시작값과 선택 기록으로 다시 돌리면 같은 세계 상태가 나온다.
사건 기록의 검사값도 같아야 한다.

### RSAVE-02 난수 스트림

무작위 값은 전투, 조우, 세계 사건처럼 쓰임새별로 나눈다.
한 스트림이 다른 스트림의 결과를 대신하지 못한다.

### RSAVE-03 교차 오염

한 시스템의 처리 순서가 다른 시스템의 결과를 흔들지 못하게 한다.
순서 의존으로 난수를 공유하지 않는다.

### RSAVE-04 원장 의무

모든 상태 변경은 사건 원장에 기록한다.
원장 없는 변경은 인정하지 않는다.

### RSAVE-05 원장 항목

원장은 원인 ID와 명령을 적는다.
세계 시간과 변경 주체와 대상이 빠지면 무효다.
변경 전후 요약 해시와 규칙·콘텐츠 버전을 함께 붙인다.

### RSAVE-06 원인 설명

원장으로 노선 봉쇄의 원인을 설명한다.
물가가 오른 까닭도 원장에서 읽는다.
인물이 세력을 떠난 이유를 원장 밖 추측으로 메우지 않는다.

### RSAVE-07 인물 미시 줄

면담·거래·후계 지지는 인물 미시 줄로만 남긴다.
그 줄을 세계 사건으로 바로 올리지 않는다.

### RSAVE-08 임계 승격

미시 줄의 합이 임계를 넘을 때 세계 사건이 된다.
임계 미만을 세계 사건으로 승격하지 않는다.

### RSAVE-09 성명 난수

성명을 고르는 난수는 인물 스트림만 쓴다.
다른 스트림으로 성명을 고르지 않는다.

### RSAVE-10 저장 내용

저장 파일에는 판본이 붙은 세계 상태를 담는다.
명령·사건의 위치와 콘텐츠 판본이 빠지면 안 된다.
진행 중인 전투의 확정 체크포인트도 저장 대상이다.
체크포인트에는 불변 전투 컨텍스트, 일시정지·재개 상태, 결정론적 수락 순서가 붙은 명령 기록과 정산 영수증을 담는다.

### RSAVE-11 원자 쓰기

쓰기는 임시 파일에서 시작한다.
검사값을 확인한 뒤에만 원본과 바꾼다.

### RSAVE-12 거부

지원하지 않는 버전은 조용히 읽지 않는다.
잘린 파일도 잘못된 체크섬도 조용히 읽지 않는다.

### RSAVE-13 오류와 백업

거부하면 명확한 오류를 반환한다.
이전 백업은 보존한다.

### RSAVE-14 전투 저장 시점

전투 컨텍스트 발행 전이 저장 허용 지점이다.
전투 상태와 수락된 명령 기록이 함께 확정된 체크포인트에서도 저장한다.
결과 정산 완료 뒤에 다시 연다.
저장은 실시간 전투에 턴이나 새 시간 간격을 만들지 않는다.

### RSAVE-15 중간 저장 읽기

중간 저장을 읽을 때 캠페인을 다시 조회하지 않는다.
저장된 불변 컨텍스트와 수락된 전투 명령 기록을 복원한다.
일시정지 중 확인된 교체 명령은 재개 뒤 다음 시뮬레이션 스텝에서 같은 수락 순서로 적용한다.

### RSAVE-16 전투 상태 연속

저장 뒤에도 부대의 논리 위치, 정면, 현재 지시와 일시정지·재개 상태가 이어진다.
같은 체크포인트와 수락된 명령 기록은 같은 결과와 검사값을 내야 한다.

## 판정 순서

1. 시작값과 선택 기록을 고정한다.
2. 난수 스트림을 전투·조우·세계 사건으로 가른다.
3. 성명 난수는 인물 스트림만 연다.
4. 상태 변경마다 원인 ID와 명령, 세계 시간, 주체와 대상, 전후 해시, 규칙·콘텐츠 버전을 원장에 적는다.
5. 면담·거래·후계 지지는 인물 미시 줄로만 남긴다.
6. 미시 줄의 합이 임계를 넘으면 세계 사건으로 올린다.
7. 저장 내용은 판본 세계 상태, 명령·사건 위치, 콘텐츠 판본, 불변 전투 컨텍스트, 일시정지·재개 상태, 수락 순서가 붙은 명령 기록과 정산 영수증으로 한정한다.
8. 임시 파일에 쓰고 검사값을 확인한다.
9. 확인된 뒤에만 원본과 바꾼다.
10. 지원하지 않는 버전, 잘린 파일, 잘못된 체크섬은 거부하고 오류를 반환한다.
11. 이전 백업을 보존한다.
12. 전투 저장은 컨텍스트 발행 전, 상태와 수락 명령이 함께 확정된 체크포인트, 정산 완료 뒤에만 연다.
13. 중간 저장 읽기는 저장된 불변 컨텍스트와 수락된 전투 명령 기록만 복원한다.
14. 부대의 논리 위치·정면·현재 지시와 일시정지·재개 상태가 저장 전과 같은지 대조한다.
15. 일시정지 중 확인된 교체 명령이 재개 뒤 다음 시뮬레이션 스텝에서 같은 순서로 적용되는지 대조한다.

## 금지 사항

- 같은 시작값과 선택 기록이 다른 세계 상태를 내는 일
- 같은 기록이 다른 사건 검사값을 내는 일
- 한 시스템 처리 순서가 다른 시스템 결과를 흔드는 일
- 난수 스트림을 섞어 쓰는 일
- 원장 없이 상태를 바꾸는 일
- 원장 항목을 빠진 채로 확정하는 일
- 인물 행위를 임계 전에 세계 사건으로 올리는 일
- 성명 난수에 인물 스트림 이외를 쓰는 일
- 검사값 확인 전에 원본을 바꾸는 일
- 지원하지 않는 버전을 조용히 읽는 일
- 잘린 파일을 조용히 읽는 일
- 잘못된 체크섬을 조용히 읽는 일
- 이전 백업을 버리는 일
- 중간 저장을 읽을 때 캠페인을 다시 조회하는 일
- 저장 뒤 부대의 논리 위치·정면·현재 지시나 일시정지·재개 상태를 다시 굴리는 일
- 저장을 실시간 전투의 새 턴 종료 규칙이나 시간 간격으로 만드는 일
- 수락된 교체 명령의 결정론적 순서를 잃는 일
