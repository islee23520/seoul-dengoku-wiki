# 세력과 외교, 전쟁과 공성 규칙

> 출처: docs/game-logic/Factions-and-Diplomacy.md, docs/game-logic/Warfare-and-Sieges.md — 계약 수치는 구현 상수를 우선한다.

## 개요

세력 정치는 호감도 하나가 아니다.
개인 신뢰와 대중 평판과 지역별 정통성과 이행 가능한 약속과 집단 불만의 그래프로 관계를 읽는다.
전쟁은 병력 수 비교가 아니라 접근로와 보급과 사기와 퇴로와 점령 후 유지 능력을 둘러싼 연속 과정이다.

## 조항

### RWARFARE-01 정치는 그래프다

호감도 하나로 외교를 접지 않는다.
개인 신뢰와 청중별 평판과 근거별 정통성과 이행 가능한 약속과 집단 불만의 그래프로 판정한다.

### RWARFARE-02 신뢰 T

신뢰 `T[A,B]`의 범위는 -100~100이다.
기본값은 0이다.
개인과 기관 사이 협조는 이 값에서 읽는다.

### RWARFARE-03 평판 R

평판 `R[F,a]`의 범위는 -100~100이다.
기본값은 0이다.
청중별 공개 평가만 이 축에 남긴다.

### RWARFARE-04 정통성 L

정통성 `L[F,n,k]`의 범위는 0~100이다.
현지 신규 주장은 20으로 연다.
식량·전력·안전 같은 근거별 승인이 이 값에 묶인다.

### RWARFARE-05 정치 자본 PC

정치 자본 `PC`의 범위는 0~100이다.
기본값은 0이다.
회의와 보증과 연합 행동의 비용으로만 쓴다.

### RWARFARE-06 불만 결속 지렛대

불만 `G`와 결속 `C`의 범위는 0~100이고 기본값은 0이다.
지렛대 `V`의 범위는 0~1이고 기본값은 0이다.
결속은 집단 행동을 조직하는 능력이고 지렛대는 상대를 강제할 실질 수단이다.

### RWARFARE-07 이행 신뢰도 Rel

`Rel = clamp(1 - 0.50*부족 - 0.30*고립 - 0.40*과확장, 0, 1)`이다.
범위는 0~1로 가둔다.
제안 수용과 계약 위험은 이 값에서 읽는다.

### RWARFARE-08 신뢰 갱신

`신뢰변화 = clamp(sum(사건영향 * 신빙성), -25, 25)`이다.
`T' = clamp(T + 신뢰변화 + 기준선이동, -100, 100)`으로 덮는다.
한 번의 사건으로 -25 아래나 25 위를 직접 밀어내지 못한다.

### RWARFARE-09 압력 산식

`압력 = clamp(0.45*불만 + 0.35*결속 + 0.20*(100*지렛대), 0, 100)`이다.
불만과 결속은 0~100이고 지렛대는 0~1이라 100을 곱해 같은 척도로 맞춘다.
압력의 범위는 0~100이다.

### RWARFARE-10 불가능한 약속

모든 제안은 먼저 실제 경로와 물자와 권한과 배타 계약 충돌을 검사한다.
불가능한 약속은 높은 교섭 능력으로 통과시키지 못한다.

### RWARFARE-11 회의 비용

일반 회의는 5 정치 자본이다.
긴급 심의는 10 정치 자본이고 연합 전체 안건은 20 정치 자본이다.
세 비용 모두 0~100 안에 가둔다.

### RWARFARE-12 정치 자본의 한계

정치 자본 지출은 신뢰나 정통성을 직접 바꾸지 못한다.
그 값은 지출이 뒷받침한 행동의 기록된 결과로만 바뀐다.

### RWARFARE-13 강제 요구 문턱

조직화 압력은 40이고 위기 압력은 70이다.
강제 요구 지렛대는 0.75다.
압력 70 이상과 지렛대 0.75 이상이 2주 연속일 때만 파업·봉쇄·분리를 연다.

### RWARFARE-14 협약 재검토

일반 협약 재검토의 기본은 3주다.
범위는 1주~12주다.

### RWARFARE-15 고립과 정통성

고립은 외부 약속만 약화시킨다.
현지 통치의 정통성을 자동으로 깎지 않는다.

### RWARFARE-16 후계와 동시 제안

후계자가 바뀌면 개인 약속과 제도 약속을 구분해 재검토한다.
새 후계의 성명은 후계·이름 로스터·세계 원장을 따른다.
동시 제안은 같은 주간 스냅샷으로 평가한 뒤 명령 ID 순서로 정산한다.

### RWARFARE-17 Rel 검산

부족 0.30 고립 0.40 과확장 0.50이면 감점은 0.15와 0.12와 0.20이다.
`Rel=clamp(1-0.15-0.12-0.20,0,1)=0.53`이다.
신뢰 60이어도 실제 배송 성공률이 53%면 장기 전력 공급 협약은 거부되거나 담보·단계 이행이 붙는다.

### RWARFARE-18 압력 검산

불만 80 결속 60 지렛대 0.8이면 `압력=clamp(0.45*80+0.35*60+0.20*(100*0.8),0,100)=73`이다.
지렛대 0.75 이상과 함께 2주 연속이면 강제 요구가 열린다.
실패 원인이 제3자 봉쇄이고 사전 통보했다면 신빙성 계수로 신뢰 손실을 줄인다.

### RWARFARE-19 전쟁의 축

전쟁은 병력 수 비교가 아니다.
접근로와 보급과 사기와 퇴로와 점령 후 유지 능력의 연속 과정으로 푼다.
공성 접근로와 보급과 퇴로는 4방향 시야와 공간으로 계획한다.

### RWARFARE-20 전력과 결속

전력 `S`의 범위는 0~100이고 기본값은 100이다.
작전 결속 `C`의 범위는 0~100이고 기본값은 70이다.
전력은 전투 가능 인원·장비이고 결속은 대형 유지와 철수 통제다.

### RWARFARE-21 보급일과 피로

보급일 `D`의 범위는 0~6이고 기본값은 3일이다.
피로 `F`의 범위는 0~100이고 기본값은 0이다.
보급일은 작전 지속 기간이고 피로는 전투 효율과 패주 손실에 붙는다.

### RWARFARE-22 접근 용량과 엄폐

접근 용량 `A`의 범위는 1~3이고 기본값은 2파티다.
방어 엄폐 `V`의 범위는 0~30이고 기본값은 10이다.
압박 `P`와 돌파 `B`의 범위는 0~100이고 기본값은 0이다.

### RWARFARE-23 전투 계수

`피로계수 = clamp(1 - F/200, 0.5, 1)`이다.
`적재계수 = clamp(1 - max(0, 적재율-80)/100, 0.8, 1)`이다.
전투는 시작 시 확정된 전투 컨텍스트만 쓰고 종료 결과는 `ResultId`로 한 번만 캠페인에 반영한다.

### RWARFARE-24 압박 증가

`압박증가 = clamp(6 + floor((공격작전력-수비작전력)/20) - 고립, 1, 12)`이다.
압박 일일 증가 기본값은 6이고 범위는 1~12다.
고립은 정상 0 부분 봉쇄 1 완전 차단 2이며 물류 문서를 그대로 쓴다.

### RWARFARE-25 패주와 주둔

`패주손실 = clamp(15 + 5*고립 + floor(F/10), 15, 35)`이다.
`주둔요구 = clamp(20 + 10*적대접근로수 + floor(5*과확장), 20, 80)`이다.
과확장은 물류의 공유 0~2 척도를 그대로 가져온다.

### RWARFARE-26 부가 손실

위험 추가 손실의 기본값은 0이고 범위는 0~4다.
철수 피로는 +15이며 범위는 0~100이다.
점령 직후 치안은 20이고 범위는 0~100이다.

### RWARFARE-27 무보급

탄약과 식량을 묶은 보급일이 0이면 전투 계수는 0.60이다.
다음 무보급 공성일을 지속하지 못한다.

### RWARFARE-28 고립의 대가

고립은 압박 증가를 낮춘다.
철수·패주 손실은 커지고 점령지 수리는 막힌다.

### RWARFARE-29 퇴로 검사

퇴로가 봉쇄되면 질서 철수 대신 긴급 탈출이나 항복이나 패주만 남는다.
퇴로 그래프 검사 `LegalFallback`을 통과하지 못하면 패주손실을 적용한다.

### RWARFARE-30 점령의 한계

점령 승리는 시설 복구와 주민 협력을 자동 부여하지 않는다.
동시 공격은 접근 용량만큼만 완전 전력을 쓰고 나머지는 예비·지원으로 정산한다.

### RWARFARE-31 상태 전이

흐름은 접근에서 시작해 공격 명령이면 교전으로 압박 작전이면 봉쇄로 간다.
봉쇄는 `P>=40`과 `B` 누적에서 돌파로 넘긴다.
교전은 합법 퇴로가 있으면 질서철수 결속이 붕괴하면 패주다.

### RWARFARE-32 점령 이후

돌파에서 목표를 확보하면 점령이다.
점령 다음은 주둔·수리·협상의 안정화다.

### RWARFARE-33 작전 검산

공격 작전력 90 수비 작전력 78 고립 0이면 `압박증가=clamp(6+floor(12/20),1,12)=6`이다.
공격대 피로 40이면 피로계수는 `clamp(1-0.2,0.5,1)=0.8`이다.
같은 공격대가 고립 2 피로 70으로 패주하면 `패주손실=clamp(15+10+7,15,35)=32`다.

## 판정 순서

1. 실제 경로와 물자와 권한과 배타 계약 충돌을 먼저 검사한다. 불가능한 약속은 여기서 끊는다.
2. `Rel`을 `clamp(1 - 0.50*부족 - 0.30*고립 - 0.40*과확장, 0, 1)`로 구한다.
3. 신뢰변화와 `T'`를 자른 뒤 평판과 정통성을 같은 주간 스냅샷으로 읽는다.
4. 정치 자본 비용을 뺀다. 일반 회의 5 긴급 심의 10 연합 전체 안건 20이다.
5. 압력을 계산한다. 70 이상과 지렛대 0.75 이상이 2주 연속일 때만 강제 요구를 연다.
6. 동시 제안은 같은 주간 스냅샷으로 평가한 뒤 명령 ID 순서로 정산한다.
7. 공성 접근로와 보급과 퇴로를 4방향 시야와 공간으로 고정한다.
8. 시작 시 확정된 전투 컨텍스트만 쓴다. 보급일 0이면 전투 계수 0.60을 넣고 다음 무보급 공성일을 막는다.
9. 접근 용량 안에서만 완전 전력을 투입한다. 나머지는 예비·지원이다.
10. 압박증가와 피로계수와 적재계수를 적용한다. `P>=40`과 `B` 누적에서 돌파를 연다.
11. 합법 퇴로가 있으면 질서철수를 허용한다. `LegalFallback` 실패면 패주손실을 넣는다.
12. 종료 결과는 `ResultId`로 한 번만 캠페인에 반영한다. 점령 승리에 시설 복구와 주민 협력을 자동으로 붙이지 않는다.
13. 주둔요구를 계산하고 점령 직후 치안 20에서 안정화를 연다.

## 금지 사항

- 호감도 하나로 외교를 접지 말 것
- 불가능한 약속을 교섭 능력으로 통과시키지 말 것
- 정치 자본 지출로 신뢰나 정통성을 직접 바꾸지 말 것
- 압력 70과 지렛대 0.75가 2주 연속이 아닌데 강제 요구를 열지 말 것
- 고립으로 현지 정통성을 자동으로 깎지 말 것
- 후계 교체 때 개인 약속과 제도 약속을 한 덩어리로 덮지 말 것
- 동시 제안의 난수를 다시 굴려 순서를 바꾸지 말 것
- 병력 수 비교만으로 전쟁을 닫지 말 것
- 보급일 0에서 다음 무보급 공성일을 지속하지 말 것
- `LegalFallback` 실패를 질서철수로 처리하지 말 것
- 점령 승리에 시설 복구와 주민 협력을 자동 부여하지 말 것
- 접근 용량을 넘는 동시 공격에 완전 전력을 주지 말 것
- 전투 결과를 `ResultId` 없이 두 번 반영하지 말 것
- 설계 가정 수치를 구현 상수보다 앞세우지 말 것
- 고립 단계 0~2와 과확장 0~2를 다른 범위로 바꾸지 말 것
