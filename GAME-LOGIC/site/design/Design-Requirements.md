# 설계 요구 티켓

MDA 층은 설계 어휘다. 개발 단위는 GitHub 요구 티켓이다.

한 칸에는 그 요소가 무엇인지 적는다.

## 시야

시야와 카메라는 용사주식회사 채널의 2.5D 전투 화면을 따른다. 요구 티켓 [#97](https://github.com/islee23520/seoul-kenshi/issues/97).

## 전투 형태

전투 형태는 Songs of Silence와 같은 실시간 진형·카드 전투다. 수치 잠금은 [#77](https://github.com/islee23520/seoul-kenshi/issues/77)(닫힘). 분대 명령은 [#99](https://github.com/islee23520/seoul-kenshi/issues/99). 집계 생존수와 사상자는 [#100](https://github.com/islee23520/seoul-kenshi/issues/100).

## 카드 부여

인물의 생업·관계·직위가 카드와 지휘 반경으로 전투에 들어온다. 부여 규칙 요구 티켓 [#98](https://github.com/islee23520/seoul-kenshi/issues/98).

## 인물 POC

POC 사람 표현은 오드랜드 Spine이다. 실행 티켓 [#58](https://github.com/islee23520/seoul-kenshi/issues/58).

## 화면 목표

화면 목표는 `.omo/design/poc-complete.html` 열 면이다. 색인 [#101](https://github.com/islee23520/seoul-kenshi/issues/101). 보고서 `/ui-ux-refs/`.

## 시각 수용

타이틀은 [#8](https://github.com/islee23520/seoul-kenshi/issues/8). UI kit·아이콘·타일은 [#23](https://github.com/islee23520/seoul-kenshi/issues/23). 승격 슬롯은 [#26](https://github.com/islee23520/seoul-kenshi/issues/26). 수용 게이트는 [#27](https://github.com/islee23520/seoul-kenshi/issues/27).

## 구현 순서

아래 검증 단계는 시각 수용·슬롯 연결·시각 게이트를 끝내는 순서다. 그 다음이 분대 명령(#99)과 사상자 표현(#100)과 카드 부여(#98)다.
