ISSUE #101

현재 목표 설계와 역사 POC 레퍼런스

《서울:전국》의 현재 목표는 토탈워식 실시간 부대 지휘다. 이 페이지는 목표 설계와 과거 비교 자료를 구분하며, 새 전투의 구현을 뜻하지 않는다. #101의 화면 연구를 결정 11에 맞춰 읽는다.

TARGET

부대 지휘 · 현재 목표 계약

영웅은 별도 지휘 인물이며 병졸 수에서 제외한다. 병졸 한 분대는 최대 20명이다. 전체 분대 수·영웅 수·군단 상한은 정하지 않는다. 인물 중심 캠페인의 생업·관계·직위·후계와 역·노선 연결은 유지한다.

부대 선택 → 이동·공격·진형 방향·정지 → 미리보기 → 확인 또는 취소. 확인한 새 명령은 선택 부대의 현재 지시를 교체하고, 취소는 기존 지시를 유지한다. 확인된 지시만 수락 기록에 남긴다. 영웅 직접 액션, 카드·덱·드로우·재충전, 명령 큐·웨이포인트·감속·배속은 목표가 아니다.

닫힌 전투 결과는 ResultId별 정확히 한 번 반영한다. 결과 반영은 귀환 명령이 아니며 원정을 계속할 수 있다. 귀환·정착·정복·방랑·교역은 별개의 결말이다. 철수는 LegalFallback을 확인하는 명령, 패주는 비자발 이탈, 항복은 자발 선택이다. 막힌 퇴로만으로 항복을 지우지 않으며 포획은 별도 신병 결과다.

미술 목표는 애니메이션풍 정비율이다. 3D 자유 지휘 카메라(팬·오빗·줌)와 파티의 닫힌 전투만 일시정지하는 기능은 질문 무응답 뒤 채택한 설계 기본안이다. 정지 중 확인한 지시는 수락 순서에 남고 재개 뒤 다음 시뮬레이션 단계에 적용한다. 공유 세계와 다른 파티는 멈추지 않는다.

현재 Archify 설계: 목표 UI 템플릿 · UX 상태 전이 · 데스크톱 와이어프레임. 합성 목업의 목표 개정면. 모두 문서용 설계이며 실제 게임 렌더나 구현 증거가 아니다.
