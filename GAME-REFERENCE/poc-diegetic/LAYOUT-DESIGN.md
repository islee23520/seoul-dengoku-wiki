# UI 레이아웃 설계 상세

이 문서는 지금까지 확정한 레이아웃 설계를 한 장으로 정리한다. 근거는 루트 Design.md 계약, 무드보드(`../ui-layout-moodboard/`), 다이제틱 전환 문서(`./DIRECTION.md`)다. 화면을 유니티부터 짜지 않는다 — HTML 시안으로 검증한 값을 계약으로 잠그고 uGUI로 옮긴다.

## 전체 화면 구조

- 씬 순서는 Bootstrap(0) → MainTitle → Foundation(1)이고 씬 교체는 앱 FSM만 승인한다.
- 화면은 활성 lease당 Canvas 하나이고 모달 없이 같은 문서 안 패널 전환으로 단계를 표시한다.
- 대상 해상도는 1280×720과 1920×1080(16:9). 1080p에서 같은 비율 스케일을 유지한다.
- 키보드만으로 1차 액션 전부에 닿는다. 포커스는 신호 황 링으로 표시한다.

## 안정 요소 이름 체계

화면 요소는 `UiElementNames`가 단일 출처다. 목업 컨트롤과 유니티 이름이 일대일로 대응한다 — `main-title-root`·`main-title-start`, `stage-rail`·`route-rail`·`station-*`, `encounter-choices`·`choice-*`, `battle-hud`·`battle-grid`·`battle-cell-{x}-{y}`·`battle-play-pause`, `formation-edit-*`(슬롯·정면·확정·취소), `settlement-panel`·`return-action`. 스냅샷·테스트·캡처가 같은 이름 집합을 공유한다.

## 무드보드와 검증 자산

- `../ui-layout-moodboard/` — 11개 영역(시각 언어·앱 흐름·타이틀·캠페인·조우·전투·진형·지휘관 카드·정산·공간 문법·구현 파이프라인)의 자립형 무드보드. 동결 캡처·구현 캡처·위키 다이어그램만으로 구성했다.
- 이 문서의 수치는 무드보드 검증 당시 게이트(patina·금지어·경로 무결성·브라우저 렌더)를 통과한 값이다.

## 다이제틱 전환

2026-09-13 소유자 판정으로 표현층은 다이제틱 방향으로 갈아탄다 — 웹 카드·칩·스크롤 목록 문법을 폐기하고 UI를 세계 안 사물(관제 콘솔 계기·반발광 지도판·티커 프린터·클립 카드 랙)로 만든다. 구조 계약은 이 문서의 수치 그대로 산다. 앵커 시안은 `./battle-hud/index.html`(캡처 `./battle-hud/anchor-capture.png`), 방향 원칙은 `./DIRECTION.md`에 있다. 승인된 앵커를 기준으로 나머지 표면을 같은 언어로 펼친 뒤 동결 바를 교체한다.
