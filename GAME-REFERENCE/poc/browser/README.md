# 브라우저 POC 기록과 현재 목표

이 폴더의 실행 데모는 2026-09-07 진형·카드·격자 POC 기록입니다. 현재 제품의 시각·입력 기준이 아닙니다. 현재 목표와 와이어프레임은 [`GDD/system-design/total-war-ui/`](../../../GDD/system-design/total-war-ui/index.html)에 있습니다.

현재 목표는 토탈워식 부대 지휘입니다. 이름 있는 영웅은 병졸 수에 포함되지 않는 별도 지휘 인물이고, 병졸 한 분대는 최대 20명입니다. 영웅 직접 액션, 카드 자원, 4방향 격자와 강제 귀환을 채택하지 않습니다.

- 지휘관 카드 기록: `avatar-preview/`
- 4방향 진형 편집 기록: `formation-editor/`
- 카드 전투 미리보기 기록: `battle-preview/`
- 회수 캠페인 기록: `recovered-campaign/`

필그리미지 원본 아틀라스는 여기 없습니다. 로컬 검토 URL만 `avatar-preview/SOURCE-PROVENANCE.md`에 적혀 있습니다.
바이트 해시는 `SHA256SUMS`입니다. 목업을 고치면 해시를 다시 만들고 유니티 이식을 다시 대조합니다.
