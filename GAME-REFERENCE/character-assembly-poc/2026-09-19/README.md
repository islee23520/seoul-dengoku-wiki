# 캐릭터 조립 POC — 1차 라운드 실패 아카이브

Tripo GLB/FBX 남녀 머리·몸 소스에서 Blender 5.2.2로 베이스를 조립한 POC 산물 아카이브.
**1차 라운드는 원래 목표 달성에 실패했다. PR #168 병합은 실패 산물의 보존이며 생산 승인이나 검증 게이트 성립이 아니다.**
소유자 지도와 실제 목표 데이터로 남성 맨 베이스의 좌우 분석·조건부 대칭·접합부 조정·텍스처 연결성 개선까지는 성공했다. 그 성공은 구강과 안구가 비어 있는 상태에 한정되며, 최종 UV의 생산 품질을 뜻하지 않는다. 남성 구강 통합, 여성 베이스·조립·검증, 애니메풍 셰이더는 실패했다. 다른 메쉬에서의 자율 재현과 게이트 성립은 판단 불가다.

최신 판정과 2차 라운드 회고: [RETROSPECTIVE.md](../round2/RETROSPECTIVE.md). 아래 수치는 과거 측정 기록이며 전체 승인 근거로 사용하지 않는다.

## 이전 세션 완료 주장이 무효가 된 이유

1. **UV 감사 후처리 버그**: `uv_overlap_audit.audit()`의 겹침 항목은 딕셔너리인데, `unwrap_female_uv2.py`·`retry_male_uv.py`는 리스트/튜플만 받아 전 항목을 건너뛰었다. "비인접 겹침 0" 판정은 무효다. 뒤의 `review/package_blends.py`도 Blender 실제 삼각분할이 아닌 polygon fan을 사용하고, 인접면 겹침을 제외하며, 퇴화 여부를 `previous_claim_ok`에 합치지 않았다. `review/corrected-uv-audits.json`의 192/1,456/40,853은 그 알고리즘의 역사적 출력이다. 이를 실제 렌더 UV의 확정된 불량 개수로 재사용하지 않는다. native 삼각분할과 독립 fixture로 다시 검증해야 한다.
2. **통합 씬 배치 결함 (실측 확정)**: `review/scene-audit.json` — 남성 구강 파츠 전체(잇몸·치아·혀)의 세계 z중심이 0.256–0.316m(골반 높이)으로 측정됐다. 입 높이(~1.6m)가 아니라 다리 사이에 떠 있다. 원인: `build_integration_v2.py`가 X만 이동하고 소스 blend의 원래 좌표를 검증하지 않았다. 여성 머리 비율 과대·목 이행 불량, 여성 구강 파츠 미포함, 안구 위치 근사 추정치도 그대로다. 재열기 렌더: `review/final-front-reopened.png`.
3. **여성 구강 분리 미완료**: 729면을 34그룹으로 식별·태깅(`work/female-head-oral-groups.blend`)했으나 상/하 구강·혀 오브젝트화는 미수행.

## 디렉터리 구성

- `deliverables/` — 통합 씬(final-integration.blend, **시각 결함 있음**), 공용 안구 마스터
- `work/` — 선별 13개 중간 .blend (대칭·UV·색상·구강 단계별)
- `work/textures/` — 베이크 텍스처 (male 4096px, female 2048px + 소스 추출)
- `reports/` — 전 세션 검증 JSON/MD. **기존 ok/완료 필드는 각 검사의 범위와 신뢰성이 재입증되기 전 생산 승인 근거가 아니다.**
- `evidence/` — 선별 렌더 이미지 10세트
- `scripts/` — 측정·수리 스크립트 전체 (회귀 테스트 포함)
- `review/` — 이번 리뷰가 새로 만든 이식성 영수증·수정 감사·씬 실측·재렌더

## 이식성

`review/portable-blends.json`은 패킹 시도와 재열기 후 정점/면/쿼드 수 일치를 기록한다. 좌표·UV·재질·참조 경로의 동일성 전체를 검사한 영수증은 아니다. 검사 코드의 `OK`도 패킹 실패 목록이 아니라 인벤토리 일치만으로 정해져 있어, 그 상태값 하나로 자립형 파일을 승인할 수 없다.
