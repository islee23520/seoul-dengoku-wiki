# 고밀도 얼굴–저밀도 몸 접합 공정 계약

이 작업의 목적은 일체형 캐릭터를 얻는 데 그치지 않는다. 사용자가 의도적으로 제공한 서로 다른 밀도의 얼굴과 몸을 사람이 다루는 방식으로 접합하고, 그 과정을 측정·선택·개선할 수 있는 절차로 만드는 것이다. 이미 합쳐진 모델로 대체해 이 과제를 우회하지 않는다.

## 입력과 보존

- 얼굴과 몸의 원본, 성분 ID, 좌표계, 토폴로지·텍스처 해시를 유지한다.
- 얼굴의 높은 밀도는 보존할 디테일의 요구이다. 무조건 낮추거나 몸 전체를 무조건 늘리지 않는다. 접합부의 정점 간격·루프 방향·변형 범위를 측정해 국소 감소/증가/리토폴로지를 선택한다.
- 원본에 의도된 눈·입 개구부, 별도 구강 부품, 승모근·쇄골, 승인된 얼굴 크기를 구분한다. 이 구분은 개구부 개수만으로 추정하지 않는다.

## 후보 평가 순서

1. **필수 실패 검사:** 빈 메쉬, 비유한 좌표, 의도하지 않은 구멍, wire/중복/퇴화 면, 비정상 연결, winding 불일치, 보호 영역 훼손, 원본 부품 유실을 검사한다. 하나라도 실패하면 승인 후보가 아니다.
2. **형상 비교:** 영역별 기하 노말 불연속, 접힘, 엣지 길이·차수 분포, 면 왜곡, 원형 편차, 볼륨/실루엣, 텍스처·UV 품질을 측정한다. 지표 이름·단위·영역과 원본을 함께 기록한다.
3. **비교·라우팅:** 실패 원인에 맞는 수리 방법을 고른다. 정점 쌍의 틈은 국소 용접, 뒤집힌 연결은 방향 수정, 손상된 면 흐름은 국소 리토폴로지, 자연스럽지 않은 접합 곡면은 기하 역분석 기반 보정으로 구분한다. 형상 결함을 노말만 바꿔 숨기지 않는다.
4. **선택:** 먼저 필수 조건을 통과한 후보만 비교한다. 하나의 점수로 상쇄하면 안 되는 조건은 가중합에 넣지 않는다. 지표 간 우열이 충돌하면 Pareto 후보로 남기고 시각 검증 또는 사용자 선택으로 결정한다. 임의의 점수·가중치를 프로젝트 기준인 것처럼 만들지 않는다.
5. **최종 검사:** 선택한 후보가 최종 조립·분리 파츠·UV·재질·저장 후 재열기까지 목표를 충족하는지 확인한다. 중간 단계의 통과는 전체 완성 판정이 아니다.

## 조건부 대칭 복원

대칭 복원은 수리 방법 중 하나이지 모든 인체에 적용하는 기본 규칙이 아니다.

- 장식 없는 대칭 베이스처럼 **대칭이어도 되는 대상인지 먼저 확인**한다. 의도된 비대칭 조형·상처·장비·포즈는 보존한다.
- 좌우를 같은 좌표계·같은 영역·같은 지표로 감사한다. 어느 쪽이 더 정상적인지 미리 정하지 않는다.
- 한쪽이 형상과 구조 검사를 통과하고 반대쪽보다 적합할 때, 그 절반을 donor로 선택한다. 이번 사례의 왼쪽 성공은 일반적인 왼쪽 우선 규칙이 아니다.
- 복제 작업본에서 반대 절반을 제거하고 donor를 반사한다. 실제 몸 중심 평면과 origin을 확인하고, 중심선만 허용 오차 내에서 용접한다.
- 양쪽 모두 실패하면 먼저 수리한다. 좋은 목 지표가 같은 절반의 얼굴 구멍을 상쇄하지 않는다. 대상 영역을 나누는 경우 각 영역 donor와 연결 검증을 명시한다.
- 반사 후 중앙 seam, 면 방향, 대칭 편차, 성분 수, 보호 경계, 선택한 donor의 원형 보존을 재검사한다. UV는 좌우 중첩 없는 atlas로 다시 펼치고 텍스처를 재투영·보정한다.

## 역산과 점수의 한계

사용자 시범의 전후 대응 메쉬로 변위와 기하 노말 변화를 역산한다. 사후 적합 설명력과 수정 전 입력만 사용하는 예측력은 분리한다. 평가 영역과 실패 기준은 측정 전에 고정하며, 수리 결과를 보고 유리한 영역만 선택하지 않는다. 한 사례에서 배운 가중치·임계값은 새 사례 검증 전까지 잠정값이다.

현재 수학적 결과와 한계는 `Sculpt-Inverse-Analysis.md`에 있다. 자동 적용 후보는 그 검증에서 아직 불합격이며, 사용자 스컬트나 대칭 donor 선택을 대신하지 않는다.
