# 목 접합부 스컬트의 기하 역분석

## 결론

사용자가 수정한 왼쪽 목은 **토폴로지를 바꾸지 않고 정점을 국소적으로 재배치해, 접힌 면의 기하 노말을 연속적인 방향으로 정리한 결과**이다. 노말만 재계산한 작업도, 단순히 접합선 전체를 일정 강도로 수축시킨 결과도 아니다. 법선 방향 이동과 접선 방향 재배치가 모두 필요하다.

현재 데이터에서 유효한 최소 설명은 **위치마다 강도가 다른 국소 Laplacian 완화**이다. 최종 형상을 이용한 사후 역모델은 관측 변위 제곱합의 92.98%를 설명한다. 그러나 수정 전 형상만으로 예측한 모델의 공간 분할 검증 설명력은 64.84%이며, 아직 사용자 결과를 자동으로 재현했다고 판정할 수 없다.

이 분석은 메쉬를 수정하지 않았다. 브러시 경로를 눈으로 흉내 내는 시도는 중단했다.

정점 인덱스, 모서리 연결, 면의 정점 순서가 동일하므로 최근접 표면 매칭 없이 같은 인덱스끼리 정확히 비교한다. 원본 파일과 좌표의 해시는 `sculpt-inverse-source-receipt.json`에 있다. 위치·기하 노말·면적·이웃 관계는 `sculpt-inverse-data.npz`에 추출했다.

전체 변경 정점은 487개이고, 화면 기준 왼쪽은 421개이다. 왼쪽 변위 크기의 중앙값은 1.924 mm, 90백분위는 5.739 mm, 최대는 10.722 mm이다. Z < 1.50 m의 몸과 Z > 1.62 m의 얼굴 정점은 전후 이동량 0이다. 이 Z 구간은 이 파일 좌표계의 관측값이지 다른 캐릭터에 복사할 고정 임계값이 아니다.

## 2. 정점 이동이 기하 노말을 바꾸는 관계

수정 전후 정점을 각각 \(x_i,y_i\), 변위를 \(d_i=y_i-x_i\)라 한다. 삼각형으로 평가한 한 면에서

\[
a=x_j-x_i,\quad b=x_k-x_i,\quad
\delta a=d_j-d_i,\quad\delta b=d_k-d_i
\]

이며 비정규화 기하 노말 \(c=a\times b\)의 변화는 정확히

\[
\Delta c=\delta a\times b+a\times\delta b+\delta a\times\delta b
\]

이다. 최종 단위 노말은 \(n'= (c+\Delta c)/\|c+\Delta c\|\)로 결정된다. 마지막 항은 유한 변형의 2차 항이다. 변형된 유효 삼각형 1,094개에서 이 항의 크기는 전체 교차곱 변화 대비 중앙값 7.65%, 90백분위 28.94%였다. 심하게 접힌 곳은 작은 각도 선형 근사만으로 판단하면 부족하다.

이는 **정점 이동을 먼저 설명하고, 그 결과로 노말 변화를 계산해야 한다**는 뜻이다. 면 법선 자체를 독립된 손잡이처럼 조정하는 분석이 아니다. 쿼드 토폴로지는 그대로 유지하고, 삼각형 평가는 기하 계산에만 사용했다. 입력에 존재하던 퇴화 삼각형 13개는 이 노말 미분 통계에서 제외했으며 별도의 결함으로 남겼다.

## 3. 실제로 무엇이 줄었는가

접합 면의 이웃 그래프에서 10-hop 이내, 목 주변의 수정 전 좌표 범위로 분석 영역을 정했다. 전체 1,681개, 왼쪽 평가 정점 816개이며 변경된 왼쪽 421개를 모두 포함한다. 수치는 이 정의에서 계산했다.

| 기하 지표 | 수정 전 | 사용자 수정 후 |
|---|---:|---:|
| 왼쪽 접합 경계 각도 중앙값 | 13.64° | 4.28° |
| 경계 각도 90백분위 | 28.91° | 9.56° |
| 경계 최대 각도 | 157.08° | 15.47° |
| 영역 내 90° 초과 이면각 모서리 | 11 | 0 |
| 영역 내 면 winding 불일치 | 0 | 0 |
| 이산 Laplacian 제곱합 | 기준 | 57.35% 감소 |
| 이면각 제곱합 | 기준 | 74.53% 감소 |

따라서 국소 문제는 면 winding 오류보다 **심한 꺾임·접힘과 불균일한 정점 배치**였다. `90° 초과`는 급격한 접힘의 지표일 뿐, 그 자체로 자기교차 검출을 대신하지 않는다.

변위를 수정 전 단위 정점 노말 \(n_i\)에 대해 분해하면

\[
d_i^{\perp}=(d_i\cdot n_i)n_i,\qquad
d_i^{\parallel}=d_i-d_i^{\perp}
\]

이다. 변위 제곱합의 40.58%가 법선 성분, 59.42%가 접선 성분이다. 법선 성분은 대체로 안쪽 이동이며, 접선 성분 크기의 중앙값은 1.313 mm이다. 튀어나온 띠를 낮추는 동시에 이웃 정점 간 배치를 풀어준 효과가 관측된다. 접선 이동도 유한 이산 메쉬에서는 형상을 바꿀 수 있으므로 완전한 무변형 재매개화라고 부르지 않는다.

## 4. 역모델: 무엇까지 설명할 수 있는가

\(P\)를 메쉬의 정점 이웃 평균 연산자라 하면, 최종 형상의 이웃 방향은 \(u_i=(Py-y)_i\)이다.

스칼라 유효 완화계수는

\[
\hat\alpha_i=\max\left(0,\frac{d_i\cdot u_i}{u_i\cdot u_i}\right)
\]

로 역산한다. 이 모델 \(d_i\simeq\hat\alpha_i u_i\)의 변위 설명력은 87.31%이다. 최종 기하 노말로 \(u_i\)를 법선·접선 성분으로 나누고 두 계수를 각각 적합하면 92.98%로 높아진다. 변경 정점의 잔차 중앙값은 0.259 mm, 90백분위는 1.440 mm이다.

**이 숫자는 자동화 성능이 아니다.** 우변에 사용자가 만든 최종 형상이 들어가며, 정점마다 계수를 적합한 사후 설명이다. 브러시 종류·강도·순서·횟수를 유일하게 복원하지 못한다. 여러 다른 국소 연산이 같은 끝점 메쉬를 만들 수 있다. 계수가 클 때도 이를 브러시 강도나 실제 반복 횟수로 바로 해석하면 안 된다.

## 5. 수정 전 형상만 사용하는 후보 검증

기본 후보는 고정된 외곽을 두고 다음 선형계를 푼다.

\[
(I+\operatorname{diag}(\alpha)(I-P))\hat y=x
\]

구현에서는 분석 영역 밖 정점이 우변의 Dirichlet 경계항으로 들어간다. 영역 밖 이동량은 0이다. 초기 후보는 접합부에서의 그래프 거리로 \(\alpha\)를 줄였다.

개선 후보는 초기 불규칙성

\[
\rho_i=\frac{\|(Px-x)_i\|}{\text{평균 인접 모서리 길이}}
\]

를 사용해 국소 강도를 조절한다. 이는 같은 공간 크기라도 메쉬 밀도가 다를 수 있음을 보정하기 위한 무차원 지표이다. 큰 \(\rho\)가 항상 결함은 아니므로 자연스러운 근육·턱 경계에는 보호 영역과 추가 판정이 필요하다.

앞목·옆목·뒷목을 수정 전 좌표의 각도로 나눴다. 두 구역에서 강도·범위를 고르고 나머지 구역을 평가했다. 가까운 정점들을 무작위로 섞는 분할은 사용하지 않았다.

| 후보 | 공간 분할 변위 설명력 |
|---|---:|
| 일정 국소 explicit 이웃 평균 | 49.44% |
| 일정 국소 implicit 이웃 평균 | 51.27% |
| 초기 거칠기 적응 implicit 완화 | **64.84%** |

개선 후보의 구역별 위치 RMSE는 앞목 1.465 mm, 옆목 0.953 mm, 뒷목 1.998 mm이다. 이 메쉬에서 국소 범위와 강도를 조절하는 방향이 일정 필터보다 낫다는 증거이다.

하지만 실패 조건도 남는다.

- 앞목의 예측 최대 접합각은 37.47°로, 사용자 결과 15.47°보다 나쁘다.
- 사용자가 건드리지 않은 평가 영역도 최대 2.84 / 1.80 / 3.59 mm 움직였다.
- 이 모델로 사용자 메쉬를 덮어쓰지 않았다. 현재 자동 적용 판정은 **불합격**이다.
- 여러 후보 계열을 같은 예제에서 살펴본 탐색적 공간 검증이다. 새로운 캐릭터·새 접합부에서의 독립 검증은 아직 없다.

## 6. 검사 게이트에 반영할 내용

1. **대응성:** 전후 토폴로지 해시가 같아야 정점별 변위 역분석을 허용한다. 달라지면 같은 인덱스 비교를 중단한다.
2. **구조와 형태 분리:** boundary/winding/degenerate 검사는 구조 게이트이며, seam-angle/곡률/실루엣 검사는 별도이다. 앞 게이트 통과를 완성도 판정으로 쓰지 않는다.
3. **보존 영역:** 얼굴·승모근·쇄골 등 선언한 영역 밖의 이동을 실제 좌표로 검사한다. 이번 예제의 Z 숫자를 다른 모델에 하드코딩하지 않는다.
4. **기하 노말:** 면 winding 오류와 큰 이면각을 혼동하지 않는다. 접합 최대각·상위 분위·곡률 감소를 함께 기록한다.
5. **밀도와 위치별 강도:** 동일한 브러시 강도나 동일 횟수는 서로 다른 정점 밀도에 같은 결과를 내지 않는다. 길이 정규화와 국소 범위가 필요하다.
6. **거짓 성공 방지:** 사후 역적합 점수는 설명 근거로만 사용한다. 수정 전 입력만 사용한 예측, 보호 영역 이동, 미사용 사례 검증이 별도로 통과해야 자동 수리로 승격한다.

현재 게이트의 결과는 자동 수리 승인 대신 **어느 접합 구역에 추가 연구·검토가 필요한지** 반환해야 한다.

## 재현

```bash
/opt/homebrew/opt/python@3.14/bin/python3.14 \
  GAME-REFERENCE/character-assembly-poc/2026-09-19/scripts/analyze_sculpt_inverse.py
```

Python 3.14.3, NumPy 2.4.2, SciPy 1.17.1에서 실행했고 exit 0 및 `INVERSE_ANALYSIS_COMPLETE`를 확인했다. 결과는 `sculpt-inverse-analysis.json`이다. 추출 스크립트는 Blender의 `extract_sculpt_inverse_data.py`이며, 원본 장면은 열어 바꾸지 않고 라이브러리 데이터만 읽은 뒤 임시 데이터블록을 정리한다.

`validate_inverse_geometry.py`로 후보 좌표를 실제 Blender 5.2.2 BMesh의 메모리 복제본에 넣어 교차검증했다. 앞/옆/뒤 최대 경계각은 각각 37.475° / 11.025° / 8.920°로 독립 NumPy 계산과 일치했다. float32 좌표 변환 오차는 최대 8.39e-8 m, 분석 영역 밖 이동은 0이며 사용자 오브젝트에는 적용하지 않았다. 결과는 `sculpt-inverse-native-validation.json`이다. 임시 데이터블록은 제거됐고 원래 장면은 보존됐다.

교차검증 첫 실행은 압축 NPZ 배열을 모서리 루프 안에서 반복 해제해 GUI를 오래 점유했다. 결과는 끝까지 수신했고, 후속 실행은 필요한 배열을 시작 시 한 번만 읽도록 수정했다. 수학 검증과 사용자 GUI 점유를 분리하는 실행 기준도 필요하다.

참고: [Blender Smooth](https://docs.blender.org/manual/en/latest/sculpt_paint/sculpting/brushes/smooth.html), [Blender Retopology](https://docs.blender.org/manual/en/latest/modeling/meshes/retopology.html). 위 수치와 역모델 결론은 공식 문서의 주장이 아니라 이 세션의 실제 전후 데이터에서 계산한 결과이다.
