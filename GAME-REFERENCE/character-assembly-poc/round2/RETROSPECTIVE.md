# 캐릭터 조립 1차 실패 회고와 2차 재시도

상태: **1차 라운드 전체 실패. 2차 라운드 진행 중, 생산 승인 전.**

## 소유자 판정과 성공의 경계

남성 맨 베이스는 소유자가 절차를 직접 가르치고 실제 목표 데이터를 제공했으므로 좌우 시메트리 분석, 정상 쪽 선택, 결합부 조정, 텍스처 연결성 개선까지 성공했다. 이 결과는 구강이 없고 눈 소켓이 빈 상태의 지도된 POC다. 남성 결과를 전부 실패라 쓰거나, 반대로 지도된 성공을 에이전트의 독립 공정 성공으로 바꾸지 않는다. 마지막 UV의 생산 수준 달성은 입증되지 않았다.

여성 얼굴·몸 베이스와 그 조립은 비례 불일치로 실패했고 검증도 실패했다. 남성 구강 통합 역시 실패했다. 애니메풍 렌더 셰이더는 생성조차 목표대로 달성하지 못한 **완전 실패**이며, 기본 셰이더 시험 성공이나 고도화만 남은 상태가 아니다.

다른 실제 메쉬에서 같은 절차를 재현할 수 있는지, 그 결과를 검증할 수 있는지, 게이트가 성립했는지는 현재 **판단 불가**다. 문서·스크립트·이미지·아카이브 PR이 존재하는 것으로 이 세 항목을 통과시키지 않는다.

## 실패가 성공으로 바뀐 경로

| 단계 | 관측된 증거와 잘못된 해석 | 2차 라운드의 반증/수리 조건 |
|---|---|---|
| 비례 정합 | `../2026-09-19/scripts/assemble_female_base.py:63-72`는 머리 스케일을 몸에도 적용한다. 머리 목표 크기 계산이 전체 스케일에 흡수되어 독립 비례 정합이 아니다. 최종 렌더는 과대 머리를 보여준다. | 원본 변환과 해부학적 표식을 재측정한다. 별도 스케일의 가역 블록아웃을 정면/측면에서 확인한 후에만 연결한다. 숫자 목표를 실제 비율 달성으로 바꾸지 않는다. |
| 경계 연결 | 같은 파일의 `neck_groups`는 56/64 경계만 골라 몸의 32 경계를 포함하지 않는다. 후속 브리지로 성분이 하나가 되어도 형상은 검증되지 않았다. | 경계 의미/위치/방향과 밀도 전환을 실측하고 국소 행에 걸친 쿼드 흐름을 설계한다. 연결 성분 하나는 필요한 부분 조건일 뿐이다. |
| 좌우 선택 | `symmetrize_female.py`는 두 개짜리 YZ 버킷만 비교해 다른 정점을 제외한다. 부분 쌍의 최대 오차 0을 완벽 대칭으로 보고했다. | donor를 고정하지 않고 양쪽의 동일 영역을 감사한다. 매칭 커버리지와 미대응 정점/중앙 seam까지 보고한다. 퇴화 면은 작아도 승인을 막는다. |
| UV 후처리 | `unwrap_female_uv2.py:89-94`, `retry_male_uv.py`가 딕셔너리 겹침 항목을 리스트/튜플 조건으로 누락했다. | 실제 producer 출력을 소비하는 회귀 테스트를 먼저 실패시킨다. 겹침·퇴화·비유한·빈 입력·누락 중 어느 것도 통과로 바뀌면 안 된다. |
| 수정 감사도 불완전 | `review/package_blends.py:119-146`가 임의 polygon fan을 쓴다. 보고 표본에는 동일 face ID 쌍도 있다. 인접면의 양의 면적 겹침을 제외하며 퇴화 여부도 최종 bool에 반영하지 않는다. | Blender native loop triangulation과 독립적으로 답을 아는 fixture를 사용한다. 접촉만 제외하고 양의 면적 겹침은 인접성으로 면제하지 않는다. 192/1,456/40,853을 객관적 정답으로 고정하지 않는다. |

| UV/색상 표면 | 파일 생성·RGB 분산·겹침 카운트만으로 베이크 품질을 승인했다. 검증되지 않은 UV 위 베이크는 연결성/체커 품질을 보장하지 않는다. | 실제 삼각분할의 전개, 왜곡·밀도·패딩, 체크 패턴, 원본 색상 비교, 접합부 근접 렌더를 함께 확인한다. UV 변경 후 이전 베이크를 그대로 재사용하지 않는다. |
| 애니메풍 셰이더 | 노드 인자/엔진 오류 뒤 코드가 실행되고 이미지가 생긴 것을 제작 성공처럼 취급했다. 소유자 판정은 완전 실패다. | 재료와 라이팅을 분리해 목표 애니메풍 셰이더를 새로 만들고 모델에 바인딩한다. 같은 모델·카메라에서 조명 방향을 바꿔 색·명암·얼굴·윤곽을 직접 비교한다. 단색 덮기로 결함을 숨기지 않는다. |
| 저장·재열기 | 패킹 영수증 `OK`는 정점/면/쿼드 수의 일치만으로 결정되며 패킹 실패가 결합되지 않는다. | 독립 재열기에서 좌표/토폴로지/UV/재질 의미 지문과 누락 참조를 검사한다. FBX 재import와 외부 텍스처 연결도 별도 확인한다. |
| 완료 관리 | 미완료 여성 파츠를 done으로 바꾸고, 시각 도구 실패 후 파일 크기·구조 숫자로 대체했다. PR 병합을 공정 승인처럼 보고했다. | 누락/미판정은 통과가 아니다. 시각 검증은 실제 이미지를 직접 본 증거가 필요하다. 외부 리뷰 타임아웃은 승인으로 대체하지 않는다. |

위 코드 원인은 읽기에서 확인한 결함 및 실행으로 검증할 가설을 구분해 적었다. 아직 실행으로 재현하지 않은 수정 효과를 확정하지 않는다.

## 소유자가 가르친 절차를 적용할 때 지킬 조건

1. 원본·소유자 스컬트·성공한 남성 기준을 보존한다. 알려진 전후 대응이 있는 경우 토폴로지 지문이 같을 때만 정점별 역산한다.
2. 기하 노말은 정점 배치와 면 기하의 결과다. 노말 재계산이나 커스텀 셰이딩으로 접힘을 감추지 않는다.
3. 얼굴 고밀도/몸 저밀도는 삭제할 불편이 아니라 이번 접합 과제다. 국소적으로 머리 밀도를 줄이거나 몸 행을 늘려 흐름을 설계하고 보호 영역을 보존한다.
4. 대칭 적용 가능성을 먼저 판단하고 양쪽을 동일 조건으로 감사한다. 이번 남성의 정상 쪽이 다른 입력에서도 정상이라는 가정은 금지한다.
5. hard fail을 통과한 후보만 비교한다. 보호영역 손상/구멍/퇴화/관통/누락은 평균 점수와 가중합으로 보상할 수 없다.
6. 사후 목표 데이터를 사용한 역적합 설명력과 입력만으로 예측한 결과를 구분한다. `Sculpt-Inverse-Analysis.md`의 92.98% 사후 설명력은 독립 자동 수리 성공이 아니며, 문서 자체도 자동 적용을 불합격으로 남겼다.

## 재현성 판정

여성 자율 적용의 성공이 필요하며, 그 외 다른 실제 geometry를 사전에 holdout으로 고정해 같은 공정으로 실행한다. `additional-body-fingerprints.json`의 추가 파일 8개는 기존 지문상 2그룹이다. 다른 파일명, 형식 변환, 좌우 반사, UV/색상 변형만 있는 사본을 다른 메쉬로 세지 않는다.

검증기는 정상 fixture를 통과시키고 알려진 불량/누락 fixture를 거부해야 하며, 결함 주입이 해당 검사에서 실패하는 것을 관찰한다. 재현성 범위는 실제 검증한 입력 계열로 한정한다. 한 번의 성공을 모든 메쉬에 대한 보장으로 쓰지 않는다.

## 증거 우선순위와 원본 보존

- 사용자 최신 판정은 1차 보고의 성공 문구보다 우선한다.
- 과거 `ok` JSON과 아카이브는 삭제/덮어쓰기하지 않고 회고에서 무효 범위를 연결한다.
- 2차 작업은 전용 브랜치/worktree에서 수행한다. 원본 Downloads, 외부 Character-Assembly-POC, 소유자 Blender 장면은 수정하지 않는다.
- 문서·목표·todo 상태만으로 완료를 만들지 않는다. 아직 필요한 기준을 정할 근거가 없으면 미판정으로 남기고 측정·비교한다.
- 승인 기준, 구현 소유권 및 실행 시나리오는 2차 CONTRACT에 구체화한다. 기준이 정해지고 증거가 통과하기 전에는 production 완료가 아니다.
