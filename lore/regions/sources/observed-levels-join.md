# 관측 층수 조인

> 과거 출처 조인 관측 기록이다. 아래 334역·265관측·1,708건물 수와 접근 실패는 당시 입력 판본의 상태이며 현재 조회·재조사 결과가 아니다. 원문 수치와 실패를 보존한다. 현재 원자료 판본·출처·해시는 [지역 안내](../README.md), PG head 조회는 [작성 계약](../../AUTHORING-JSON.md)을 따르며 관측되지 않은 층수·현재 가동·시설 보유권을 생성하지 않는다.

키 없이 받은 출처만 붙인다. 없는 칸은 창작하지 않는다.

| 출처 | 대상 | 건수 |
|---|---|---|
| 서울교통공사 OA-11572 CSV | 1–8호선 역사 | 247 |
| OSM `layer`/`level` (ODbL) | 봉은사·삼성중앙·선정릉·언주 | 4 |
| OSM 건물 웨이 이름 일치 | 역 3 + 동 건물 43 | 3+43 |
| 한국어 위키백과 구조 칸 (CC BY-SA) | 개포동 등 11 | 11 |

334역 중 관측 층수 265. 나머지 69는 코레일·9호선·우이신설·신분당 등. 서울시 추가 CSV는 로그인/타임아웃. 건축물대장은 API 키.

건물 1,708채 중 이름 완전 일치 43채만 OSM `building:levels`를 쓴다. 거리 최근접은 옆 빌딩 오류라 쓰지 않는다.
