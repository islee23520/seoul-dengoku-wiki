# 서울 지역 설정 데이터

이 문서는 선택한 **2026-07-01 행정동 경계의 427개 동·25개 구** 판본과 출처를 설명한다. 334역은 당시 이동 그래프 목록이며 행정동 면적·최신 작위 슬롯 수와 별개다. 현재 세계는 서울 안에서만 성립한다. 현행 작위는 행정동 남작령 슬롯→지역구 백작령→자치구 공작령→복수 자치구 왕국→서울 제국이며 최신 공식 판본·분할 예외·권리 승인은 [루트 가이드](../../WORLD_BUILDING_GUIDE.md)를 따른다. 이 문서의 고정 판본·수치가 최신 공식 경계나 재배치 완료를 증명하지 않는다.

## 날짜와 출처

조회 기준일은 2026-09-12다. 행정동 자료의 기준일은 2026-07-01, OSM 원본 스냅샷은 2026-09-04T23:00:00Z다. PBF 파일 수정일은 2026-09-05다. 지형 파일의 2017년 12월은 저장 객체 수정 시기다.

선택 경계는 통계청 SGIS 행정동을 가공한 `vuski/admdongkor` 공개 자료다. 표시는 그 커밋의 경계이며, 공식 최신 법정 경계 인증이 아니다. 고정 커밋은 아래와 같다.

- [2026-07-01 행정동 GeoJSON](https://raw.githubusercontent.com/vuski/admdongkor/7360288277dfd12d74e54b959c59bdd66f852e3a/ver20260701/HangJeongDong_ver20260701.geojson)
- SHA-256: `c01ef44a0eb00978662ba7a6240ccb1da287fb52abd85104a1758969d391132f`
- 원본 취득일: 2026-09-12. 원본 커밋일: 2026-08-26.
- 가공물 CC BY 4.0, 원자료 SGIS 공공누리 제1유형 출처표시 유지. [자료 라이선스](https://github.com/vuski/admdongkor/blob/master/LICENSE-DATA).

같은 경계 파일이 서울 밖도 담는다는 아래 수치는 2026-10-10 원자료 조사 기록이다. 경기도 602동(47개 시군구), 충청북도 153동(14), 충청남도 208동(16), 대전광역시 82동(5), 세종특별자치시 24동(1), 강원특별자치도 188동(18), 서울 포함 1684동과 `sources/selection.json`의 `extended_coverage`는 provenance로 보존한다. 서울 밖을 현행 세계·추가 집필 범위·미지의 미래 활동지로 승인한 기록이 아니며 소문·보고로 현행 서사에 남기지 않는다.

OSM 자료는 `© OpenStreetMap contributors`, ODbL 1.0 조건을 유지한다. 지형은 Mapzen·USGS 및 해당하는 NOAA 출처표시를 보존한다. 원본 지리 번들은 위키 저장소의 [`data/geography/`](../../data/geography/README.md)에 보관한다. 서울 기존 번들, 요청 권역을 포함하는 대한민국 OSM 원본, 선택 행정동 실제 도형과 고도 타일을 함께 유지한다. 파일별 출처·크기·SHA-256은 그 디렉터리의 `manifest.json`을 따른다. 원본 PBF는 Unity Assets에 복사하지 않는다.

## 논리 문서 구조

- `content/<구 코드>.json`은 해당 구 동별 저작 내용의 PG 논리 식별자다. 물리 JSON을 복원하거나 직접 고치지 않는다. [PG 작성 계약](../AUTHORING-JSON.md)에 따라 현재 head·승인 상태와 지원되는 typed 편집을 확인한다. 다른 구의 시설을 이름만 보고 가져오지 않는다.
- 이 작업트리에는 옛 공간·객체 원장 생성 도구(`TOOL/tools/regions/`)와 `WIKI/` 별도 저장소가 없다. 과거 명령은 현행 공간 재생성 절차가 아니다.
- 현행 지도 원천의 논리 ID는 `../places/World-and-Subway-Layers.json`이다. 지원되지 않는 도메인 변경을 물리 파일·SQLite 쓰기로 우회하지 않는다.
- 공간 생성물과 검증 기록: `.omo/evidence/seoul-regions/`. 이 폴더의 존재만으로 콘텐츠 완료를 판단하지 않는다.

각 동은 주민·생업, 산출/입력/부족, 위험, 개막 상태, 이웃과의 관계, 플레이어 행동/비용/결과/대가, **건물 재사용**을 가진다. 건물 칸은 `content.buildings`다. 강·구·동 규칙은 강·구·동 건물 재사용（`../places/Building-Reuse-Geography.json`）이 정본이다. 장소와 태그는 관측, 경계·소속·면적은 계산, 붕괴 뒤 주민과 사건은 창작이다. OSM 태그만으로 기관의 현재 가동을 말하지 않는다.

세계관 날짜는 시나리오 타임라인（`../chronology/Scenario-Timeline.json`）의 개막일이다. 임하준 실종과 기존 중앙 급수·부품 계약의 만료가 출발 조건이다. 다음 봄의 유언장, 가을 행렬, 겨울 무기열차 사건을 이미 일어난 개막 사실로 앞당기지 않는다.

## 전수 검사

경계는 EPSG:5179에서 안정 ID 순서로 중복을 제거했다. 원래 선택 합집합 **606,223,725.0069752㎡**를 유지하고, 모든 동의 비어 있지 않은 도형을 보존한다. 경계가 맞닿았다는 사실만으로 이동 간선을 만들지 않는다.

원자료의 태그 있는 node와 모든 way/relation을 처리 원장에 남긴다. 이름 없는 객체도 남기고, 같은 이름을 한 시설로 합치지 않는다. 후보는 내부 할당, 외부, 도형 미완성 격리 중 하나로 기록한다. 선택 자료를 다 처리한 것과 현실 시설을 확인한 것은 별개다.

외부 SQLite 이관 진단이 필요할 때만 `WIKI_DOCUMENT_DB=/절대/외부/이관.sqlite node scripts/lore-json-validate.mjs --public --strict`를 사용한다. 이것은 레거시 문서 구문·스키마·링크 진단이며 PG 현재 head·공간 원자료 독립 재생성·서사 적합성·게시 승인을 증명하지 않는다.

옛 `prepare_boundary.py`·`build_region_atlas.py`·`assemble_region_content.py`·`verify_region_atlas.py` 절차는 이 작업트리 밖의 과거 도구 기록이다. 그 도구나 입력 번들이 다시 제공되기 전에는 재생성 가능하다고 주장하지 않는다. PG 현재 조회·정식 생성·실제 지역·지도 화면의 확인 범위는 각각 구분해 기록한다.

이 원장은 지역 저작 데이터다. Unity 내부 공간과 지역 시뮬레이션은 여기 없다.
