# 강·구·동 건물 재사용

**가. 건물 재사용의 원칙**

붕괴 뒤 서울의 건물은 새로 짓지 않는다. 2026년 붕괴 직전의 위치와 형태가 뼈대다. 그 위에서 쓰임만 바뀐다. 현재 쓰임은 과거 기록과 다를 수 있다.

## 세력과 건물

**가. 점령의 최소 단위**

동은 면적을 나누는 칸으로 남는다. 세력이 가져가는 최소 단위는 건물이다. 동 이름에 깃발을 꽂는 것으로는 점령하지 않는다.

**나. 역 건물 우선**

동에 지하철역이나 철도역이 있으면 배급과 통행세, 숙영, 피난은 그 역 건물을 먼저 본다. 영등포역 하역장과 서울역 대합실, 제기동 환승처처럼 역이 생활의 입구가 된다. 학교와 주민센터, 병원은 지원 건물로 남는다.

**다. 동의 세 상태**

동은 세 상태 가운데 하나에 있다. 내용은 다음 표와 같다.

| 상태 | 뜻 |
|---|---|
| `held` | 한 세력이 지배력 50 이상으로 가져간다. |
| `contested` | 둘 이상이 나눠 가지거나, 한 세력의 지배력이 50 미만이다. |
| `vacant` | 세력 깃발이 없다. 건물과 역은 있다. |

## 세 층

**가. 세 층의 내용**

세 층의 내용은 다음 표와 같다.

| 층 | 단위 | 하는 일 |
|---|---|---|
| 강 | 한강 남북, 지천 | 침수·제방·선석이 1층을 먹을지 결정한다. |
| 구 | 25 자치구 | 어떤 직능이 그 구의 잔존 건물을 가져가는지 정한다. 구를 국가로 바꾸지 않는다. |
| 동 | 427 행정동 | 관측 앵커마다 붕괴 전 용도와 붕괴 후 쓰임을 적는다. |

**나. 이름과 쓰임**

장소 이름과 기능은 과거에서 온다. 경계는 나뉜다. 현재의 쓰임이 그 위를 덮는다.

## 한강과 지천

**가. 강 남북의 구**

한강 이북의 구는 종로·중구·용산·성동·광진·동대문·중랑·성북·강북·도봉·노원·은평·서대문·마포·강서이다. 이남의 구는 양천·구로·금천·영등포·동작·관악·서초·강남·송파·강동이다.

**나. 지천**

지천이 구를 가른다. 중랑천이 중랑·동대문·노원을 지나간다. 안양천이 양천·구로·영등포 서부를 가른다. 탄천이 강남·송파를 가른다. 청계가 종로·중구·성동을 가른다. 홍제가 서대문·은평을 가른다. 동 이름에 여의도·이촌·반포·잠실·망원·합정·암사·구의·자양이 들어가면 본류 수변으로 본다.

**다. 수변의 규칙**

수변은 세 층의 규칙을 먼저 적용한다. 본류 1층은 우기 창고이거나 포기한 공간이다. 거주는 3층 이상에 둔다. 배급 창구는 제방 안쪽에 둔다. 지천 변은 오수와 범람, 멧돼지와 너구리 회랑이다. 학교 운동장은 우회 제방으로 쓴다. 관악·도봉 같은 내륙 고지는 침수 대신 경사와 단전을 받는다. 학교는 대피 대강당이 된다.

## 구가 가져가는 직능

**가. 직능의 출처**

십육국 권역을 구 위에 얹는다. 건물 직능은 구의 시설에서 나온다. 영등포 정수와 신정 차량기지, 방화 기지, 창동 차륜, 노량진 냉동, 제기동 약재가 각 구에서 먼저 남는 시설이다. 배정은 다음 표와 같다.

| 구 | 강 | 먼저 가져가는 건물 |
|---|---|---|
| 영등포 | 남, 한강·안양천 | 정수·역 하역장. 시장은 예약 배급 창구. |
| 양천·구로·금천 | 남, 안양천 | 차량기지·공단 동. 학교는 부품 건조. |
| 강서 | 북, 한강 | 방화 기지와 연구동. 공항 기억은 창고용. |
| 용산·마포 | 북, 한강 | 철도 창고·선석. 방송동은 기록 중계. |
| 종로·중구 | 북, 청계 | 행정동·대학. 장부와 봉인 서고. |
| 성동·광진 | 북, 한강 | 공방·교량 접근. 학교는 수리 실습. |
| 강동 | 남, 한강 | 정수·동부 교량. 병원은 탁수 격리. |
| 송파·강남·서초 | 남, 탄천·한강 | 배급 타워와 잠실·수서 창구. 아파트 저층은 봉인. |
| 동작·관악 | 남 | 노량진 냉동, 남부 경사 대피. |
| 은평·강북·성북 | 북, 북한산 | 피난 대강당, 고지 창고. |
| 도봉·노원 | 북, 중랑천 | 창동 차륜, 북부 철도 숙영. |
| 중랑·동대문 | 북, 중랑천 | 환승·제기동. 시장은 약재와 환승 화물을 나눈다. |

## 과거 용도와 현재 쓰임

**가. 기본 쓰임**

붕괴 전 용도는 현재 쓰임의 바탕이다. 아래 표를 기본으로 한다. 강·구가 그 위에 덮는다.

| 관측 | 기본 쓰임 |
|---|---|
| 학교 | 동 민병 숙영. 운동장은 화물 정렬. 특별실은 봉인. |
| 주민센터 | 동 장부와 배급 창구. |
| 병원·의원 | 야전 의무. 정수 인근은 탁수 격리. |
| 대학 | 기록 사본 공방. 실험동은 봉인하거나 부품 분해. |
| 시장 | 허가 장터. 예약분과 판매분을 나눈다. |
| 역 | 생활 화물 인계와 피난 층. 선로는 국가 통행세. |
| 아파트 | 3층 이상만 거주. 1–2층은 침수 창고이거나 포기. |
| 공원·녹지 | 얕은 경작, 방목, 우기 배수. 묘지로 쓰지 않으면 명시한다. |
| 상점·사무실 | 공방이거나 셔터 봉인. |

## 층마다

| `state` | 뜻 |
|---|---|
| `flooded` | 우기·지천 물. 거주 금지. |
| `sealed` | 판자·쇠터. 허가 없이면 못 들어간다. |
| `occupied` | 사람이 쓴다. 배급·숙영·인계. |
| `abandoned` | 모서리 비웠. 낮은 탐색만. |
| `yard` | 노천. 운동장·화물 정렬. |

**가. 용도별 최소 층**

용도별 최소 층은 다음 표와 같다.

| 관측 | 층 |
|---|---|
| 역 | 지하 2 선로, 지하 1 승강장, 1층 대합실, 옥상 망루 |
| 학교 | 1층 현관·운동장, 2층 교실 숙영, 3층 특별실 봉인, 옥상 |
| 아파트 | 1–2층 침수 또는 포기, 3층 거주, 옥상 봉인 |
| 주민센터 | 1층 창구, 2층 서고 봉인 |
| 병원·의원 | 1층 대기, 2층 침상 |
| 대학 | 1층 사본 공방, 실험동 봉인 |
| 시장 | 지하 창고, 1층 허가 장터 |
| 공원·녹지 | 지표면 한 층 |
| 그 밖 | 1층, 필요 시 옥상 |

**나. 수변 1층**

수변 1층은 `flooded` 또는 창고이다. 거주는 3층 이상이다.
