# 시작 프리셋 — 선택형 난이도와 결핍 조합

> 근거: K-시스템 "빈곤은 하나의 난이도가 아니라 여러 종류의 결핍" [REF:K-START], BB "기원은 시작 보너스가 아니라 회사의 장기 규칙" [REF:BB-ORIGINS].
> 각 프리셋은 결핍의 종류가 난이도를 만든다. 숫자 조정이 아니라 "무엇이 없는가"가 다르다.

> 설계 제안이며 현재 선택 가능한 기능 목록으로 읽히지는 않는다. 아래 수치는 목표값이고,
> P0/P1/P2는 구현 우선순위이며 완료 판정으로 남기지는 않는다.

## 프리셋 (6종)

### ☀ 표준 — "떠돌이 삼인조" (Normal)

> 어느 역에서도 환영받지 못하는 세 사람. 하룻밤 잠자리를 얻는 것이 오늘의 목표.

| 항목 | 값 |
|---|---|
| 시작 인원 | 3 (지휘관 + 무작위 2) |
| 보급 | 30 (아슬아슬 — 며칠치) |
| 장비 | 최소 (봉·낡은 의복) |
| 세계 인물 후보 | 무소속 카드 `unaffiliated-jaepyo-jo`(조재표), `iyen`(이연)은 무작위 동료 배치 후보 풀에 들어간다. 배치는 프리셋 시작 시 무작위로 정하고 시작 조합에 들어올 확률만 있다 |
| 평판 | 모든 세력 0 (무관심) |
| 거점 | **없음** — 영등포 대합실에서 하룻밤 허락받은 상태 |
| 장기 규칙 | 없음 — 표준 규칙 그대로 |
| 난이도 | ★★☆☆☆ |

### 🛡 쉬움 — "전직 자치 순찰대" (Easy)

> 무너진 자치회의 옛 순찰대원들. 싸울 줄은 알지만, 옛 동료들은 그들을 배신자로 본다.

| 항목 | 값 |
|---|---|
| 시작 인원 | 4 (지휘관 + 무작위 3, 전원 기본 전투 스킬 보유) |
| 보급 | 50 (여유) |
| 장비 | 양호 (제식 봉·순찰 방패·응급 키트) |
| 평판 | 신도림 자치회 **−3** (배신자 취급), 나머지 0 |
| 거점 | 신도림 B1 대합실 구석 사용권 (월 보급 −5) |
| 장기 규칙 | 신도림 자치회와의 관계 회복이 첫 관문. 구원정보 접근 불가 |
| 난이도 | ★☆☆☆☆ |

### 💰 경제 — "상인 잔존자" (Economy)

> 붕괴 전 물류망의 생존자. 물건은 있지만 지킬 힘이 없다.

| 항목 | 값 |
|---|---|
| 시작 인원 | 3 (지휘관 + 상인 출신 1 + 무작위 1) |
| 보급 | 80 (풍부) |
| 장비 | 상인용 (운반용 카트·저울·교섭 수첩) |
| 평판 | 교역로 세력 +2, 군벌 −1 (약탈 대상) |
| 거점 | 없음 — 이동하며 거래 |
| 장기 규칙 | **교역 이윤 +20%** / 전투원 고용 비용 +50% (상인 출신은 싸우지 않음) |
| 난이도 | ★★☆☆☆ (전투 회피 경로) |

### ⚔ 도전 — "탈영 소대" (Hard)

> 구로 군벌에서 탈영한 전투 소대. 잘 싸우지만, 군벌의 추격자가 뒤에 있다.

| 항목 | 값 |
|---|---|
| 시작 인원 | 5 (지휘관 + 전투원 4) |
| 보급 | 20 (부족 — 탈출하며 거의 잃음) |
| 장비 | 군용 (제식 무기·방어구 — 좋지만 눈에 띔) |
| 평판 | 구로 군벌 **−5** (살해 대상), 나머지 세력 −1 (군인 불신) |
| 거점 | 없음 — 계속 이동해야 함 |
| 장기 규칙 | **구로 군벌 추격자**가 주기적으로 스폰. 정착 시 추격 강도 증가 |
| 난이도 | ★★★★☆ |

### 🏚 최난 — "고아 무리" (Very Hard)

> 지하에서 태어나 지하에서 자란 아이들. 숫자는 많지만 아무것도 모른다.

| 항목 | 값 |
|---|---|
| 시작 인원 | 6 (지휘관 + 미성년 5 — 전원 스킬 없음) |
| 보급 | 10 (극빈) |
| 장비 | 없음 (넝마주움) |
| 평판 | 모든 세력 0 — 단, 의뢰 수주 시 **신뢰도 판정** 필요 (아이들을 믿는 곳 없음) |
| 거점 | 폐쇄된 환기구 안 (은신처 — 시설 없음) |
| 장기 규칙 | 성장 속도 ×2 (배움이 빠름) / 사망 시 사기 타격 ×2 / 의뢰 보상 −30% |
| 난이도 | ★★★★★ |

### 📜 스토리 — "마지막 역장" (Story)

> 마지막까지 역을 지킨 노역장과 그를 따르는 소수. 정통성은 있지만 힘이 없다.

| 항목 | 값 |
|---|---|
| 시작 인원 | 3 (지휘관 = 역장 + 무작위 2) |
| 보급 | 40 |
| 장비 | 평균 |
| 평판 | 영등포 주민 +5 (존경), 군벌 −2 (장애물) |
| 거점 | **영등포 B1 부분 통제권** (시설: 게시판만. 의무실·보급소는 수리 필요) |
| 장기 규칙 | 영등포 수리 비용이 성장 목표. 정통성으로 특정 의뢰 전용 접근. 역 상실 시 게임오버 아님 — 망명자가 됨 |
| 난이도 | ★★☆☆☆ (시작은 쉽지만 책임이 무겁다) |

## 구현 우선순위(시범 구현)

- P0: 떠돌이(표준) + 역장(스토리) — 두 개만으로도 "거점 있음 vs 없음" 비교 가능
- P1: 순찰대(쉬움) + 탈영(도전) — 평판 극단 확인
- P2: 상인 + 고아 — 경제/성장 특화 경로
