# 물류와 기반 시설

**가. 도표의 지위**

2026-09-07 위키 도표의 4방향 칸 연결은 당시 그림의 문법이었다. 처리량 공식은 아래 계산 규칙에 있다. 도표는 문서용 평면도이며 실제 게임 화면이 아니다.

구간 연결과 지형에 따라 보급 경로의 병목과 처리량을 계산한다.

물류는 필요한 종류의 물자를 허가된 경로로 제때 보내는 능력이다. 표의 수치는 모두 설계 가정이다.

## 입력과 출력

**가. 구간과 원정대**

| 입력 | 범위·기본값 | 출력 |
|---|---:|---|
| 구간 기본 처리량 `B` | 화물점/일 | 실제 처리량 `C` |
| 시설 상태 `I` | 0~1, 기본 1 | 붕괴·수리 효과 |
| 전력 `P` | 0~1 | 견인·환기·펌프 가동 |
| 접근권 `X` | 0~1 | 통행 허용 여부 |
| 위험 `H` | 0~1 | 호송 손실과 지연 |
| 원정대 비축 `Q` | 보급점 | 부족·피로·전투 준비도 |

## 계산 규칙

**가. 처리량과 공유 척도**

```text
C_e = clamp(B_e * I_e * P_e * X_e * (1-H_e), 0, B_e)
보급률 = clamp(도착량 / max(감시기간수요, 1), 0, 1)
부족률 = clamp(미충족량 / max(필요량, 1), 0, 1)
부담비율(분자, 분모) = 분모가 0이면 (분자도 0이면 0, 아니면 3), 아니면 분자/분모
과확장 = clamp(max(부담비율(요구처리량, 실제흐름), 부담비율(귀환필요량, Q), 부담비율(통치부담, 행정역량)) - 1, 0, 2)
완전고립 = 고립 단계가 2이면 1, 아니면 0
부하Δ = clamp(20 * 부족률 + 8 * 완전고립 + 6 * 과확장, 0, 35)
부하 A = clamp(A + 부하Δ, 0, 100)
```

여섯 전략 문서가 공유하는 0~2 척도를 과확장(이하 '과확장'이라 한다)으로 정한다. 이 문서의 정의를 기준으로 삼는다. 물류(요구처리량/실제흐름), 귀환(귀환필요량/Q), 통치(통치부담/행정역량)의 부담 비율 중 최댓값에서 1을 뺀 뒤 0~2로 자른다. 분모가 0이고 분자가 남아 있으면 부담 비율은 3이다. 이때 과확장은 상한 2이다. 분자도 0이면 부담 비율은 0이다.

이 문서가 정의하는 고립 단계(이하 '고립 단계'라 한다)는 공유 0~2 연속 척도이다. 모든 합법 주 경로가 정상이면 0이다. 일부 경로가 봉쇄되어 우회·경화물만 가능하면 1이다. 모든 합법 경로가 차단되면 2이다. 중간값은 봉쇄된 합법 경로 처리량의 비율로 보간한다.

이 문서가 정의하는 부하(이하 '부하'라 한다)는 0~100 누적 척도이다. 증감 계수와 구간 효과는 설계 가정이다. 감시기간 말에 `부하Δ`를 더한 뒤 0~100으로 자른다. 보급률이 1이고 허가된 안전 거점에 필요 능력 태그가 있으면 증가 대신 감시기간당 15만큼 회복한다.

**나. 부하 구간**

0~24 준비에는 물류 특화 효과가 없다. 25~49 긴장에서는 준비도가 감소하고 여유 용량이 필요한 임의 행동을 제한한다. 50~74 임계에서는 구간 진입 시 미치료 부상 하나를 악화시키거나 최하위 상태 장비 하나를 손상시킨다. 둘 다 없으면 지정 화물을 잃는다. 대상은 심각도 다음 영속 ID 순으로 정한다. 75~99 실패에서는 후퇴·화물 유기·현지 조달·분할·명시적 고위험 속행 중 하나를 결정해야 한다. 100 붕괴에서는 전진 개시를 막고 좌초·항복·해산 또는 구조/최후 조우로 넘긴다. 자동 비율 사망은 적용하지 않는다.

보급은 정책 우선순위와 영속 ID 순서로 배분한다. 물자는 능력 태그가 맞는 수요에만 배정한다. 일반 보급점이 남아 있어도 의료·배터리·수리 태그는 서로 바꾸지 않는다.

## 경계 상황

**가. 단절과 복구**

- 경로가 없으면 고립 단계 2이지만 비축이 충분하면 즉시 굶지는 않는다.
- 실제 흐름이나 비축 `Q`가 0인데 해당 수요(요구처리량·귀환필요량)가 남아 있으면 그 부담 비율은 3으로 정의되어 과확장이 즉시 상한 2로 포화하고, 수요도 0이면 그 부담 비율은 0이다.
- 전력 차단 환승역은 양쪽 터널이 멀쩡해도 전동 화물 흐름이 0일 수 있다.
- 임시 복구는 기본적으로 도보·경화물만 통과시키며 중화물·무장 통과는 별도 승인이다.
- 봉쇄 연결은 삭제하지 않고 원인, 수리 자원과 예상 시간을 표시한다.
- 불필요한 중복 허브도 유지비를 내며, 최대 흐름·비축·단일고장 생존성을 늘리지 않으면 효용 0으로 표시한다.

## 계산 예시

**가. 처리량과 과확장**

기본 처리량 100, 시설 0.8, 전력 0.5, 접근권 1, 위험 0.1이면 `C=clamp(100*0.8*0.5*1*0.9,0,100)=36`이다. 수요 60을 비축 40과 배송 36으로 모두 충족하면 부족률은 0이다. 물류 부담 비율은 `60/36=1.667`이다. 귀환필요량 20과 비축 40이면 귀환 부담 비율은 `20/40=0.5`이다. 통치부담 3과 행정역량 3이면 통치 부담 비율은 `3/3=1`이다. 최댓값 1.667을 적용하면 `과확장=clamp(1.667-1,0,2)=0.667`이다. 다음 원정의 취약성을 경고한다.
