# 라벨렌 전기: 겨울선 (Ravelen Chronicles: The Winter Line) — 웹 빌드 역설계 백과사전

> Project EMBER, 웹 콘테스트 빌드(데스크톱 1920×1080). https://ravelen-chronicles-web.vercel.app/ 배포본을 2026-09-07 정적 분석(번들 판독)과 실측 플레이로 역설계했다. 한국어 1차 언어(en-US·zh-CN 로케일 동봉)의 GBA 파이어 엠블렘 계보 **턴제 SRPG**로, 캠페인 허브·인연·사기·항복·병참·거점을 얹었다.
>
> **표기**: `[코드]`는 배포 번들에서 읽어낸 상수·수식(경로는 `assets/<청크>.js` 기준), `[UI]`는 실측 플레이 화면·i18n 문자열, `[추론]`은 그 둘을 종합한 구조 해석, `[미확인]`은 이번 판독에서 위치를 못 찾은 항목이다. 출처 목록은 부록.
>
> **이 문서가 존재하는 이유**: 잔선은 2026-09-07부로 전투를 실시간·진형·카드 기반으로 전환한다([Intent.md](../../../Intent.md) 결정 3). 이 게임은 **턴제 SRPG 쪽의 마지막 정밀 참조**이며, 여기서 가져갈 것은 턴 구조가 아니라 사기·항복·지휘조·인연·병참·예고된 증원 같은 **전투 바깥 계약**이다.

- **빌드**: Vite + rolldown 번들. 진입 `game-*.js`가 `main-*.js`(전투 런타임 413KB)·`game-rules~main-*.js`(순수 규칙 엔진 386KB)·`campaign-*.js`(캠페인 210KB)·`game-ui-*.js`(279KB)를 지연 로드. 전장 JSON 24개는 빌드 시 JS 청크로 변환(`ch01-ash-village-*.js` 등). [코드]
- **표현**: DOM 스테이지(1920×1080 고정, CSS 변수 `--stage-scale`로 축소) 위에 전투 캔버스 1440×810. 유닛은 캐릭터별 스프라이트 시트(idle·walk·map-idle·attack·hit·defeat·dash·victory·heal) 795개 청크, VFX는 512px 프레임 잉크 시트 31종을 색조 합성. 지면은 `isotool-art/ground/*` 타일. [코드][UI]
- **저장**: `localStorage` 슬롯 저장·불러오기, 전투 중 저장·되감기. [코드][UI]
- **접근성·조작**: 좌클릭 선택·이동·확정, 우클릭/Esc 취소, Enter/Space 제자리 행동, M 음소거, T 지형 전술 보기, O 전체 목표. [UI]

## 4. 유닛 모델

- **스탯 9종**: `hp, strength, magic, skill, speed, luck, defense, resistance, constitution`. [코드]
- **무기**: `might, hit, critical, weight, range[min,max], rank(E…), type`. 타입은 sword·lance·axe·bow·dagger·tome·staff·tool. `effectiveness`가 이동 타입 하나를 지정. 비무장 방어는 might 0·range [0,0]의 도구로 취급(반격 불가). [코드]
- **이동 타입**: foot·mounted·armour·flying. 기병은 얕은 물 진입 불가. [코드][UI]
- **클래스 특기**(예): 정면 승부(사거리 1 공격 시 공격 +1·명중 +10·피해 감소 1), 고립 돌파(인접 2칸 내 아군 0일 때 +1), 대기 장창(방어 시 기병 상대 +2), 철창 반격(기병 상대 피해 감소 2), 균열(중장·요새 상대 +2), 고정 사격(활·미이동 시 +1·명중 +15). `master-` 접두 상위판 존재. [코드]
- **단검+숲 표식**: 숲에서 단검으로 공격하면 상대에게 다음 이동 페널티와 회피 페널티 표식. 도로 위 피격 시 이동 페널티. [코드]

## 5. 전투 공식 (`game-rules~main`)

| 항목 | 식 | 비고 |
|---|---|---|
| 무기 상성 | sword > axe > lance > sword | 우세 +1 (공격 ×2 = +2, 명중 +15), 열세 반대. bow·dagger·tome·staff 중립 |
| 공격 속도(AS) | `speed − max(0, weight − constitution)` | |
| 회피 | `AS×2 + luck + 지형 회피 + 보정` | |
| 명중(원시) | `무기 hit + skill×2 + floor(luck/2) + 상성 15 + 보정 − 상대 회피` → 0..100 clamp | 지팡이는 `85 + hit` |
| 명중(표시·판정) | 원시치 t≤50: `round(t(2t+1)/100)`, t>50: `n=198−2t`, `round(100 − (n+1)(n+2)/200)` | 2RN 곡선 — 표시값과 실제 판정이 같다는 튜토리얼 문구와 일치 |
| 피해 | `max(0, (str 또는 mag) + might + 상성×2 + 특효 5 + 공격 보정 − (def 또는 res) − 피해 감소)` | tome·staff는 mag/res, 지팡이 might는 절반 |
| 치명 | `무기 crit + floor(skill/2) + 보정 − 상대 luck − 치명 회피` → 0..50 clamp | |
| 추격(2회 공격) | `AS ≥ 상대 AS + 4` | 반격 가능·사거리 내일 때만 |
| 타격 순서 | 공격자 → (반격) → (공격자 추격) → (방어자 추격) | |

[코드] 모든 항목. 사거리 밖·도구 무기는 피해 0·반격 불가.

## 7. 사기와 항복

- **아군 사기**: 기본 60, 0..100 clamp. 40 미만 경고, 80 이하에서 조건 충족 시 턴당 +5 회복(상한 80). **0이면 와해** — 지휘 명령 잠금·인연 명령 무효. [코드]
- **적 지휘관 사기**(전장별): 기본 60(한 전장은 40). 적 격파당 사기 손실 5~10, 격파 누적 손실 상한 10~40, 지정 목표 완료 손실, 지휘관 HP 임계 손실, 캠페인 트랙 손실. [코드]
- **항복 3조건**: 사기 ≤ `moraleAtMost`(전장별 15~50) **그리고** 지휘관 HP% ≤ 임계 **그리고** 퇴로 엄호. 셋 다 맞으면 항복 확정. [UI][코드] 임계 HP%는 전장별 값이라 [미확인].
- **사기 사건**: 손실·회복·0 도달·40 미만 진입에 각각 효과음. [코드]

## 9. 병참·거점·장치·증원

- **병참 준비안**: 다음 전장에 대한 한 번뿐인 준비. 서로 다른 준비안 최대 2개, 출격 시 차감, 고르지 않아도 출격 가능. [UI]
- **거점**: 점령 즉시 효과. 감시탑은 **다음 증원 위치를 미리 드러내고**, 예고 칸을 점유하면 출현에 대비. [UI][코드]
- **장치**: 수문(물이 빠진 구간이 평지로), 문, 봉수·중계 신호, 곡물·보급 수레, 기록·명부, 감옥·막사, 군기·집결 깃발, 화재(경고→발화). 인접한 행동 가능 아군이 행동을 소비해 조작. [UI][코드]
- **증원 웨이브**: `pendingWaves`·`warnedWaveIndexes`로 예고 후 도착. [코드]
- **캠페인 허브**: 명부·인연·편성(지휘조 편집)·슬롯 저장·장 선택·에필로그. [UI][코드]
- 경험치·레벨업·승급 수치는 [미확인] (레벨업 처리 함수와 "승급" 문자열 존재만 확인).
