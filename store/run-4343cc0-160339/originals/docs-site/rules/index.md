# 게임로직 — 전체 규칙서

- [캠페인 루프와 진행 규칙](./Rules-CampaignLoop.md) — 캠페인 한 사이클은 거점 준비부터 결과 반영까지 여섯 단계로만 돈다.
- [실시간 진형과 카드 전투 규칙](./Rules-Battle.md) — 한 판은 확정된 전투 컨텍스트로 시작해 ResultId 하나로 끝난다.
- [이동과 조우 규칙](./Rules-TravelEncounters.md) — 원정 이동은 동서남북 네 방향만 받는다.
- [거점과 영토 규칙](./Rules-Strongholds.md) — 역은 점령만으로 완성되는 깃발이 아니다.
- [경제와 생산, 물류 규칙](./Rules-EconomyLogistics.md) — 경제는 생존 자원과 제작 자원과 노동과 전력과 실제 운송 능력을 한 장부로 묶는다.
- [세력과 외교, 전쟁과 공성 규칙](./Rules-FactionsWarfare.md) — 세력 정치는 호감도 하나가 아니다.
- [저장과 결정성 규칙](./Rules-SaveDeterminism.md) — 같은 시작값과 선택 기록은 같은 세계와 같은 사건 검사값을 강제한다.
