2 · 대출 매트릭스 — 무엇을 누구에게서 빌렸나

레퍼런스차용한 요소잔선에서의 형태의도
켄시
떠돌이 문법		 K-START 결핍의 종류 = 난이도6종 시작 프리셋 (인원/자원/장비/평판/거점/압박 축)반복 플레이의 출발점 다양화
K-SETTLEMENT 정착은 선택떠돌이 → 시설 이용권 → 선택적 역 운영자정착 없이도 성장 루프 완결
K-SURVIVAL 회복 가능한 실패쓰러짐 ≠ 사망 · 부상 이행실패 후 재기 — 게임오버 아닌 악화
K-NOMAD 세계 상태 전이핵심 인물 생존·수감 → 지역 변화제한된 세계 반응 (전면 시뮬 금지)
배틀 브라더즈
용병회사 경제		 BB-ECONOMY 시간 = 비용이동·휴식만 캠페인 시간 진행 · 보급 일일 소모"이 행동의 날수까지 계산하라"
BB-ROSTER 로스터 ≠ 배치로스터 6 · 배치 상한 3 · 부상자 교체 휴식인원 관리의 의사결정
BB-TERRAIN 지형 비용오르막 +1AP · 고지 사거리 +1하이트맵 전술 가치
BB-CRISES 세계 위기중반 세계 이벤트 → 고용/물가 변화세계가 살아있음을 경제로 체감
CK3
인물 중심 대전략		 CK3-CHOICES 선택 투명성조우 3선택 비용/효과/위험 사전 공개추측이 아니라 계산으로 결정
CK3-CHARACTER 인물 존재감초상·관계·상태 상시 표시 · 경고 배지인물이 자원이다
CK3-MAPMODE 정보 모드전략 노선도의 세력권/통행권 전환같은 지도의 다른 질문
FE / FFT
전술 문법		 FE-COMMAND 유닛→명령→대상→확정/취소이동/공격/대기 + 공격 예상 + 무소모 취소실수 없는 수동 전술
FFT-HEIGHT 고도·CT하이트맵 B1/B2 · 층구분 · 전투 행동시간전투의 시간 단위는 월드와 다름
창세기전·TS
인터미션·신념		 WOG-INTERMISSION 준비·장비·대화거점 허브 (인터미션 N면)비지도 관리면의 원조
TS-VOTE 선택이 관계에 누적조우 선택 → 관계·평판 누적행동의 지속적 결과
UOUO-FORMATION 리더가 이동을 결정파티 편성·대표 토큰최강 개인 ≠ 최적 리더
배너로드MB-CLAN 클랜 티어 → 정치 자격밴드 평판 → 시설 접근 → 역 운영권성장이 곧 권한 확장
신장·삼국지NA-DOMESTIC 영토 내정역 시설 수리·운영 (후반)정착 이후의 심화 관리
태합입지전TR-CAREER 생업 = 성장 경로수리·의료·운송·교섭 전투 외 성장전투만이 답이 아님
XCOM 2X-DUAL 양층 시간 압박전략(보급 고갈) × 전술(턴 제한) 압박선공적 운영이 유일한 방어
다키스트 던전DD-ATTRITION 소모품 같은 영웅부상자 관리·로테이션 강제원시적 강함이 아니라 마모
Into the BreachITB-INTENT 예고된 위협위협 칸 표시 · 적 의도 사전 공개계산 가능한 전술

3 · 시스템별 조합 공식

경제 압박

시간 = 비용

BB 일급 → 잔선 보급 일일 소모
K 허기 → 식량 체인
FFT 이동일 → 역간 여행 시간
= 이동·휴식만 시간 진행, 메뉴·전투는 정지

부상·사망

회복 가능한 실패

BB 영구부상 → 정산 영수증 표시·다음 원정 이행
K 쓰러짐≠사망 → 3단계(쓰러짐/부상/사망)
DD 로테이션 → 부상자 교체 강제

세계 반응

두 속도의 진화

K World States → 핵심 인물 상태 전이
BB 위기 → 고용·물가 변화
CK3 의견 → 관계 지속
= 작은 사건(시설 상태) + 큰 사건(인물·전쟁)

모집·포획

3경로 분리

K 구조→신뢰→가입 → 핵심 동료
BB 인력시장 → 계약 인력(수당)
MB 포로 설득 → 생포 후 협상
= 즉시 구매 없음 · 관계가 게이트

정착 진행

선택적 승급

K 3상태 → 유랑/도시집/전초기지
BB 비정착 → 이동 회사도 성장
MB 클랜티어 → 권한 확장
= 떠돌이→이용권→선택적 역 운영

명시적 비채택

가져오지 않은 것

✗ CK3 전투 추상화·봉건 계승
✗ BB 육각·9AP·대규모 용병단
✗ K 초반 grind
✗ FE 자동 원상복구
✗ 전면 4X 시뮬레이션

4 · 3-표면 구조 — 각 표면이 묻는 질문이 다르다

S · STRATEGY

전략 노선도

"누가 어디를 지배하며, 무엇을 우선할 것인가?"

서울 전체 → 16국 세력권 · 2D 평면 도식 (3D 금지)
조회 = 시간 정지 · 결정만 시간 진행
CK3 정보모드 NA 영토

W · WORLD

역간 여행

"일행은 어디로, 어떤 대가로 갈 것인가?"

현재역→목적역 · 경로·보급·사건
이동 = 시간·비용 소모 · 사건에서 판단 정지
FFT 이동일 BB 비용

B · BATTLE

역 내부 B1/B2

"지금 누가 어느 칸에서 무엇을 할 것인가?"

하이트맵 5×5 · 사각 칸 · 고저차
전투 행동시간 ≠ 여행 시간 · 임의 환산 금지
FE·FFT BB 지형 ITB 위협

N · 비지도 관리면 — 거점 허브·조우·배치·정산은 지도가 아니라 관리·선택·준비·정산 기능군. 배경에 지도가 있어도 지도 수에 더하지 않는다. 창세 인터미션 CK3 이벤트

+ FE/FFT 전술문법 + 창세/TS 인터미션·누적

= 잔선: 서울

떠돌이 3인이 보급 압박 속에서 의뢰를 수행하며,
선택의 비용을 알고 전술로 해결하고,
