# 실시간 부대 지휘 전투

전투는 참가자, 전장, 목표, 보급, 합법 퇴로와 증원 조건을 확정한 닫힌 세션으로 시작한다. 플레이어는 부대를 골라 지시하며, 전투는 변경할 수 없는 `ResultId` 하나를 내고 끝난다. 카메라와 일시정지 질문은 답변 없이 기한이 지났으므로, 아래 방식을 권장 설계 기본값으로 채택한다. 소유자가 직접 확정한 결정으로 기록하지 않는다.

## 부대 지휘

직접 조작하는 대상은 개별 영웅이 아니라 선택한 부대다. 지휘 범위는 다음으로 한정한다.

1. 전투 전이나 허용된 재편 상태에서 진형과 정면을 정한다.
2. 한 부대 또는 함께 지시할 부대들을 선택한다.
3. 이동, 공격, 방향 전환, 진형 변경, 정지 가운데 하나를 고른다.
4. 전장에 표시된 경로·목표·도착 진형을 미리 본다.
5. 확인하면 새 지시가 그 부대의 현재 지시를 교체한다. 취소하면 기존 지시를 그대로 둔다.

확정한 지시만 수락된 명령 기록에 들어간다. 여러 지시를 쌓는 큐, 웨이포인트 연쇄, 순서 편집, 감속·배속과 영웅 직접 행동은 목표 범위가 아니다.

선택하지 않은 상태에서는 부대 명령을 확정할 수 없다. 미리보기와 확정 때 모두 같은 전투 컨텍스트로 유효성을 검사하되, 미리보기 자체는 상태를 바꾸지 않는다.

## 영웅과 병졸 분대

이름 있는 영웅 캐릭터와 병졸 분대는 별도 전장 행위자다. 영웅은 병졸 인원에 포함하지 않는다. 병졸 한 분대의 상한은 20명이며, 21명 이상을 한 분대로 합치지 않는다. 전체 분대 수, 영웅 수, 군단 상한과 분대 최소 인원은 이 문서가 정하지 않는다.

영웅도 지휘 명령의 대상이 될 수 있지만 직접 액션 콤보를 조작하지 않는다. 영웅 상태와 병졸 분대의 인원·사기·진형을 따로 기록하고, 결과에서도 영웅 개인의 생사·부상·구금과 병졸 분대 손실을 한 숫자로 합치지 않는다.

## 카메라와 일시정지 기본값

전투 카메라는 3D 자유 지휘 시점이다. 플레이어는 전장을 팬·오빗·줌으로 살핀다. 특정 각도, 시야각이나 수치를 새로 정하지 않는다. 위에서 내려다본 전장 도식은 위치와 상호작용을 설명하는 문서용 청사진이며, 실제 게임 렌더 화면이 아니다.

일시정지와 재개는 실제 전투 상태다. 일시정지는 이 파티의 닫힌 전투 세션만 멈춘다. 공유 캠페인 월드, 세계 시간이나 다른 파티의 전투·이동은 멈추지 않는다.

일시정지 중에도 부대를 선택하고 명령을 미리 본 뒤 확인하거나 취소할 수 있다. 확인한 명령에는 결정론적 수락 순서를 붙인다. 재개하면 다음 시뮬레이션 스텝에서 그 순서에 따라 적용한다. 같은 부대에 나중에 확인한 명령은 앞서 확인한 현재 명령을 교체하며, 별도 명령 큐를 만들지 않는다. 취소한 미리보기는 수락 순서에 들어가지 않고 기존 명령을 유지한다.

## 전투 종료와 신병 처리

| 종료 상태 | 원인과 지휘 상태 | 퇴로·결과 규칙 |
|---|---|---|
| 일반 승리·패배 | 목표 달성이나 전투 불능 판정으로 끝난다. | 승패와 손실 사실을 결과에 적는다. |
| 명령 철수 | 플레이어가 철수를 지시하고 확인한다. 철수 중에도 지휘가 유지된다. | `LegalFallback`을 통과한 경로가 있어야 한다. 실패하면 명령 철수는 성립하지 않는다. |
| 사기 패주 | 결속 붕괴로 통제를 잃고 이탈한다. | 합법 경로를 고르는 명령 철수와 구분하며, 패주에 따른 손실 사실을 남긴다. |
| 수락된 항복 | 한쪽이 항복을 제안하고 상대가 받아들인다. | 퇴로 봉쇄나 `LegalFallback` 실패만으로 항복 선택을 없애지 않는다. |

포획은 종료 상태가 아니라 전투 뒤 인물별 신병 처리에서 생기는 구금 결과다. 항복자, 패주자, 부상자나 생존자를 자동으로 모두 포로로 바꾸지 않는다. 포획 여부와 신병 처리는 해당 인물 ID에 붙여 결과에 기록한다.

각 전투는 위 종료 상태 가운데 하나와 전투 사실을 담은 불변 결과를 한 번만 발행한다. 캠페인은 같은 `ResultId`를 정확히 한 번 정산한다.

## 전장 원형

| 원형 | 전술 특징 |
|---|---|
| 작은 역사 | 기둥과 상점, 짧은 교전 거리, 좁은 전열 |
| 환승역 | 층 전환, 여러 입구, 측면 노출과 증원 경로 |
| 종착역 | 막힌 끝, 넓은 승강장, 차량 엄폐 |
| 터널 | 한 줄 진형, 긴 시야, 퇴로 위험 |
| 지상 폐허 | 넓은 시야, 환경 노출, 기동 유리 |
| 차량기지 인접 | 대형 설비, 수리 목표, 다중 경로 |
| 한강 횡단 구간 | 제한된 연결, 붕괴와 침수 위험 |

## 같은 상황은 같은 결과로

실시간 환경에서도 결정론 계약은 유지한다. 전장 생성, 명중, 피해, 사기와 증원은 전투 시드와 수락된 명령 기록으로 재현되어야 한다.

- 시뮬레이션은 고정된 규칙 간격으로 진행한다.
- UI의 시각 이동은 게임 Core의 논리 위치를 따라 표현한다. 화면에서만 부대를 이동시켜 Core의 이동 판정을 대신하지 않는다.
- 동일한 컨텍스트와 수락된 명령 기록이 다른 결과를 내면 검증 실패다.
