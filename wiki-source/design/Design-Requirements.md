# 설계 요구 티켓

MDA 층은 설계 어휘다. 개발 단위는 GitHub 요구 티켓이다.

한 칸에는 그 요소가 무엇인지 적는다.

## 현재 목표 (2026-09-19)

전투의 주 입력은 부대·진형 지휘다. 개별 영웅의 이동·공격·회피 연속 입력을 만들지 않는다. 인물 그림의 목표는 애니메이션풍 정비율이다. 전투 카메라와 일시정지는 질문 만료 뒤 채택한 설계 기본값이며, 소유자가 명시한 결정이 아니다. 카메라는 팬·오빗·줌의 3D 자유 지휘 시점이고 각도·FOV는 없다. 일시정지는 그 파티의 닫힌 전투만 멈추며, 정지 중 미리보기·확정을 허용한다. 수락된 명령은 재개 뒤 다음 시뮬레이션 단계에서 입력 순서대로 현재 지시를 교체한다. 감속·배속·명령 큐는 없다.

아래 티켓은 2026-09-07부터 18일까지의 카드·사이드스크롤 시기 기록이다. 이슈 번호와 닫힌 수치 잠금은 지우지 않는다. 새 구현 지시로 다시 열지 않는다.

## 시야 (기록, #97)

시야와 카메라는 당시 용사주식회사 채널의 2.5D 전투 화면을 따른다고 적었다. 요구 티켓 [#97](https://github.com/islee23520/seoul-kenshi/issues/97). 결정 10은 좌우 사이드스크롤로 고쳤다. 2026-09-19 설계 기본값은 질문 만료 뒤 채택한 3D 자유 지휘 시점이며, 소유자 명시 결정이 아니다. 2.5D·사이드스크롤을 새 요구로 되살리지 않는다.

## 전투 형태 (기록, #77·#99·#100)

전투 형태는 당시 Songs of Silence와 같은 실시간 진형·카드 전투로 잠갔다. 수치 잠금은 [#77](https://github.com/islee23520/seoul-kenshi/issues/77)(닫힘). 분대 명령은 [#99](https://github.com/islee23520/seoul-kenshi/issues/99). 집계 생존수와 사상자는 [#100](https://github.com/islee23520/seoul-kenshi/issues/100).

2026-09-19 목표는 같은 실시간 전장에서 부대를 골라 명령을 내리는 것이다. #77의 닫힌 수치를 이 문서가 바꾸지 않는다. #99는 부대 지휘와 맞닿은 옛 티켓이고, 카드 문법을 되살리는 뜻이 아니다.

토탈워 삼국·워해머처럼 이름 있는 영웅 캐릭터와 병졸 분대를 분리한다. 영웅은 병졸 수에 포함하지 않는 별도 지휘 인물이며, 병졸 한 분대는 최대 20명이다. 전체 분대 수·영웅 수·군단 상한은 미정이다.

## 카드 부여 (기록, #98)

인물의 생업·관계·직위가 카드와 지휘 반경으로 전투에 들어온다고 적었다. 부여 규칙 요구 티켓 [#98](https://github.com/islee23520/seoul-kenshi/issues/98). 이 티켓은 카드 시기 기록이다. 덱·드로우·재충전·오너 카드를 새 목표로 승격하지 않는다.

## 인물 POC

POC 사람 표현은 오드랜드 Spine이다. 실행 티켓 [#58](https://github.com/islee23520/seoul-kenshi/issues/58). 결정 10이 SD 재작업을 취소했고, 목표 그림은 정비율 애니메이션풍이다. 오드랜드 원본은 POC로 남긴다.

## 화면 목표

화면 목표는 [#101 UI/UX 화면 계약](/design/Issue-101-Ui-Ux-Decisions)의 12면과 사망·후계 보조 목업 4개다. 기존 HTML 열 면은 출발 자료이며 현재 목표 개수가 아니다. 색인 [#101](https://github.com/islee23520/seoul-kenshi/issues/101). 보고서 `/ui-ux-refs/`. 현재 Unity 보드 칸 이름은 바꾸지 않는다. 부대 지휘 화면의 문서 초안은 `GDD/system-design/total-war-ui/`에 둔다.

## 구현 순서

아래 검증 단계는 시각 수용·슬롯 연결·시각 게이트를 끝내는 순서다. 그 다음 제품 문서는 부대 지휘다. 카드 부여(#98)를 다음 구현으로 두지 않는다. 분대 명령(#99)과 사상자 표현(#100)은 옛 티켓으로 남기고, 새 수치를 이 칸에서 만들지 않는다.
