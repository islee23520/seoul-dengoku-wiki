**가. 가치관 척도의 의의**

성격과 야망, 공포, 가치관은 인물의 판단과 행동에 영향을 준다. 가치관은 권위·개방·무력·물질·공동·원칙·공개·자격·분산·변혁의 열 가지 기준으로 살핀다. 같은 문제에서도 가치관에 따라 선택하는 방법이 달라진다. 조직의 가치관에도 같은 기준이 적용되며, 실제 의사결정과 운영 관행에서 그 성향이 드러난다. 지도자가 바뀌면 조직의 정책도 달라질 수 있다.

척도는 −100부터 100까지이다. 0은 그 축에서 아직 어느 쪽으로도 기울지 않은 상태를 뜻하며, 무관심을 미덕으로 평가하는 값은 아니다. 욕망과 취향은 가치관과 별도로 기록한다. 수치는 [values-cast.json](https://github.com/islee23520/seoul-dengoku-wiki/blob/main/lore/name-pools/values-cast.json)과 [values-orgs.json](https://github.com/islee23520/seoul-dengoku-wiki/blob/main/lore/name-pools/values-orgs.json)에 기록되어 있다.

## 인물 욕망과 취향

**가. 욕망의 성격**

가치관은 공공 쟁점에 대한 성향을 나타낸다. 욕망은 **누구와 어떻게 관계를 맺으려 하는지**에 관한 성향으로, 야망과 공포와 함께 인물의 결정에 영향을 준다.

| # | 축 | −100 | +100 |
|---|---|---|---|
| 1 | 갈망 | 낮음·절제 | 강함 |
| 2 | 독점 | 나눔·열린 자리 | 독점·질투 |
| 3 | 위험 | 안전·예측 | 위험·금지 |
| 4 | 과시 | 비공개 | 공개 |
| 5 | 지속 | 일시 | 장기 동반 |

**나. 세부 성향 분류**

지향: 이성 / 동성 / 양성 / 무성향 / 유동. 결합: 단혼 / 다자 / 계약동거 / 비독점 / 없음.

욕망의 다섯 척도는 갈망·독점·위험·과시·지속이다. 지향과 결합 방식은 이 척도와 별도로 기록한다.

## 조직 가치관

**가. 조직 가치관의 기준**

조직 가치관도 인물과 **같은 10축**으로 구성한다. 값은 현재 헌장, 평의회 다수결, 장부 관행을 기준으로 매긴다. 정부에서 상원의원 개인의 권위 숫자와 정부의 권위 숫자는 다를 수 있다. 이 차이가 쟁점이 된다.

## 조직 정책 9칸

**가. 정책 선택지**

조직의 정책은 전쟁·이주민·급수·노동·기록·기술·교역·후계·결합의 아홉 항목으로 나뉜다. 각 항목에는 선택지가 있다.

| 슬롯 | 선택지 | 서울에서 보이는 일 |
|---|---|---|
| 전쟁 | 방어 / 제한전 / 선제 | 수비대만 / 보호군 / 선제 점령 |
| 이주민 | 추방 / 검역수용 / 시민권 | 관문 명부 |
| 급수 | 계약 / 최저선 / 볼모 | 단수 제재 |
| 노동 | 강제복무 / 계약 / 시민복무 | 군사호적 |
| 기록 | 비공개 / 교차검증 / 전면공개 | 유언·원장 |
| 기술 | 가문비밀 / 면허공유 / 공동원장 | 펌프·냉각 키 |
| 교역 | 봉쇄 / 허가 / 개방시장 | 경매·호송 |
| 후계 | 혈통 / 양자도제 / 공개시험 | 총관·원로 |
| 결합 | 단혼허가 / 계약동거 / 가문결합 / 군호적결합 / 개방결합 | 혼인·동거 장부. 성적 취향을 조직이 지정하지 않는다 |

운영가문 HC·HP와 서울 바깥 회랑 XT도 같은 항목을 쓴다. 가문에 관한 기록은 [세계 서사 총람](/wiki/World-Narrative-Atlas/)에 있고, 층별 세부 설명은 [가문](/wiki/Chaebol-Houses-and-Century-Factions/)에 있다.

## 세 세력의 관행 (개막)

**가. 지표의 의미**

가치관은 현재 다수가 따르는 관행을 나타낸다.

| 세력 | 눈에 띄는 축 | 개막 시점의 관행 |
|---|---|---|
| 정부 | 권위(명령·집정), 자격(세습) | 장부에 오른 사람만 국민으로 인정한다. 직업은 부모에서 자식으로 물려준다. 대통령은 종신이다. |
| 자유도시 | 분산(생활권 분할) | 도시마다 각자 권력이고 왕은 없다. 물자와 기술을 주고받는다. |
| 아크 | 권위(교주와 가문) | 통치는 가문을 단위로 하며, 신도는 세례를 받는다. |
