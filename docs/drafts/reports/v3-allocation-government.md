# v3 정부 인물 배치 조정 보고 (과제 30)

대상: `docs/drafts/people/government/batch-01.jsonl` ~ `batch-11.jsonl`(507줄: 정부 504명 + 무소속 3명). 기준: 04장 16.2·16.3절 정원표, 14.1·14.2절(군대 하나에 지휘관 하나 [승인]), 07장 4.2·4.3·4.7·4.8·5.2·9.4절. 원장: `docs/drafts/reports/v3-ledger-parts/t30-government.md`(T30-gov-1~23, 26). 배치 방법의 근거는 07장 4.7절 머리의 과제 30 결정(2026-11-13): 묶음 배정을 세력 전체로 맞출 때는 4.7절 순서를 처음부터 다시 돌리지 않고, 정원표·자리·이름 있는 자리를 지키면서 옮기는 사람이 가장 적은 배치를 고른다(잠정 T30-gov-1). 2차 조정(9절)은 07장 6.2절 의원 집안 칸 규칙(잠정 T30-gov-13)을 따른다.

## 1. 방법

- 11개 묶음을 한데 모아 줄(구)·단계·직함 묶음(16.2절 "직함·직업 구성")·역할을 정원표와 대조했다. 묶음 02~06, 10은 공용 배정표(`t17-b01/placement.json`)를 따르지 않고 묶음마다 따로 배정해서, 합친 상태에서 줄 인원이 맞지 않았다(종로 59/67, 서대문 15/22, 은평 38/30, 강북 31/23, 노원 41/33 등).
- 한 번의 세력 전체 배정으로 풀었다. 조건: 줄마다 인원·단계별 인원·직함 묶음 인원이 16.2절과 같고, 역할의 단계는 16.3절을 따르며, 줄마다 국회의원·의원 집안 후계·의원 집안 아이·구청장·구 부대 지휘관이 하나씩, 동장·역장·경찰관·부양 식구는 표의 수만큼, 의원 집안 배우자·친족은 집안 3칸인 줄에 하나, 기능조 조장·장터 상인 우두머리·보건소장은 많아야 하나다. 07장 7.2·7.3절의 이름 있는 자리(Key 9명, 국회의원 14명, 대통령 집안 셋, 신종목·신준)는 고정했다. 기록된 나이가 역할의 최소 나이(07장 5.1절)에 못 미치는 칸에는 앉히지 않았다.
- 사람의 단계(stage)는 하나도 바꾸지 않았다(정부에는 07장 4.1절의 바뀌는 사람이 없다).
- 지금 자리를 지키는 쪽을 먼저 두고, 옮겨야 할 사람은 가장 적게 골랐다(역할이 같은 채 구만 옮기기 < 같은 구 안에서 역할 바꾸기 < 둘 다). 같은 조건이면 07장 4.7절 1번 P 순서가 뒤인 사람이 옮긴다. 그래서 겹친 자리는 P 순서가 앞선 사람이 지켰다. 이것은 4.7절 3~4번을 처음부터 다시 돌린 결과(공용 배정표)와 다르다. 다시 돌리면 약 240명의 약력을 새로 써야 하므로, 정원표를 맞추는 최소 이동을 택했다(원장 T30-gov-1, T30-gov-12).
