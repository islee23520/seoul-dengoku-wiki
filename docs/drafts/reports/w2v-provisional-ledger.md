# W2V provisional ledger

Every item here is a provisional default written into public text without owner approval. In the drafts and in data/sql each one carries an `<!-- owner-pending: ... -->` comment. The site renderer drops HTML comments, so readers never see them, while tools can still find them. The reader-facing wording frames each item as a telling ("by most accounts", "the stories say") rather than as settled canon. Nothing here changes a bible section 3 date.
