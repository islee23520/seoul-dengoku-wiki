# v3 task 28: correcting translation errors in the fixed facts

Owner instruction (2026-11-13): "번역오류는 전부 수정해야하는것". Every correction below is listed in `docs/design/v3/fixed-facts.corrections.json` with `at` paths covering every occurrence in the frozen snapshot, so `node scripts/pages/v3-fixed-facts.mjs --check` passes. The output reads "fixed facts unchanged (with 143 listed corrections applied)". The same values were also corrected in the data (`data/sql/030,050,090,100,110,120,121,123`). Every other mention of the same entity changed with them so links stay consistent: lore text, relation `from`/`to`, tree `lineage.surname/bongwan` and map holdings. No portrait token held a corrected value; their names are Korean.

## Convention found in the data (kept, not normalized)

- **Korean person names** are Revised Romanization: the surname, a space, then the given name. Given-name hyphenation is mixed, about 50/50 ("Han Jae-mok" next to "Yu Sejin"), and was left as is. Within given names the data romanizes by pronunciation, with liaison and assimilation: Byeoryun 별윤, Bungmin 북민, Geumnin 금린, Darwon 달원, Bichun 빛훈. Corrections follow that pattern.
- **Surnames** are mostly strict RR (I, Gim, Bak, Choe, Gang, O, No). Accepted variants also occur (Kim 17 vs Gim 2 for persons, Yi, Lee, Oh, Kang, Noh, Park, and Park/Yi in tree ancestors). These are legitimate surname spellings and were **not** changed. Clan **labels** (`$.clan.name`) must agree with their own clan table row, so those were corrected.
- **Clan labels** use the form "<Bongwan> <Surname> Clan" or "<Surname> Clan of <Bongwan>". Both forms are kept.
- **Stations** use the line operator's official English station name. Before this task 247 of 312 did; after it, all corrected ones do. Sources: the operator station tables (Seoul Metro / Korail / Shinbundang / Sillim / Ui lines, cited per row), cross-checked with the project's `Seoul-Station-Catalog` document (030, column 영문). Where the two disagree, the operator wins (see below). **Gu and dong names** use the MOIS administrative Revised Romanization, with sound changes at syllable boundaries. All 427 dong names were re-checked with an RR sound-change romanizer; the four found are corrected below (Galhyeon 갈현 was flagged and is correct RR, since ㄹ+ㅎ keeps l).
- **Non-Korean persons** must use the surname spelling of their `nonkorean_family` row. The data otherwise keeps diacritics (Müller, Wiśniewska, Zielińska, Léa, Tomáš).
