# v3 잠정 항목 원장 (v3 Provisional Ledger)

계획 `.omo/plans/wiki-lore-rebuild-v3.md`. v3 바이블과 그 뒤 작업이 새로 지은 이름, 수치, 사실을 모두 여기에 올린다. 여기 있는 항목은 소유자가 답하기 전까지 승인된 설정이 아니다(저장소 규칙 "답변 전에는 후보를 승인된 설정으로 기록하지 않는다").

번호 규칙:

- 과제마다 자기 절("## task NN")을 두고 과제 접두 번호(`T02-1`, `T02-2`, ...)로 적는다. 문서 본문은 같은 번호로 "(잠정 T02-n)"이라 표시한다.
- 과제 24가 마지막에 모든 절을 모아 전역 번호 1..N으로 다시 매기고, 과제 접두 번호와 전역 번호의 대응표를 남긴다.
- 소유자 승인을 받은 항목은 지우지 않고 상태를 적어 둔다.

열: `#`(번호), `Document`(문서), `Location`(문서 안의 절), `Provisional item`(잠정 항목).
