# 아바타·의상 파이프라인에서의 참조 사용법

HairDeck(헤어/아바타 구성)과 Tripo(이미지→3D 메시)에 넣을 입력을 만들 때 참조 소스를 쓰는 방법이다. 참조는 **제작자가 눈으로 보고 자체 설정으로 번역하는 입력**이며, 외부 이미지를 파이프라인에 직접 투입하지 않는다.

## 1. 의상 설계 (settei → 서울 설정)

1. [settei 항목](settei/README.md)에서 의상 종류가 가까운 작품·캐릭터를 원문 링크로 열람한다.
2. 실루엣, 층 구성, 소재, 색 계열을 **텍스트로 요약**해 서울 인물의 의상 슬롯(상의/하의/신발/소품)에 맞춰 새로 쓴다. 원 캐릭터의 고유 디자인(문양, 로고, 고유 소품)은 가져오지 않는다.
3. 결과는 서울 인물 설정 문서에 둔다. 항목에는 참조 링크만 남기고 설정화 내용은 옮기지 않는다.

## 2. 포즈·의상 참조 → 2D 캐릭터 시트

[pose-costume](pose-costume/README.md)의 포즈 코드(정면·상·하·측·사선 5뷰)와 의상 코드를 골라 작업 노트에 코드만 기록한다. 캐릭터 시트는 `.agents/skills/seoul-character-images`의 절차로 생성하며, 산출물은 승인 전 2D 후보다. 실제 PNG와 receipt가 있어야 생성을 보고한다.

## 3. 캐릭터 시트 → Tripo 프롬프트

Tripo 입력은 이미지다. 프롬프트·메타 필드는 아래 틀을 쓴다.

```text
full body, A-pose or T-pose, front view, neutral expression, plain background,
<성별·체형>, <의상 슬롯별 요약: 상의 / 하의 / 신발 / 소품>,
<색 계열>, no text, no logo, single character
```

- 의상 요약은 위 1단계에서 서울 설정으로 다시 쓴 문장을 쓴다.
- 포즈는 리깅을 위해 A/T 포즈로 고정한다. 참조 포즈는 뷰 구성 확인에만 쓴다.
- 3D 생성은 `seoul-character-images` 스킬의 `3d-generate` 계약을 따른다.

## 4. 금지

- setteidreams 이미지의 다운로드, 위키 게시, Tripo/이미지 모델 입력 투입.
- 제3자 유래 이미지(pose-costume의 `data/source` 계열)의 위키 이식과 재배포.
- 승인되지 않은 후보를 승인 설정으로 기록하는 것.
