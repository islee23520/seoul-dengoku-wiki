# #656 종교 연합 개정 검토 자료

[Wiki #656](https://github.com/islee23520/seoul-dengoku-wiki/issues/656)의 AI 숭배 세력 전환을 구체적인 문장과 선택지로 검토하기 위한 기여 문서다. 국가 이름·직함·교리·상징의 채택은 아직 확정하지 않았다. 이 디렉터리는 PostgreSQL 저작 정본이나 공개 생성 입력이 아니다.

- [개정안](ai-cult-proposal.md): 추천 교리, 권력 구조, 명칭 3안, 국기 구도 3안, 국가 문장 방향, 기사·인물 문단과 장면 후보.
- [근거 원장](ai-cult-source-index.json): 요청·현재 저장소 지침·공개 생성 표면의 판본과 확인 한계.
- [검토 기록](ai-cult-review.md): 별도 관점 검토의 관측과 반영한 수선.
- [요청 스냅샷](sources/wiki-656.json): 2026-11-03 조회한 이슈 본문과 공개 메타데이터. 수정안과 구분해 보존한다.

추천은 국호와 기존 왕·당회장 직함, 관할 색을 유지하고 기록 해석형 교리와 F1 도상을 검토하는 안이다. 다른 후보도 비교할 수 있도록 함께 남겼다. 오경재의 기존 신앙 표기와 새 개인 교리의 충돌은 별도 변경 대상으로 적었고, 가문 전체 개종·휴머노이드 반입·새 작위·영토·수치·장비를 자동 부여하지 않았다.

문서 기여 반영, 개별 설정 채택, PG draft revision 생성, 공개 게시, 국기 이미지 제작, 게임의 임시 국기 교체는 각각 다른 단계다. 이 제출로 #656 전체 완료를 선언하거나 이슈를 자동 종료하지 않는다.
