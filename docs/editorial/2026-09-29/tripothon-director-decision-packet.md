## 출발 분대와 개인 입력

신종목 지휘관은 #298의 지시다. **영웅 1명 + 성인 병졸 2명**은 기존 총 3명 안의 구체화이며 인원·병졸 식별·장비는 미승인이다. 20명 상한은 병졸에 적용한다. 별도 인물 K번호를 발급하지 않고 운반/기록 슬롯만 둔다. 민웅기와 신준은 분대에 들어가지 않는다.

| 개인 슬롯 | 역할·장비 제안 | 승인해야 할 실제 입력 |
|---|---|---|
| K1009 신종목, 영웅 지휘관 | 주민 회수 협의·귀환 판단. 연습용 목총 1 대여안 | 무기 ID·방어구 ID·전투 기술/숙련·몸 상태·기분·리더십·지휘 바인딩. 총검술 사실 외 입력은 미정. |
| 운반 보조, 성인 병졸 후보 | 동의한 부품 운반, 인원 대조. 가방 1, 분대 공구 꾸러미 1 보관. 임시 분대장 우선 후보 | 실제 식별자·성인 여부·참여 동의와 일곱 개인 입력. 후보 지정이 리더십 능력 부여는 아니다. |
| 기록 보조, 성인 병졸 후보 | 동의·교환/대여·허가·응답 기록. 가방 1, 분대 기록지 1 보관 | 실제 식별자·성인 여부·참여 동의와 일곱 개인 입력. 기록 업무는 무공이 아니다. |

장비를 분대 소유/보관 담당으로 분리했으며 무기·방어구를 가방으로 채우지 않는다. 무기 없음·방어구 없음도 소유자의 명시적 입력이어야 한다. 총기·실탄 0은 기존 대여안의 제안이며 정본 소지품 조사 결과가 아니다. 기본 이동 태세는 **통상 행군**으로 권고하고 협상 우선·철수 허용을 행동 방침으로 적는다. 옛 `경계`를 여섯 번째 태세 ID로 구현하지 않는다. CP에서 이동 속도를 유도하지 않는다.

승인표는 각 개인의 입력 및 승인자·일시·URL을 비워 둔다. 신종목이 전투 중 지휘 불능이면 승인된 임시 분대장이 전투 정산/귀환 책임을 이어받되, 신종목 사용 불가에 따른 목표 실패는 지우지 않는다. 임시 지휘가 새 성공 조건을 만들지 않는다.

예시 승인 경로의 산술은 기존 인수 명세와 같다: 물자 2, 부품 잔량 0, L=3/R=1/F=1/T=22/K=1/M=2/O=1. 새 응답 없이는 성공이 아니다. 이는 시연 점수이며 인물 신뢰 T[A,B]·영웅 충성·전투 수치가 아니다. 증감·시작값·척도·임계값 80은 아직 코드 상수로 넣지 않는다.

## 디렉터 승인 체크리스트와 인수인계

각 항목은 [승인표](decision-inputs.json)에 승인자·일시·URL을 함께 기록한다. `D299` 하나의 승인으로 다른 칸을 채우지 않는다.

- [ ] **D299 위치:** 학동/논현2동의 별도 허구 시설 채택 여부. 승인 후에만 지역 또는 연표 정본 편입 PR과 해당 원천 앵커를 확정한다.
- [ ] **D299-ACCESS:** 출발·창고·중계 현장 접속의 층/노드/간선·현재 봉쇄와 허가·복귀 경로를 검증한다. 소유자는 허구 접근 설정을 승인하고 #297은 존재 간선·통제·층 전환을 구현/검사한다. 위치만 승인해도 출입 공백이 남으면 2단계는 잠긴다.
- [ ] **D298-A:** 성인 병졸 2명의 실제 식별·참여와 개인 입력 7칸, 장비 대여 출처·ID, 통상 행군 태세 ID, 임시 분대장 순서를 승인한다. null을 기본 건강/평온/0으로 바꾸지 않는다.
- [ ] **D298-B:** 기존 시작 물자·재고/회수/주민 잔류·모든 선택 Δ·척도·위기 임계 80을 단위/정식 필드와 함께 승인한다. 제안 숫자의 일괄 승인으로 처리하지 않는다.
- [ ] **D298-C:** 성공 AND, 새로운 응답 식별/수신 시각/확인자, 실제 당직 시간 매핑, 정확히 한 번 정산을 승인한다. 가동 후 소모한 부품 잔량을 다시 ≥2로 검사하지 않는다.
- [ ] **D298-D:** 조우 여부·상대 개인 입력과 전투 필요 여부·귀환 조건을 승인한다. 정착은 별도 체류 동의/지속 가능 조건 승인 전 잠근다.
