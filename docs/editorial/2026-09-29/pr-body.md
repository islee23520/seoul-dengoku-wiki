# docs(tripothon): 창고·출발 분대 결정을 개별 승인 항목으로 구체화한다

#299·#298의 기존 학동/성인 3명 제안은 역 사이 연결과 개인별 승인 입력이 부족해 구현자가 미정 값을 보충할 위험이 있었다. 비게시 editorial 제안을 유지하면서 학동을 권고하는 대안 비교, 지하철 역별 경로, 별도 창고 출입 승인, 개인별 입력표와 #281/#285/#297/#283 인수 조건을 보완한다.

- 기존 역 ID `학동`, 강남구청→학동 1간선 및 학동→강남구청→선정릉 2간선을 GAME `ac98566ab41132747ae86a3b6825ea5ad2518aeb` 그래프로 확인했다. Wiki의 S16/open 전략 통행과 지역 건물의 봉인·침수·야간 출입 제약을 구분한다. 지하철 층은 권고이며 창고의 접속·출입 층·총 전환 수·점유권은 미정이다.
- 신종목 지휘관과 성인 병졸 2명, 통상 행군, 운반/기록 역할 및 임시 분대장 후보를 명시한다. 개인별 무기·방어구·기술·몸 상태·기분·리더십·지휘 입력과 승인 기록은 null로 남긴다. 총검술에서 장비 보유·수치를 만들지 않는다.
- 기존 5+1단계 선택·효과·동의·중복 정산 거부·가동 후 새 응답 AND 조건을 보존한다. 신준 12세의 휴식, 민웅기 대전 소재, S00, 2124년 기연결을 유지한다. 공개 카드·카탈로그·지역 원천·게임 데이터는 수정하지 않는다.

검증: 대상 JSON schema, 기존 schema 10/10, 렌더 175/175, 그래프/BFS/통행·미승인 계약·6개 원천 바이트·19개 기존 블록 보존 검사 및 diff check 통과. `build`, admission(5 pass/2 fail), contract는 **기준 main의 Atlas projection 33개 불일치**로 실패한다. Atlas와 33개 projection 및 관련 4모듈이 기준 main과 바이트 동일함을 확인했다. 별도 typecheck와 publication gate도 미생성 파일 때문에 실패했으며 전체 빌드 통과를 주장하지 않는다.
