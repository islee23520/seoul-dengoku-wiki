## 이미 있던 실패

이번 변경에서 실패를 숨기거나 기존 테스트를 약화하지 않았다.

- `scripts/test-common-tiers.mjs`: 기대 인원은 1,010명이나 원천/생성 인원은 1,016명이다. 초기 기준본의 전체 테스트는 **229건 중 228 통과, 이 1건 실패**였고, PR #198을 포함한 기준본에서도 동일한 실패를 확인했다.
- 부모 `verify-cast.mjs --docs lore`: 중복 이름과 미기재 계약 항목 등 **92건**. 초기 기준본과 작업본의 출력이 일치했다. 출력 SHA-256: `9a57d9b1573dc2c3795f01647874c1c1181e4a4b9608dd426d28dab14c053b6f`.
- LSP/Biome은 이 환경에 설치되지 않아 실행하지 않았다. 별도 패키지를 추가하지 않고 Node 구문 검사·JSON 파싱·기존 테스트·TypeScript 빌드를 사용한다.

## 검증 기록

- 신종목 회귀 테스트는 이전 `없음. 생업만.` 원천에서 실패하고, 원천만 고쳐 생성물이 낡아 있어도 실패하며, 정식 생성 후 통과함을 확인했다.
- 로컬 Wiki에서 신종목 상세의 `무공: 총검술.`과 “정본 카드 원문 전체”를 펼쳤을 때의 `무공. 총검술.`을 확인했다. 그 조회에서 콘솔 경고/오류는 없었다.
- 기여 문서의 상대 링크 41건은 깨짐 0이었다. Wiki 링크 검사(22 등록 경로)와 문서 계약 검사(83 문서)도 통과했다.
- 최종 `npm run build --prefix wiki` 통과: 83문서 생성, TypeScript 검사와 프로덕션 번들 생성 성공. 기존 Vite 설정 및 대형 청크 경고는 남아 있다.
- 생성 완료 후 `node --test --test-reporter=spec wiki/scripts/test-*.mjs` 실행: **232건 중 231 통과, 기존 인원수 검사 1건 실패**. 생성기와 테스트, 링크 검사는 같은 파일을 읽고 쓰므로 순차 실행한 결과를 최종 근거로 삼았다.
- 별도 목록 대조: 아홉 유파·별칭 한 개·여섯 수련 분야·상세 61항목, 12행씩인 분류 표 다섯 개, 기존 블록 앵커, 보류 세부 항목의 이름·훈련·부담·명령·전장 원형 보존을 확인했다. 원천 JSON과 동기화한 Markdown 및 생성 인물 상세를 대조했다.
- 브라우저에서 최종 빌드를 다시 로드하여 개정 명칭과 10열 표 다섯 개(각 12행)를 확인했다. 폐기한 여섯 공개 명칭은 본문에 노출되지 않았다. `강단발`, `차륜망치`, `손결`, `사제와-겸전과-형조`의 기존 해시 링크는 새 절 위치로 이동했다. 네 보류 이름은 남아 있다.
- 신종목 상세에서 원문 펼치기와 “정본 원문 위치로 이동”을 직접 실행했다. 원문 `#신종목`에서도 총검술이 확인되었다. 확인한 로컬 페이지의 콘솔 경고·오류는 0건이었다.
- `node --check`(수정한 테스트 두 파일)와 `git diff --check` 통과. 최종 cast 검증 출력의 SHA-256도 위 기준선과 일치했다.

최종 통합 검증과 제출 상태는 본 PR의 검증 기록으로 함께 확인한다. 이 문서의 로컬 실행 결과는 운영 서버 반영이나 게임 전투 구현의 증거가 아니다.
