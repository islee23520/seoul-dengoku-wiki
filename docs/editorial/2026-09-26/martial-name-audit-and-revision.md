## 편집 결론

디렉터 요구는 **무협 이름을 없애라는 뜻이 아니라, 무공답지 않은 억지 조어를 없애라는 뜻**으로 적용한다. `심법·권법·검법·봉법·신공`을 금지하지 않는다. `매트손`을 `발손연격`으로 바꾸는 식의 새 조어도 만들지 않는다. 이름에는 수련의 성격이 드러나고, 설명에는 실제 동작과 제약이 드러나야 한다.

이번 전수검사 대상은 정식명 9개, 생활 별칭 6개, 공통 분류 6개, 세부 항목 61개다. 이 **82개를 각각 한 행씩** 검토했다. 별도로 품계 4개·총림 습속 4개와 기존 무술·문파·조직명을 검토했다. 61개는 모두 독립 무공이라는 뜻이 아니다. 원문이 `기법`으로 묶은 표 60행과 `상륙호위진` 1개이며, 여기에 장비·정비·행정·의례가 섞여 있다.

권장 적용은 다음과 같다.

- `강단발·죽대손·매트손·빈탄손·렌즈숨`은 별칭을 폐기하고 정식명으로 통일한다. 새 별칭은 만들지 않는다.
- 장르감이 이미 있는 `차륜강체공·연각권법·호위철벽진`은 살린다. 한자어라는 이유로 바꾸지 않는다.
- 정식명은 `공탄총검법 → 총검술`을 추천한다. 1차의 `수문심법·연환검법` 권고는 철회한다. `수문호흡법·죽검연환법`은 이미 수련과 장르가 드러나며, 새 이름이 원래보다 분명해지지 않는다.
- `기록단절법`은 기록 파괴와 전수 단절을 혼동시키므로 개명을 보류한다. 독립 무공명 대신 `기록원 전승`이라는 설명용 항목명을 쓸 수 있지만, 이는 새 정식명이 아니다. 원격의 기존 명칭을 이번 검토로 삭제하지 않는다.
- 분류어는 `손결 → 수련 분야`, `내숨 → 호흡·지구력`, `외손 → 신체 단련`, `경보 → 이동·보법`, `연장 → 무기·도구`, `손고침 → 정비·지원`으로 정리한다. 분류 변경이 무공 효과 변경을 뜻하지 않는다.
- `총림·개방·항룡십팔장·타구봉법`은 보존한다. 총림 안의 개방 전수와 소림 전수는 별개이며, 전원에게 무공을 자동 부여하지 않는다.

이 문서는 위키를 수정한 결과가 아니라 **적용할 이름과 문구를 정리한 편집 산출물**이다. 변경 추천·유지는 이 검토의 판단이며, 원격 정본의 승인 상태를 뜻하지 않는다.

신종목은 사용자 최신 설정에 따라 **총검술 무공 사용자**다. 1차의 ‘무공 없음 유지’ 지침은 폐기한다. 다만 총검술을 익혔다는 사실만으로 특정 유파 가입·스승·숙련 등급·총기 지급을 추가하지 않는다.

## 명명 기준

1. **기술의 종류를 숨기지 않는다.** 맨손 전투는 권법, 검술은 검법, 봉술은 봉법, 호흡·집중 수련은 심법, 집단 대형은 진법이라는 익숙한 장르 어휘를 쓸 수 있다. 권법은 발기술도 포함할 수 있다.
2. **모두에게 신공을 붙이지 않는다.** 신공은 특별한 전승의 호칭으로 쓸 수 있지만, 이름만 바꾸며 새 힘·위계·초능력을 추가하지 않는다.
3. **이름과 설명은 역할이 다르다.** 무공명은 짧게 기억되도록 하고, 시설 기원·장비·금기·동작은 설명에서 풀어 쓴다. 모든 이름을 작업 지시문으로 바꾸지 않는다.
4. **모든 작업이 초식은 아니다.** 수리·장부 대조·배급·위령은 전승의 일부로 남기되, 무공 초식과 같은 목록에서 구분한다.
5. **손·숨·줄을 만능 접미사로 쓰지 않는다.** 인물, 기술, 호흡, 인가, 기록을 모두 ‘손’이라고 부르는 문체를 걷어 낸다.
6. **옛 이름은 이력에만 남긴다.** 별칭을 폐기한 뒤 화면·대사·인물 카드에 다시 노출하지 않는다. 안정 ID나 기존 링크를 지우라는 뜻은 아니다.

김용의 이름을 연구한 [Ni·Tang(2022)](https://doi.org/10.22158/sll.v6n3p1)은 무공명의 문화적 맥락과 번역을 다룬다. 이를 참고해 장르 어휘와 설명문을 분리했다. 위 여섯 기준과 아래 이름은 **프로젝트 편집 판단**이며 논문이 특정 작명법이나 후보명을 보증한다는 뜻은 아니다. 기존 작품의 초식 문장·목록을 가져오지는 않았다.

## 4. 세부 항목 61개

표 머리는 `기법` 대신 **항목**으로 바꾸고 분류 열을 둔다. 표시명은 짧은 제목이고, 동작·대상·도구·제약은 설명에서 함께 읽는다. **설명형·재분류 항목은 수련/작업/장비 목록용이지 신규 무공명이나 초식명 등록안이 아니다.** `보류`는 내부 검토용으로만 남기며 추천 후보를 화면에 자동 적용하지 않는다. 명령·비용·조건·금기는 이 편집에서 바꾸지 않는다.

| T60 | 삼본대조 | 기록 검증 | 재분류 → 세 사본 대조 | 세 본이라는 수량을 보존한다. 의료나 위조자의 자격 회복과 다르다. |
| T61 | 먹줄고침 | 기록 정정 | 개명·재분류 → 기록 정정 | 먹줄은 건축 도구로 읽힌다. 설명에 ‘증인 앞에서 한 줄을 다시 쓴다’를 명시하고 평판 비용·무증인 수정 금기를 보존한다. |

## 5. 품계·습속·문장까지 함께 정리

### 품계 4개 — 원문 L98–101

| 원문 | 추천 표기 | 유지할 지위 |
|---|---|---|
| 견습손 | 견습 | 생업은 있으나 아직 유파에 입문하지 않은 상태 |
| 당직손 | 입문자 | 스승 앞에서 전수가 시작된 상태 |
| 사제손 | 전수자 | 배운 계통을 다른 사람에게 가르칠 수 있는 상태 |
| 원로손 | 원로 | 금기를 감독하고 내침·파문을 선언하는 역할 |

등급·권한·국가 작위와의 관계는 그대로다. `무공 사제`는 종교 사제와 혼동되므로 일반 설명에서 `무공 스승`으로 쓴다. 사제 관계라는 표현은 유지한다.

### 총림의 비전투 습속 4개 — 원문 L119–122

| 원문 | 추천 표기 | 경계 |
|---|---|---|
| 명부함걸음 | 피난민 명부 옮겨 적기 | 이름을 옮겨 적는 일이지 보법이 아니다. |
| 피난줄나눔 | 피난 대열 나누기 | 줄을 나누고 자리를 비우는 일이며 호위 진형을 대신하지 않는다. |
| 위패앞앉음 | 위패 앞 묵념 | 산 사람 이름을 명부에 올리지 않는 의례이며 호명 제압이 아니다. |
| 빈손나눔 | 남은 배급 나누기 | 나눔의 습속이며 권법·전투 도구가 아니다. |

네 습속은 항룡십팔장·타구봉법의 초식이 아니다. 소림 전수와도 합치지 않는다.

### 주변 표현

| 원문 | 추천 | 이유 |
|---|---|---|
| 기질적 기술 | 신준의 경로 판별 | 본문이 다루는 인물·행동을 직접 적는다. 타고난 능력이라는 새 해석을 붙이지 않는다. |
| 2026에서 온 손 | 2026년의 기원 | 손이 무엇을 뜻하는지 다시 해독할 필요가 없다. |
| 전수 줄 | 가르치는 사람·곳 | 사람·장소가 혼재한 칸임을 드러낸다. 실제 계보는 별도 기록한다. |
| 몸값 | 부담·위험 | 돈이나 몸값이 아니라 부상·시간·노동·정치적 부담이다. |
| 금기 인접 | 관련 금기 | 기획 메모형 압축어를 없앤다. |
| 익힌 손이 전수가 되었다 | 생업에서 익힌 기술을 제자들에게 가르치기 시작했다 | 전수의 주체와 행위가 분명해진다. |
| 위조하면 손이 죽는다 | 위조하면 전수 자격을 잃는다 | 손 절단·신체 마비와 제명 처분을 혼동하지 않는다. |
| 무공은 손을 죽이고, 나라는 인준을 연다 | 유파는 전수를 끊고, 국가는 인준을 심사한다 | 두 절차를 구분하는 원문 취지를 보존한다. |
| 형조 | 겸전 심사 | 일반 설명용 풀이. 기존 구술 명칭과 제도는 원천 승인 없이 삭제하지 않는다. |

`삼본이 설교를 사본으로 만든다`, `물이 없으면 인준도 종이다`는 작동 규칙을 확인하기 어려운 수사다. 분위기용 대사로 남길 수는 있지만 규칙 표에서는 실제 대상·행위·실패 조건을 적어야 한다. 무엇이 실제로 무효가 되는지 불명확하므로 이번 개명으로 효과를 새로 확정하지 않는다.

## 6. 유지·분리하는 외부 명칭

- **총림 / 안국총림, 개방, 항룡십팔장, 타구봉법**: 디렉터 요구와 최신 원천을 보존한다. 총림이 개방을 전승한다는 사실과 총림 전체·백온 개인이 개방 무공 보유자라는 주장은 다르다.
- **소림 / 소림사, 화산파, 독고구검**: 정본에 등장하는 전승·참고 이름을 보존한다. 소림은 총림 안의 별도 전수이고, 화산파·독고구검은 참고 문맥이다. 소속만으로 개인 전수를 추정하지 않는다.
- **태권도, 택견, 수박, 씨름, 유도, 본국검법, 태극권, 태극검법**: 이어 쓰는 기존 무술명 8개다. 새 지역 유파의 별칭으로 붙이지 않는다.
- **검도, 거합도, 고류, 총검 훈련**: 원문 기원 설명의 수련·전통이다. 고류는 단일 무공명이 아니다. 태권도는 기원 설명과 위 8개 목록에 중복 등장하므로 중복 집계하지 않는다.
- **환승계, 궤도기병**: 각각 상호부조망·시설 군사다. 무공명 개편으로 새 유파나 국가로 만들지 않는다.
- **환승 길잡이, 역 방송팀, 문 수리반, 역 품앗이**: 과거 로컬 제안의 후보명이지 최신 아홉 유파를 대체하는 이름이 아니다. `태권도파` 역시 과거 이슈의 예시 인용이다.

## 7. 실제 반영 경로와 미해결 경계

정본 적용 시에는 다음 순서로 동기화해야 한다. 이번에는 이 원격 파일들을 수정하지 않았다.

1. `lore/culture/Martial-Paths.json`의 한국어 표시명·본문을 수정하고 Markdown을 렌더링한다. 영어 이름·설명도 같은 의미로 맞춘다. 현재 `.md`만 검색·치환하면 생성 시 되돌아갈 수 있다.
2. `lore/editorial/Naming-Ledger.json`의 `martialSchools[]`, `lore/glossary.json`, 대응 Markdown과 명명 검증 목록을 맞춘다. 확인되지 않은 한자를 만들어 넣지 않는다.
3. 인물 원본의 실제 무공 보유 문구와 상성·금기·제목·목차·링크를 갱신한다. **신종목은 최신 사용자 지시에 따라 총검술 사용자로 정정한다.** 아래 원천 갱신 지침을 따른다. 다른 인물에게 능력을 자동 부여하지 않는다.
4. 안정 ID·slug·본문 anchor는 표시명과 분리해 보존한다. 옛 이름의 anchor가 남았다는 이유만으로 사용자 화면에도 별칭을 남기지는 않는다.
5. `wiki`의 생성 작업으로 `wiki/public/person-details/`와 `wiki/src/generated/`를 재생성한다. 이 출력물을 직접 편집하지 않는다.
6. 해당 저장소의 lore 렌더·gate·인물 상세·링크 검증 후 게시 화면을 확인한다. 이번 로컬 문서 작업에서는 원격 프로젝트 테스트나 배포를 실행하지 않았다.

### 신종목: 이전 게시 상태와 새 적용 설정

- **이전 게시 상태:** 기준 SHA의 [Core-Characters.md L345](https://github.com/islee23520/seoul-dengoku-wiki/blob/dd8661d2f2326f4b107071a3e5f310a96a9eb9d9/lore/characters/Core-Characters.md#L345) 신종목 카드와 JSON `신종목-p4`에는 ‘없음. 생업만.’이 있다. 이는 과거 입력의 관찰이지 앞으로 유지할 지시가 아니다.
- **새 적용 문구:** 무공 필드의 한국어는 `총검술.`, 대응 영어는 `Bayonet fighting.`으로 맞춘다. 문장형 소개에서는 `신종목은 총검술을 익혔다.`로 쓴다. 해당 수정은 사용자 직접 설정을 근거로 한다.
- **변경 지점:** `lore/characters/Core-Characters.json`의 `신종목-p4` ko/en 본문을 갱신하고 저장소 렌더 절차로 대응 Markdown을 맞춘다. 생성 후 상세 JSON의 `sections["무공"]`뿐 아니라 `biography`에도 이전 문구가 남지 않는지 읽는다.
- **별개로 남길 것:** 총검술은 능력명이다. S08의 정식명 개편과 함께 표시를 맞추되, 신종목이 그 특정 유파에 가입했거나 원문의 군·징집 계보에 속한다고 자동 연결하지 않는다. 스승·무공 품계·현재 소총/총검/탄약 접근·전투 수치는 미정이다. 기존 생업·소속·관계는 유지한다.
- **잘못된 수정 방지:** `values-cast.json`에 없는 `school`·`martial` 필드를 새로 만들지 않는다. `person-1009`는 생성 순서에서 나온 표시 ID이므로 이름과 원천 앵커도 확인한다. 생성 JSON과 TS를 직접 고치지 않는다.

### 적용 보류와 실전 연결 경계

S05는 안전한 새 정식명이 아직 없어 **개명만 보류**한다. T28·T40·T58은 동작 또는 효과 해석이 충돌하므로 **개명과 그 해석에 따른 신규 효과 연결을 보류**한다. 이 네 항목 때문에 나머지 이름 정리를 막을 필요는 없지만, 82행을 무조건 치환하는 작업은 금지한다. 기존 기능을 이번 편집으로 삭제하라는 뜻도 아니다.

T15의 ‘고친 장비’처럼 설명의 대상이 압축된 항목도 이 명칭표만으로 전투 규칙을 새로 구현하지 않는다. 효과·대상·성공 조건이 추가로 필요한 경우 별도 규칙 정의가 선행돼야 한다. 이름 정리 승인과 런타임 전투 승인은 별개다.

이름의 자연스러움은 편집 판단이므로 플레이어의 취향까지 시험으로 증명할 수는 없다. 원문의 유해물질 노출·신체 단련·손상 묘사를 현실의 안전한 수련법으로 안내하지 않는다. 이번 작업은 물리적 타당성이나 게임 동작을 검증한 것이 아니다.

## 8. 카드·툴팁·대사 문맥으로 읽은 예시

아래는 문구의 사용 적합성을 확인하기 위한 **편집 예문**이다. 카드 구현·효과·숙련도 확정이 아니다.

| 용도 | 표시명 또는 문구 | 함께 읽는 설명·조건 |
|---|---|---|
| 신종목 인물 카드 | 무공: 총검술 | 능력만 표시. 스승·유파·무장 보유는 추가하지 않는다. |

| 유파 목록 | 죽검연환법 | 죽대를 쓰며 간격과 연속 대응을 익히는 검술. |

‘봉인절단법을 펼친다’ 같은 새 초식 대사는 쓰지 않는다. 실제 작업이면 ‘봉인을 자른다’고 쓰고, 정식 무공이면 해당 무공명을 쓴다. 이 구분이 작명과 설명을 다시 뒤섞지 않는 기준이다.
