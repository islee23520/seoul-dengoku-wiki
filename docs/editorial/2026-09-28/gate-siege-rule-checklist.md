# 신도림 연결부 사건 규칙 적용 체크리스트 (#22)

비게시 편집 기록. 대상은 위키 이슈 #22 「이야기: 「문을 닫지 않는 공성전」 세 과거 비교 실험」(원본 seoul-kenshi#86)과 그 사건 카드를 옮긴 `lore/chronology/Sindorim-Junction-Cargo-Gate.json`이다. 이슈 본문은 2026-09-28에 다시 읽었고 댓글은 없었다.

## 1. 전환 근거

계획 원장의 결정 3은 사람 플레이테스트를 이 스윕에서 하지 않고 세계관·서사 규칙 적용 검증으로 대체한다. 이 문서는 이슈 8절의 기록지와 품질 게이트웨이의 “사람 대상 실험” 표를 규칙 적용 항목으로 바꾼다. 규칙 적용 통과는 재미나 플레이 경험의 검증이 아니다.

| 이슈의 사람 실험 항목 | 바꾼 규칙 적용 항목 | 확인 방법 |
|---|---|---|
| 과거와 계획의 인과: 참가자 3명 중 2명이 과거와 계획의 관계를 설명 | C2 세 과거가 서로 다른 문 상태·허가·운반 능력을 만들고, 그 차이가 계획 표의 서로 다른 행으로 이어진다 | 사건 JSON `crossings`·`plans-table` 대조 |
| 해결 방식의 차이: 다른 두 해결과 비전투 한 경로 관찰 | C3 교전이 없는 결과가 세 과거마다 따로 있고, 우회에서는 주 통로 교전이 생기지 않는다 | `plans-table` 네 번째 열, `detour` |
| 기본 조건과 동료 변형 | W4 동행은 확인 시간과 정보만 바꾸고 허가·서류·과거를 만들지 않는다 | `companions-*` |
| 공정성과 부재 | W5 파티 한정 허가, 파손 문 닫기, 우회 강제 전투, 책임자 부재, 추가 의뢰 거절을 각각 처리한다 | 아래 3절 반례 표 |
| 중복 결과 | W6 같은 결과는 수령 확인으로만 처리하고 두 번 지급하지 않는다 | `revisit-p4` |
| 해석 범위 | P2 전투 선택은 계획까지만 적고 승패·사상자를 사건에서 정하지 않는다 | `plans-p2`, `record-table` |

## 4. 이슈 본문에서 공개 사건에 옮기지 않은 것

- 1절 진행 절차, 8절 참가자 순서표와 기록지, 품질 게이트웨이의 통과 기준: 사람 실험 절차이므로 이 문서의 규칙 적용 항목으로 대체했다.
