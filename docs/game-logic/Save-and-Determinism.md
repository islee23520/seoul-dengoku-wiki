# 저장과 결정론

## 재현 가능한 세계

캠페인 시드와 명령 기록을 다시 실행하면 같은 세계 상태와 사건 원장 해시가 나와야 합니다. 난수 흐름은 전투, 조우, 세계 사건처럼 용도별로 분리해 한 시스템의 호출 순서가 다른 시스템 결과를 흔들지 않게 합니다.

## 사건 원장

모든 상태 변경은 다음을 기록합니다.

- 원인 ID와 명령
- 세계 시간
- 변경 주체와 대상
- 변경 전후 요약 해시
- 규칙과 콘텐츠 버전

이 원장을 통해 “왜 노선이 봉쇄되었는가”, “왜 물가가 올랐는가”, “왜 인물이 세력을 떠났는가”를 설명할 수 있습니다.

## 저장 구조

저장은 버전이 있는 세계 상태, 명령·사건 위치, 콘텐츠 revision과 진행 중 전투 체크포인트를 포함합니다. 임시 파일에 쓰고 체크섬을 확인한 뒤 원본과 교체합니다.

지원하지 않는 버전, 잘린 파일, 잘못된 체크섬은 조용히 읽지 않습니다. 명확한 오류를 반환하고 이전 백업을 보존합니다.

## 전투 저장 지점

- 전투 컨텍스트 발행 전
- 전투 턴 종료 체크포인트
- 결과 정산 완료 뒤

중간 저장을 읽을 때 캠페인을 다시 조회하지 않고 저장된 불변 컨텍스트와 전투 명령 기록을 복원합니다.
