# 게임 명제

## 플레이어가 되는 사람

플레이어는 세계를 구하도록 선택된 영웅이 아닙니다. 한 역 사회에 흘러든 무명 인물이며, 작은 파티를 꾸리고 생업과 의뢰를 수행하면서 이름을 얻습니다. 수리, 의료, 운송, 경비, 교섭과 탐사도 전투만큼 중요한 성장 경로입니다.

## 장기 목표

서울을 하나의 국가로 통일하는 결말만 강요하지 않습니다. 노선 연합, 독립 역 사회, 지상·지하 공동체, 교역망 패권, 기술 복구 체제처럼 플레이 과정에서 형성된 정통성에 따라 여러 질서가 등장합니다.

## 단일 장르 문법

- 카메라는 yaw 45도, pitch 35.264도의 고정 직교 아이소메트릭입니다.
- 탐색, 상호작용과 전투는 같은 4방향 타일 격자에서 이어집니다.
- 자유 회전, 원근 탐색, 별도 실시간 전투 모드는 사용하지 않습니다.
- 캐릭터는 해당 시점에 맞춘 2.5등신 SD 실루엣과 네 방향 표현을 사용합니다.
- 한 타일은 1.5m이며 일반 통로는 최소 두 타일 폭입니다.

## 핵심 원칙

1. **실패는 세계에 남습니다.** 부상, 포획, 사망, 물자 손실과 관계 악화가 정산됩니다.
2. **인물은 정치의 단위입니다.** 직위, 관계, 기억과 계승이 세력의 행동을 바꿉니다.
3. **노선은 영토이자 물류입니다.** 역 하나보다 연결된 경로와 통행권이 중요합니다.
4. **전투는 전략의 결과입니다.** 보급, 동맹, 퇴로와 거점 상태가 전장에 들어옵니다.
5. **모든 상태 변화는 설명 가능해야 합니다.** 사건 원장으로 원인을 추적합니다.
