# G07 · 전해질화상군

이 페이지는 World-Narrative-Atlas의 읽기 전용 투영물입니다.

- 원본 앵커: `docs/game-logic/World-Narrative-Atlas.md`

비가 그친 용산 유치선에서 흰 염선이 전환기 쪽으로 길게 번진다. 길잡이 서진은 맨 앞에 서지 않고 마른 장갑 조각을 바닥에 던져 전도가 끊기는 지점을 찾는다. 첫 사건에서 플레이어는 승객 열차를 그대로 들이거나 삼십 분 동안 선로를 비워 장갑 변색 원인을 공개 조사할 수 있다. 열차를 밀어 넣으면 배차는 지켜지지만 숨은 웅덩이가 바퀴를 타고 신내까지 번진다. 둘째 사건은 냉각수 거래가 아니다. 용산 장부에 없는 폐전지 로트가 발견되면서 해동제철성 회수반과 가문 창고가 서로 책임을 미룬다. 플레이어가 로트를 봉인하면 냉동 화물 두 칸을 폐기해야 하고, 봉인을 풀면 전해질화상군이 누출 지도를 거두어 다음 우기의 안전 경로를 잃는다. 마지막에는 피부막 균열이 지휘 실패를 일으키지 않는다. 신내 승강기 바닥이 하나의 전도면으로 이어지자 세 회수조가 서로 다른 농도계를 내놓고 홀 전체의 전원을 끊자고 요구한다. 응급 환적을 살리려면 시민 참관인이 젖은 구간을 직접 표시해야 하며, 그 과정에서 누출을 숨긴 배차 가문의 이름도 공개된다. 합의 뒤 원장에는 괴물의 패배가 아니라 폐기 장갑 수, 정지한 열차 분, 다시 열 수 없는 창고 칸이 적힌다. 화상 흔적을 통행 자격으로 삼지 않는다는 약속은 선언이 아니라 다음 교대가 같은 장갑을 함께 쓰는 것으로 증명된다.

## 연결 시나리오

### G07-SC1 · 흰 염선의 배차

- 단계: 1
- 촉발: 비가 그친 용산 유치선에 흰 염선이 전환기까지 번지고 장갑 변색이 승객 열차 출발 직전에 관측된다.
- 관련 세력: S07, HC07, H07
- 생태 기제: 빗물이 받침대 염을 녹여 연무를 만들고 길잡이가 마른 장갑 조각으로 전도가 끊기는 지점만 표시한다.
- 선택지: 승객 열차를 정시에 통과시킨다 / 삼십 분 선로를 비워 변색 원인을 공개 조사한다 / 염선만 봉인하고 배차는 유지한다
- 결과: 정시 통과는 숨은 웅덩이를 신내까지 옮긴다. 조사 지연은 배차를 깨뜨린다. 부분 봉인은 원인 지도를 남기지 못한다.
- 도덕 비용: 승객 시간과 회수 노동자의 피부를 같은 아침에 저울질한다.
- 원본 항목: G07

### G07-SC2 · 장부 밖 폐전지

- 단계: 2
- 촉발: 용산 장부에 없는 폐전지 로트가 유치선 하층에서 발견되고 해동제철성 회수반과 가문 창고가 책임을 미룬다.
- 관련 세력: S07, S12, HC07
- 생태 기제: 로트의 누액이 전해질화상군의 농도 지도와 겹치므로 봉인 여부가 다음 우기 안전 경로를 결정한다.
- 선택지: 로트를 봉인해 냉동 화물 두 칸을 폐기한다 / 봉인을 풀어 누출 지도를 지킨다 / 로트를 신내 환적 홀로 옮겨 책임을 분산한다
- 결과: 봉인은 냉동 화물을 버리고, 해제는 다음 우기 지도를 지운다. 홀 이동은 염을 승객 동선에 퍼뜨린다.
- 도덕 비용: 누구의 장부 공백을 시민 회랑이 대신 갚을지 고른다.
- 원본 항목: G07

### G07-SC3 · 하나의 전도면

- 단계: 3
- 촉발: 신내 승강기 바닥이 하나의 전도면으로 이어지자 세 회수조가 홀 전체 전원 차단을 요구한다.
- 관련 세력: S07, S12, XT02, HC07, H07
- 생태 기제: 농도계가 서로 어긋난 채 바닥이 통전되면 길잡이도 경로를 지정하지 못하고 시민 참관만이 젖은 구간을 표시할 수 있다.
- 선택지: 홀 전원을 끊고 응급 환적을 멈춘다 / 시민 참관이 젖은 구간을 표시하며 환적을 살린다 / 서해곡창 냉동 유입을 우회시켜 염 부하를 바깥으로 돌린다
- 결과: 전원 차단은 환적을 죽인다. 표시 작업은 누출을 숨긴 배차 가문 이름을 공개한다. 외곽 우회는 오염 위치를 한 계절 고정한다.
- 도덕 비용: 오염을 어디에 둘지가 선택이며 창을 남기는 연출이 아니다.
- 원본 항목: G07
