노량진 방풍 골목의 경보등이 켜졌지만 세 문지기는 같은 문을 보지 않는다. 하나는 차압이 떨어졌다고 하고, 하나는 접지선이 살아 있다고 하며, 마지막은 약령행 환자 열두 명을 명부에서 찾는다. 첫 사건에서 플레이어는 경보가 울린 문을 봉쇄하는 대신 빈 천을 먼저 통과시켜 오염 방향을 확인할 수 있다. 검사가 길어지면 해열제가 늦고, 성급히 열면 먼지가 환자 대기실로 밀려든다. 둘째 사건에서는 여재와 전력을 맞바꾸지 않는다. 오래된 송풍기가 역회전해 남관 식량 검사대와 약령 부속실 중 한쪽으로만 먼지를 보낼 수 있게 된다. 플레이어가 비어 있는 부속실을 희생하면 다음 달 연구 공간을 잃고, 시장 쪽을 택하면 당일 경매 물량이 폐기된다. 셋째 사건은 컨트롤러의 붕괴가 아니라 판정권 분쟁이다. 성화궤도방위문이 통합 방호키로 전 문을 열려 하자 세 문지기 중 둘이 승인 도장을 거부한다. 의료 호송을 살리려면 플레이어가 특정 문 하나의 사후 책임을 떠안고, 오판이 드러날 경우 방호키 권한을 시민 감사에 넘겨야 한다. 사건이 끝난 뒤 커튼은 한 겹 줄지만 신뢰는 자동 회복되지 않는다. 누가 기침했는지가 아니라 어떤 문이 어떤 압력에서 열렸는지를 남긴 기록만이 다음 통행자의 자격을 지킨다.

## 연결 시나리오

### G08-SC1 · 빈 천의 방향

- 단계: 1
- 촉발: 노량진 방풍 골목 경보등이 켜졌으나 세 문지기가 차압, 접지, 약령행 환자 명부를 각각 다른 문으로 읽는다.
- 관련 세력: S08, HC08, H08
- 생태 기제: 입자 방향이 확정되기 전에 문을 닫으면 오염 출처가 가려지고, 빈 천을 통과시켜야 산란 방향이 드러난다.
- 선택지: 경보 문을 즉시 봉쇄한다 / 빈 천을 먼저 통과시켜 오염 방향을 확인한다 / 환자 열두 명만 우회시키고 문은 그대로 둔다
- 결과: 즉시 봉쇄는 출처를 숨긴다. 천 검사는 해열제를 늦춘다. 우회만 하면 대기실로 먼지가 밀려든다.
- 도덕 비용: 약령행 환자의 시간과 골목 전체의 호흡을 같은 경보음 아래 둔다.
- 원본 항목: G08

### G08-SC2 · 역회전 송풍

- 단계: 2
- 촉발: 오래된 송풍기가 역회전해 먼지를 남관 식량 검사대와 약령 부속실 중 한쪽으로만 보낼 수 있게 된다.
- 관련 세력: S08, S13, HC08
- 생태 기제: 여재와 전력을 맞바꾸는 거래가 성립하지 않고, 역회전 덕트가 두 공간 중 하나만 희생하도록 고정된다.
- 선택지: 비어 있는 약령 부속실로 먼지를 보낸다 / 남관 식량 검사대로 먼지를 보낸다 / 송풍기를 멈추고 두 공간을 함께 닫는다
- 결과: 부속실 희생은 다음 달 연구 공간을 잃는다. 시장 쪽은 당일 경매 물량을 폐기한다. 정지는 의료와 식량을 동시에 멈춘다.
- 도덕 비용: 누가 더러운 공기를 마실지가 자원 교환이 아니라 공간의 선택이다.
- 원본 항목: G08

### G08-SC3 · 거부된 방호키

- 단계: 3
- 촉발: 성화궤도방위문이 통합 방호키로 전 문을 열려 하자 세 문지기 중 둘이 승인 도장을 거부한다.
- 관련 세력: S08, S13, XT03, HC08, H08
- 생태 기제: 판정권이 키 한 장으로 모이면 차압과 접지와 명부가 동시에 무효가 되므로 문지기들이 개폐를 멈춘다.
- 선택지: 특정 문 하나의 사후 책임을 지고 의료 호송을 통과시킨다 / 전 문을 닫아 호송을 포기한다 / 방호키 권한을 시민 감사에 넘기고 해협삼로 먼지 부두를 우회한다
- 결과: 한 문 책임은 오판 시 키 권한을 시민에게 넘긴다. 전면 폐쇄는 당일 의료를 죽인다. 감사 이양은 통행을 느리게 하되 독점을 막는다.
- 도덕 비용: 살린 호송의 대가로 누가 다음 오염 판정을 잃을지 정한다.
- 원본 항목: G08
