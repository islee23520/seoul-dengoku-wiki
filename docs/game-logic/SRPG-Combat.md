# 전술 전투

![전술 전투에서 칸에 누가 서 있고 어느 쪽을 보며 어디까지 보이는지](https://github.com/islee23520/seoul-kenshi/blob/main/docs/assets/wiki/isometric-grammar.svg?raw=true)

## 탐색과 같은 문법

전투에 들어가도 카메라나 공간 규칙은 바뀌지 않습니다. 탐색에 쓰던 고정 직교 아이소메트릭 카메라와 1.5m 4방향 타일 격자 위에서 턴제 전술 규칙이 시작됩니다.

## 전투에서 다루는 것

- 캐릭터별 차례와 행동력
- 4방향 이동
- 무기, 생업 기술, 소모품과 환경 상호작용
- 부상, 쓰러짐, 포획, 후퇴와 사망
- 목표 점령, 탈출, 방어, 구조, 수리와 운송

## 전장의 기본 형태

| 원형 | 전술 특징 |
|---|---|
| 작은 역사 | 기둥과 상점, 짧은 교전 거리 |
| 환승역 | 층 전환, 여러 입구, 증원 경로 |
| 종착역 | 막힌 끝, 넓은 승강장, 차량 엄폐 |
| 터널 | 좁은 진형, 긴 시야, 퇴로 위험 |
| 지상 폐허 | 넓은 시야, 환경 노출 |
| 차량기지 인접 | 대형 설비, 수리 목표, 다중 경로 |
| 한강 횡단 구간 | 제한된 연결, 붕괴와 침수 위험 |

## 같은 상황은 같은 결과로

전장 생성, 명중, 피해, 사기와 증원은 전투 시드와 명령 기록으로 재현할 수 있어야 합니다. 같은 입력이 다른 결과를 만들면 검증 실패입니다.
