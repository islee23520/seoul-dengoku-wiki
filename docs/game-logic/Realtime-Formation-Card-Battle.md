# 실시간 진형·카드 전투

![한 판의 실시간 진형 카드 전투 위치 방향 시야 규칙](https://github.com/islee23520/seoul-kenshi/blob/main/docs/assets/wiki/isometric-realtime-formation-card-battle.svg?raw=true)

여기서 한 판은 확정된 전투 컨텍스트로 시작해 ResultId 하나로 끝나는 실시간 진형·카드 전투 세션 한 번을 뜻합니다. 한 판 안에서 진형·사기·카드 타이밍이 실시간 전술의 핵심 축이며, 위치·방향·시야는 진형 규칙으로 이어집니다.

> 2026-09-07 소유자 결정([Intent](https://github.com/islee23520/seoul-kenshi/blob/main/Intent.md) 결정 3)으로 전투는 턴제 SRPG에서 **실시간 진형·카드 전투**로 바뀌었습니다. 이 페이지는 옛 `SRPG-Combat` 페이지를 대체합니다. 현재 POC 런타임의 동일 격자 턴제 규칙은 이 계약이 구현되기 전까지의 과도 상태이며, 이 페이지의 설계가 구현 완료를 뜻하지 않습니다. 목표 형태의 근거는 [Songs of Silence](Ref-Songs-of-Silence.md)와 [라벨렌 전기](Ref-Ravelen-Chronicles.md) 조사입니다.

## 탐색과 같은 문법

전투에 들어가도 카메라나 공간 규칙은 바뀌지 않습니다. 탐색에 쓰던 고정 직교 아이소메트릭 카메라와 1.5m 4방향 타일 격자 위에서 진형이 배치되고, 시간은 고정 간격 틱으로 흐릅니다. 일시정지는 언제든 가능하며, 일시정지 중에도 카드를 낼 수 있습니다.

## 플레이어가 하는 일

플레이어는 유닛을 한 명씩 조종하지 않습니다. 입력은 세 가지뿐입니다.

1. **전투 전 진형 편집** — 누구를 전열·후열·측면에 세우고 어느 방향을 정면으로 둘지 정합니다. 리더의 지휘 반경 안에 있는 인물만 카드와 협공의 대상이 됩니다.
2. **전투 중 카드** — 인물이 부여하는 관계·생업·특기 카드와, 출격 전에 고른 거점 카드(최대 2)를 재충전이 허용하는 만큼 냅니다. 덱 구축과 무작위 드로우는 없습니다.
3. **후퇴·항복 판단** — 사기가 무너지기 전에 물러나거나, 적 지휘관의 사기·체력·퇴로 세 조건이 맞을 때 항복을 요구합니다.

## 전투에서 다루는 것

- 진형(전열·후열·측면)과 4방향 정면, 지휘 반경
- 사기 게이지 — 0이면 명령이 잠기고 궤주가 시작됩니다
- 인물 카드(관계·생업·특기)와 거점 카드(보급·통행권·설비)
- 지형 비용과 엄폐, 장치(수문·문·신호) 조작
- 예고된 증원 위치와 위협 표시
- 부상, 쓰러짐, 포획, 후퇴, 항복과 사망

## 전장의 기본 형태

| 원형 | 전술 특징 |
|---|---|
| 작은 역사 | 기둥과 상점, 짧은 교전 거리, 좁은 전열 |
| 환승역 | 층 전환, 여러 입구, 측면 노출과 증원 경로 |
| 종착역 | 막힌 끝, 넓은 승강장, 차량 엄폐 |
| 터널 | 한 줄 진형, 긴 시야, 퇴로 위험 |
| 지상 폐허 | 넓은 시야, 환경 노출, 기동 카드 유리 |
| 차량기지 인접 | 대형 설비, 수리 목표, 다중 경로 |
| 한강 횡단 구간 | 제한된 연결, 붕괴와 침수 위험 |

## 같은 상황은 같은 결과로

실시간이어도 결정론 계약은 그대로입니다. 전장 생성, 명중, 피해, 사기, 증원과 카드 플레이는 전투 시드와 틱 스탬프가 붙은 명령 기록으로 재현할 수 있어야 합니다. 같은 입력이 다른 결과를 만들면 검증 실패입니다.
