# 인물·세력·생업

## 인물

이름 있는 인물은 능력, 생업, 부상, 소속, 직위, 신념과 주요 사건 기억을 가집니다. 모든 인물 쌍의 관계를 저장하지 않고 친족, 사제, 지휘, 계약, 협력과 원한처럼 의미 있는 관계만 유지합니다.

## 파티

파티는 이동과 전투의 기본 단위입니다. 리더, 역할, 물자, 부상자, 현재 임무와 합법적인 위치를 가집니다. 리더가 죽거나 포획되면 정해진 승계 규칙으로 새 리더를 선택하고, 불가능하면 파티를 해산하거나 포로 집단으로 전환합니다.

## 생업

| 생업 | 세계에서 하는 일 | 전술 기여 |
|---|---|---|
| 정비사 | 전력, 셔터, 승강기, 차량 수리 | 장치 해제, 엄폐물 수리 |
| 물류상 | 물자 운송, 시장 연결, 통행 계약 | 보급 배치, 장비 교환 |
| 의무원 | 치료, 방역, 의약품 생산 | 부상 안정화, 상태 회복 |
| 순찰대 | 경로 안전, 호위, 질서 유지 | 진형 유지, 제압 |
| 전령 | 정보 전달, 외교 문서, 소문 수집 | 증원 요청, 지휘 범위 |
| 탐사원 | 폐쇄 구간 조사, 지도 갱신 | 함정 탐지, 우회로 확보 |
| 기록관 | 법통, 계약, 사건 원장 관리 | 목표 분석, 사기 지원 |

## 세력과 정통성

세력은 식량, 전력, 안전, 법통, 기술, 의료, 교역 같은 서로 다른 정통성 원천을 가집니다. 하나의 선악 수치로 판단하지 않습니다. 같은 정책도 어느 집단의 생존과 권리를 침해하는지에 따라 평가가 달라집니다.

## 계승

혈통뿐 아니라 양자, 사제, 직능 길드, 선거와 임명이 지도부 계승 경로가 됩니다. 지도자의 죽음은 곧바로 세력 삭제가 아니라 직위 공백, 경쟁 후보와 정책 분기를 만듭니다.
