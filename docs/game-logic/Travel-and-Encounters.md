# 이동과 조우

## 4방향 행동

동, 서, 남, 북 네 방향만 사용합니다. 대각선 입력은 행동을 소비하지 않고 거부됩니다. 탐색과 전투가 같은 격자를 사용하므로 이동 감각과 거리 판단이 바뀌지 않습니다.

## 이동 비용

기본 한 칸 비용에 다음 요소가 더해집니다.

- 계단, 사다리, 승강기 같은 층 전환
- 부상, 통증, 피로와 과적
- 어둠, 침수, 잔해와 화재
- 적대 세력 통제와 통행권
- 파티 규모, 은밀 이동과 호위 대상

## 경로 계획

세계 지도에서는 노선, 환승과 봉쇄를 비교합니다. 역을 선택하면 동일한 세계 그래프에서 세부 격자를 펼칩니다. 막힌 연결은 사라지지 않고 원인, 위험도와 복구 조건을 보여 줍니다.

## 조우 생성

조우는 캠페인 시드, 위치, 시간, 소음, 세력 통제, 최근 사건과 파티 상태에서 결정됩니다. 동일한 세계 상태와 명령이면 같은 조우가 생성되어야 합니다.

모든 조우가 전투로 이어지지 않습니다. 통행료 지불, 교섭, 수리, 의료, 정보 제공, 은신과 우회가 정식 해결 방법입니다.
