# 캠페인 루프

![캠페인 전 단계가 공유하는 고정 아이소메트릭 문법](https://github.com/islee23520/seoul-kenshi/blob/main/docs/assets/wiki/isometric-grammar.svg?raw=true)

## 여섯 단계

1. **거점 상호작용:** 정보, 주명, 계약, 관계 문제를 선택합니다.
2. **원정 준비:** 파티, 장비, 식량, 의약품, 경로와 통행권을 준비합니다.
3. **4방향 원정:** 같은 아이소메트릭 격자에서 지상, 역사와 터널을 이동합니다.
4. **조우 해결:** 교섭, 거래, 작업, 은신, 회피 또는 전투를 선택합니다.
5. **SRPG 전투:** 결정적 충돌을 동일 격자의 턴제 전술 규칙으로 해결합니다.
6. **세계 정산:** 부상, 시간, 물자, 관계, 평판, 거점과 노선 상태가 바뀝니다.

## 개인에서 세력으로

초기에는 파티 생존과 한 역의 문제를 다룹니다. 신뢰와 직능을 얻으면 작업반이나 상단을 이끌고, 이후에는 여러 역의 협약과 노선 세력의 정책에 개입합니다. 규모가 커져도 플레이어의 선택은 이름 있는 인물과 구체적인 사건을 통해 전달됩니다.

## 활동 단위

- 행동: 한 칸 이동, 대화, 작업, 공격 같은 즉시 결정
- 시간: 이동, 피로, 식량, 지역 일정
- 하루: 역 생산과 소비, 외부 파티 이동, 노선 안전
- 한 주: 외교, 인구 집계, 정통성, 세력 목표

플레이어 주변은 자세히 계산하고 멀리 있는 세계는 집계 단위로 처리합니다. 세계 전체를 같은 정밀도로 계속 계산하지 않습니다.
