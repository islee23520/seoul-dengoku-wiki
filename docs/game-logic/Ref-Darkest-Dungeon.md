> Red Hook Studios, 2016. 1월 (DLC: The Crimson Court / The Shieldbreaker / The Color of Madness / Butcher's Circus). 고딕 호러 로그라이트 턴제 RPG. 모든 수치는 Radiant/Darkest 난이도 기준.
>
> **출처 표기**: [S-01]~[S-09]는 문서 말미 출처 목록 참조. [문서]/[추론]/[미확인]으로 신뢰도 표기.

## 1. 개요

- **장르**: 사이드뷰 턴제 전투 + 던전 탐사 로그라이트 + 영지(햄릿) 경영. 조상(Ancestor)이 불러온 재앙을 청소하는 것이 전체 전제 [S-09][문서].
- **핵심 특징(설계 철학)**:
  1. **소모품 같은 영웅**: 영웅은 영구사망하며, 로스터는 Stage Coach에서 무료로 계속 보충. 핵심 난이도는 적의 강함이 아니라 **스트레스·부상·소모의 누적(Attrition)** [S-01][문서].
  2. **스트레스가 체력보다 중요한 2중 HP**: HP는 퀘스트 끝나면 회복되지만 스트레스는 마을에서 금화를 써야 치료 [S-02][문서].
  3. **빛·어둠 리스크-리워드**: 횃불 게이지는 안전과 이익 사이의 슬라이더 [S-04][문서].
  4. **불완전한 제어**: 영웅은 괴벽(Quirk)·질병·공포(Affliction)으로 플레이어 명령을 거부할 수 있다 [S-01][S-07][문서].

## 2. 코어 루프

주 단위(1 week = 1 던전 원정) [S-03][S-05][추론]:
1. **햄릿**: 로스터 점검 → 스트레스 치료, 괴벽 치료, 업그레이드, 모집
2. **원정 선택**: 지역 4곡 + 최종 던전. 난이도(견습/숙련/챔피언) × 길이(짧음/중간/긺)
3. **보급(Provisioning)**: 횃불·식량·삽·해독제 등 금화로 구입 [S-06][문서]
4. **탐사·전투**: 방-복도 그리드 이동, 전투, 큐리오 상호작용, 야영
5. **귀환·정산**: 보상 + 무작위 괴벽/질병 획득
6. 보스 잠금 해제 진척도 → 보스 원정 → 지역 레벨업 → 반복

## 3. 진행 구조

### 3.1 원정 길이 [S-03][문서]
| 길이 | 구성 | 야영 | 특징 |
|---|---|---|---|
| 짧음 | 소수의 방 | 0 | 위험·보상 최소. 야영 불가 |
| 중간 | 분기 던전 | 1 | 보스 퀘스트는 항상 중간 |
| 긺 | 극단적 분기 | 2 | 식량·횃불 대량, 스트레스 관리 필수 |

### 3.2 난이도 3단계 [S-03][문서]
- 견습 = 결의 레벨 1 / 숙련 = 3 / 챔피언 = 5
- 영웅이 퀘스트보다 **2레벨 이상 높으면 참가 거부**. 낮으면 입장 시 레벨당 스트레스 +20

### 3.3 퀘스트 목표 [S-03][문서]
청소 / 탐색 / 수집 / 활성화 / 보스 / 최종 던전(**중도 퇴각 시 영웅 1명 사망**)

### 3.4 결의 경험치 [S-03][문서]
견습 2/3/4, 숙련 4/6/8, 챔피언 8/12/16. 결의 레벨 0~6.

## 4. 경제 시스템

### 4.1 자원 [S-03][S-05][S-06][문서]
- **금화**: 보급·치료·업그레이드. 항상 부족한 흐름 자원
- **유물 4종** — 건물 업그레이드 전용: Bust(Abbey/Sanitarium), Deed(Blacksmith/StageCoach), Portrait(Guild/Tavern), Crest(만능 하위)
- **장신구**: 매각 750~7500(조상급) [S-08][문서]
- **보급품**: 원정 시작 시만 구입, 귀환 시 극히 일부만 환급 → 과다 구입은 순수 손해 [S-06][문서]

## 5. 캐릭터/파티 시스템

### 5.1 기본 구조 [S-01][문서]
- **파티 = 4명**, 위치 1~4번. 많은 스킬이 위치 조건부
- **클래스 15+2종**: 성기사, 도적, 광대, 역병의사, 성녀, 점성술사, 나병환자, 여전사, 사냥꾼, 현상금사냥꾼, 그레이브로버, 아버미네이션, 골동품상, 석궁병 + DLC: 채찍질자, 실드브레이커
- 전투 스킬 7개 중 4개 활성(전투 중 교체 불가), 야영 스킬 7개 중 4개 [S-01][문서]
- 주요 6스탯: ACC, CRIT, DMG, DODGE, PROT(상한 80%), SPD. 명중 = 스킬 기본명중 + ACC + 숨은 +5 − 대상 DODGE [S-01][문서]

### 5.2 로스터 관리
- Stage Coach **매주 무료 모집**, 업그레이드로 로스터 상한·모집 레벨 확대 [S-05][문서]
- 스트레스 회복 시설은 **1주일 점유** → 넓은 로스터가 필수 [S-02][S-05][추론]
- 로스터 방치 시 주당 스트레스 5 회복 [S-02][문서]

### 5.3 스트레스 시스템 (핵심) [S-02][문서]
- 게이지 0~200. 획득원: 적 스트레스 공격·치명타(10+동료 5), 던전 입장, 함정, 기아, 동료 사망 목격
- **100 도달 시 결의 시험**: 소확률 **미덕(Virtue)** — 스트레스 45 리셋+버프. 그 외 **공포(Affliction)** — 명령 불복종 [S-02][문서]
- **200 도달 시 심장마비**: 즉시 사경 진입, 사경 상태였다면 즉사 [S-02][문서]
- 회복: 마을 시설(금화, 1주), 캠핑, 전투 스킬, 치명타 성공 시 3, 적 처치 50%로 3 [S-02][문서]
- 퀘스트 완료로 HP는 회복되지만 **스트레스는 100에서 캡** [S-02][문서]

### 5.4 괴벽(Quirk) 시스템 [S-07][문서]
- 영웅당 긍정 최대 5 + 부정 최대 5
- 획득: 모집 시(긍정1+부정1 보장), 원정 후(성공 시 긍정 50−0.1×스트레스/부정 30+0.2×스트레스)
- 부정 괴벽은 **미션마다 25% 확률로 자가 고착** [S-07][문서]
- 요양원: 금화로 부정 제거·긍정 고착 [S-07][문서]

### 5.5 질병과 죽음 [S-01][문서]
- **사망은 영구**. 투자 전부 소실. 사망 원인: 직접 피해, 사경 추가 피해(Deathblow), 심장마비, 출혈/독, 최종 던전 퇴각
- 유일한 부활: 마을 이벤트 "From Beyond"(희귀) [S-01][문서]

## 6. 전투 시스템

- 턴제, 유닛당 1행동. 순서 = SPD + 무작위 1~8 [S-01][S-03][문서]
- 포메이션: 아군 1~4 ↔ 적 1~4(Large는 2칸). 이동(Move) 기술로 위치 재편이 핵심
- **치명타**: 1.5배 + DoT 2턴 연장. 영웅 치명타 = 스트레스 −3, 적 치명타 = 스트레스 +10 [S-01][문서]
- **치명적 치유**: 12% 확률, 회복량 2배 [S-01][문서]
- **시체(Corpse)**: 죽은 적이 자리 유지 → 위치 전략에 영향 [S-01][추론]
- **스톨링 규칙**: 회복/버프 2회 이상 + 잔여 적 2 이하면 증원군 소환 [S-01][문서]
- **표식(Mark) 시너지**: 표적+표식 소비 딜러 조합이 대표 빌드 [S-01][문서]

## 7. 지도/세계 구조

- **세계 = 부동산(Estate)**: 햄릿 + 4개 지역 던전 + 최종 던전 [S-05][문서]
  - 폐허(언데드) / 우리(인간·야수) / 숲(야생) / 만(엘드리치, PROT 높음)
- **던전 = 방+복도 그리드**. 이동 시 광원 소모(신규 6/재방문 1) [S-03][S-04][문서]
- **정찰**: 방 입장 시 확률 발동 — 함정/전투/보물 사전 표시 [S-03][문서]

## 8. 외교/세력

전통적 외교 없음. 대응 개념 [S-07][추론]:
- **적 유형 대응**: Unholy/Beast/Human/Eldritch에 따라 괴벽·장신구 효율 갈림
- **마을 이벤트**: 원정 성공 유형에 따라 호재/악재 [S-03][문서]
- **지구(Districts, CC DLC)**: 청사진+유물로 건설하는 패시브 시설 [S-05][문서]
- **조상 스토리**: 4개 지역 보스 각각의 기원이 조상의 죄 [S-09][문서]

## 9. 이벤트/내러티브

- **서술자 = 조상**: 회고 형식. 지역 보스 처치로 회고록 해금 [S-05][S-09][문서]
- 곡선: 쾌락에 물든 귀족 → 금지된 지식 → 굴착이 열어버린 심연 → 후손에게 유산과 청소 의무
- **최종 보스 2단계**: 조상(무적, 반영체 소환) → 어둠의 심장 — 세계 자체가 악이었음이 드러나는 결말 [S-09][문서]
- 던전 이벤트: 함정, 기아 체크, 밤 습격, 큐리오 상호작용 [S-03][문서]
- "계속 탐사할 것인가 vs 지금 떠날 것인가" — 매 원정의 이탈 판단이 핵심 선택 [추론]

## 10. 난이도/압박

**설계 원칙: 원시적 강함이 아니라 마모로 죽인다(Attrition over raw power)** [추론]

압박원:
1. **스트레스 잔존**: HP는 공짜 회복, 스트레스는 금화·시간 요구 [S-02][문서]
2. **영구사망+투자 손실**: 죽으면 박은 금화·유물 전부 소실 [S-01][문서]
3. **괴벽 자동 악화**: 원정마다 부정 괴벽 확률+25% 자가 고착 [S-07][문서]
4. **광원 경제**: 안전(횃불=금화) vs 이익(어둠=스트레스·Shambler) [S-04][문서]
5. **퇴각 비용**: 스트레스+부정 괴벽; 최종 던전 퇴각=영웅 1명 처형 [S-03][문서]
6. **확률의 층위**: 95% 표시도 연속 미스 가능(연속 미스 +4 ACC 보정 존재) [S-01][문서]
7. **경제 유출**: 성공해도 치료·보급이 수입 잠식 [추론]
