# 전략에서 전투로

![전략과 전투에서 칸에 누가 서 있고 어느 쪽을 보며 어디까지 보이는지](https://github.com/islee23520/seoul-kenshi/blob/main/docs/assets/wiki/isometric-grammar.svg?raw=true)

## 세계 상태는 한 곳에서

캠페인의 `WorldState`만 영속 상태를 소유합니다. 전투는 캠페인을 직접 수정하지 않습니다.

## 전투를 시작할 때 넘기는 정보

전투를 시작할 때 다음 정보를 한 묶음으로 확정해 넘깁니다.

- 전투, 캠페인, 위치와 참가자 ID
- 부상, 사기, 장비, 물자와 파티 구성
- 전장 원형, 지형, 위험과 목표
- 합법적인 퇴로와 증원 조건
- 세계 시간, 전투 시드, 규칙과 콘텐츠 버전

전투가 시작된 뒤에는 바깥 세계의 상태를 다시 가져오지 않습니다.

## 전투가 끝난 뒤 돌려주는 결과

전투가 끝나면 승패, 흐른 시간, 인물의 생사, 새 부상, 장비 소모, 전리품, 포로, 파티의 퇴로와 거점 통제 변화를 확정된 결과로 돌려줍니다.

## 결과는 한 번만 반영

`ResultId`는 결과를 구별하는 고유 값입니다. 이미 처리한 결과가 다시 들어오면 앞서 만든 영수증만 돌려줍니다. 같은 전투에 다른 결과가 들어오면 상태를 바꾸지 않고 복구 오류를 냅니다.

정산 순서는 인물 운명, 물자, 파티 위치, 시간, 거점·노선 통제, 관계·평판 사건입니다. 반영 전 검증 단계에서 모든 불변식을 통과한 뒤 한 번에 반영합니다.

전쟁 준비, 봉쇄, 철수와 점령 이후의 수치 규칙은 [전쟁과 공성](Warfare-and-Sieges.md)에, 거점 단계 전이는 [거점과 영토](Strongholds-and-Territory.md)에 정의합니다.
