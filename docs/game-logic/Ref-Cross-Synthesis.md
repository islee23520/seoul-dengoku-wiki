## 1. 무에서 시작(start from nothing)

| 게임 | 시작 구조 | 근거 |
|---|---|---|
| **K-시스템** | 13개 기본 시작. 결핍 축이 다양: 현금/매각자산/노동력/먹는 입/전투 숙련/합법 시장 접근/신체 손상(Rock Bottom은 왼팔 없음)/개시 적대(Holy Nation -100)·현상금. 0c인 Trader와 0c인 Rock Bottom은 전혀 다른 경제. 난이도 표기는 이후 성장 배율에 영향 없음 | [문서: S82, S83] |
| **Battle Brothers** | 15개 기원. 시작 보너스가 아니라 장기 규칙: Peasant Militia(16인 출전·Lowborn만 고용), Lone Wolf(1인 사망 시 종료), Trading Caravan(매매 유리·명성 획득 66%), Manhunters(포로 충원·비율 의무) 등 | [문서: S96, S98] |
| **CK3** | 플레이어는 군주·가문에서 시작. '무(無)'가 아니라 '상속받은 부담'에서 시작 | [문서: S19, S30] |
| **FE 각성** | 서사 지정 시작. 챕터 진행형 | [문서: S01] |
| **FFT** | 직업·잡지로 시작. 파견·모집이 있는 도시 경제로 진입 | [문서: S02 pp.25–39] |
| **Triangle / 파랜드 / 창세기전 / Langrisser / TO** | 모두 서사·챕터 지정 시작. Triangle은 신념 축이 초기 분기 | [문서: S05–S09, S11] |

**최고: K-시스템** — '무에서 시작'을 단일 난이도가 아니라 **결핍의 조합**으로 설계.

**잔선 권고 [적용 제안]:** 기본 기원은 '공동 피난에서 살아남은 3인 밴드' — 안전한 B1 공용 대합실 임시 잠자리, 손수레 1대, 약 3일분 식량. 결핍은 '안정 식량 수입·긴 휴식 권리·적재량·신뢰 거래처'.

## 2. 경제 압박 루프

| 게임 | 압박 구조 | 근거 |
|---|---|---|
| **Battle Brothers** | 매일 급료+식량(1인당 하루 2, 부패 기한)+수리·의약·탄약. 지도 시간이 흐르는 동안에만 비용 발생. 계약 순이익 = 완료금+전리품 − 여행/회복 기간 급료 − 보급 − 대체 고용 | [문서: S47, S97, S102–S105] |
| **K-시스템** | 허기 시간 소모, 200 미만 영양실조→능력 저하→실신·사망. 악순환: 굶음→느려짐→습격 회피 실패→부상→수입 중단 | [문서: S84–S86] |
| **CK3** | 금·세금·병력 유지비. 압박이 개인 서사(스트레스)와 결합 | [문서: S19–S21] |
| **FFT** | 파견은 비용·기간·적자 가능성 명시. 월드 1구간=1일 | [문서: S02 pp.25–29] |

**최고: Battle Brothers** — 시간 자체가 비용이고, 모든 여행·회복·대기가 손익 계산에 들어간다.

**잔선 권고 [적용 제안]:** 압박 3종 = 공동 식량 일일 소모 + 계약 인력 수당 + 안전한 회복의 시간·비용. 확정한 이동·휴식·작업만 캠페인 시간 진행. 저수익 안전 작업과 고수익 위험 작업 병존.

## 3. 캐릭터 사망/부상 처리

| 게임 | 처리 | 근거 |
|---|---|---|
| **K-시스템** | 쓰러짐≠사망. 부위별 HP, 절단→의수·의족. 패배가 노예화·납치로 이어져도 플레이 계속 — 당한 일 자체가 다음 목표 생성 | [문서: S83, S84, S86, S87, S94] |
| **Battle Brothers** | 영구 부상 = 능력치 영구 감소, 전투 후 결과 화면 확정 표시. 사망은 사망 | [문서: wt-Permanent-Injuries, wt-Morale; S98] |
| **FE 각성** | Classic=영구사망, Casual=해당 전투에서만 퇴각. 주인공 사망은 게임오버 | [문서: S01 §14] |
| **Triangle** | 영구사망 없음, 패배·퇴각해도 EXP/Kudos 보존 | [문서: S07] |

**최고: Battle Brothers(+K-시스템)** — BB는 '결과가 인물에 남는다'를 정산 UI까지 일관, K-시스템는 '실패 후에도 선택과 진척이 남는다'를 극한까지.

**잔선 권고 [적용 제안]:** 사망 계층 3단계 — ①쓰러짐(전투 불능, 회복 가능) ②부상(다음 원정·전투 시작 상태에 이어짐, 정산 영수증 표시) ③사망(명시적 규칙이 있는 행동에서만). 현재 POC의 'HP 7 → 다음 전투 10 초기화'가 바로 고칠 지점.

## 4. 전략 계층 ↔ 전술 계층 연결

| 게임 | 구조 | 근거 |
|---|---|---|
| **Battle Brothers** | 전역 지도(전략+여행 통합) → 육각 전장. **접촉 지형이 전술 지형을 제약**. 진형 슬롯이 시작 위치 | [문서: S40–S42, S45, S50] |
| **FFT** | 노드 월드(1구간=1일) → CT/AT 사각 전장. 월드에서 편성·파견 | [문서: S02] |
| **CK3** | 그랜드 전략 지도 하나에서 전투 해결(수동 전술 전장 없음) | [문서: S67, S68] |
| **Triangle / 창세기전 2** | 세계 사건 지도(W)+지역 탐색(E)+전장(B) 3면 | [문서: S05–S07, S66] |

**최고: Battle Brothers / FFT** — 전략적 결정이 전술 결과에 그대로 이어지고, 전술 손실이 전략 경제로 반환.

**잔선 권고 [적용 제안]:** genre-map-structure §10의 3지도 구조 채택 — S 노선도 / W 역간 원정 / B 하이트맵 전장. 전환 계약: S 선택은 이동이 아님, 전투 후 자동 강제 귀환 없음.

## 8. 종합 우선순위 (잔선 구현 순서 권고)

1. **P0 — 떠돌이 경제 한 바퀴:** 3인 밴드+손수레+3일 식량 시작 → 계약 선택 → W 이동 → 조우 3카드 → B 수동 전술 → 정산 영수증(인물별 부상 포함)
2. **P0 — 부상 지속:** BB 영구부상 문법. 부상이 다음 전투 시작 HP·명중에 이어짐.
3. **P1 — 세계 두 속도:** 부속시설 상태 + 핵심 인물 상태 전이.
4. **P1 — 모집·조직:** 관계 기반 동료 + 계약 인력 분리.
5. **P2 — 정착 선택:** 'B1 정비실 운영권' 수준에서 시작해 역 전체 주권은 후반.
