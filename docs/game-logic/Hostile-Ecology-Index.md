## G01 · 범람멧돼지군

- 현대 불안: 홍수 후 도심 멧돼지 출몰과 쓰레기 경쟁
- 허구 기원: 붕괴 이후 S01·S06 회랑에서 범람멧돼지군이 형성된 서울 창작 기원이다.
- 영역: S01 핵심 서식, S06 계절 이동, XT01 외곽 압력에 반응한다.
- 경제: 에너지·고철·유기물·냉각수 중 구역 잔여 자원을 순환하며 HC01 회수 작업과 경합한다.
- 생애: 출현-확산-정체-협상가능-와해 5단계. 복제는 자원 상한에 묶인다.
- 감각: 진동·열·전자 잡음·냄새 중 둘 이상. 완전 투시 없음.
- 위계: 컨트롤러 1 + 무리 단위. 합성 H01 센서 로그와 충돌 시 인간 중재 우선.
- 연결: {"states":["S01","S06"],"houses":["HC01"],"theaters":["XT01"],"synthetics":["H01"],"corporations_successor_only":["HC01"]}
- 상승 1-3: 1 경고 출몰 / 2 인프라 교란 / 3 거점 봉쇄. 3은 협상 창 닫힘 직전.
- 교전: 소음·냉각·봉인·먹이 우회·경로 차단. 학살 올인 금지 설계.
- 교섭: HC01 중개로 자원 할당·통행 시간 거래 가능. 전멸 조건 없음.
- 도덕 비용: 무차별 제거는 시민 인프라와 공생 가능성을 함께 부순다.
- 시나리오: G01-SC1, G01-SC2, G01-SC3
