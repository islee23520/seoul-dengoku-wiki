Subject / Medium / Composition / Lighting / Mood 6부 구조를 따른다(캐릭터 미술 방향의
프롬프트 규칙과 같은 골격). 매체는 독자적 반실사 동아시아 전략게임 키 일러스트,
무광 손그림 질감, 절제 팔레트.

공통 금지(프롬프트에 명시):

- 중세 갑옷·로브 — 인물은 실용 살루지 작업복 + 즉흥 의례 장식
