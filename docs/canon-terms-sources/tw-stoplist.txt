# TW:WH 이름 생성기의 단어 분류 (gen-tw-bans.mjs가 읽는다)
# 자동 구역: 제목 단어 중 사전(https://raw.githubusercontent.com/dwyl/english-words/master/words_alpha.txt)에 있고 빈도 순위(https://norvig.com/ngrams/count_1w.txt)가 60000 안이면 stop, 사전에 있으나 드물면 cs.
#   stop = 일반 영어(단독으로 금지하지 않는다). cs = 대문자 표기만 잡는다. 어느 쪽도 아니면 조어로 보고 대소문자 무시로 잡는다.
# 수동 구역: 줄 앞 키워드 stop|cs|coined <단어> 와 drop <제목 전체>. 자동 구역보다 우선한다.
# 갱신: node scripts/pages/gen-tw-bans.mjs --fetch (수동 구역은 보존된다)

## manual (--fetch는 이 줄 아래를 보존한다)
# 수동 구역: 자동 구역보다 우선한다. 이유를 줄 끝 # 뒤에 적는다.
stop hierophant  # 이 위키의 정본 용어(아크 직제). Hierophant 단독 금지 불가. Khatep 등 이름은 따로 잡힌다
stop ironhide  # 위키 문서의 적대 개체 이름 'Tender Ironhide'(Hostile-Group-G01)와 겹친다. Grimgor는 따로 잡힌다
stop swordmasters  # 일반 영어(검술 교관). Swordmasters of Hoeth는 Hoeth로 잡힌다
stop skirmishers  # 일반 군사 용어. GDD 080에 범주 이름으로 쓴다
stop men-at-arms  # 일반 중세 용어. GDD 080에 쓴다
stop knight  # 직위·일반어(인물 데이터 090의 Rank: Knight)
drop Caravan Master  # 이 위키의 직업명(인물 데이터 050·090 상단주). 일반어로만 된 구는 금지하지 않는다
drop Supply Train  # 일반 군사 용어
drop Camp Tyrant  # 일반어 구
stop yuri  # 이 위키 인물 데이터에 Sim Yuri(050·090·110)가 있다. Prince Yuri는 구 전체로 잡는다
stop ying  # 중국계 흔한 음절. Miao Ying은 구 전체로 잡는다
stop xing  # 흔한 음절. Wu Xing War Compass는 Compass 보강 목록으로 잡는다
stop zhao  # 흔한 성. Zhao Ming은 구 전체로 잡는다
drop Men-at-Arms  # 일반 중세 용어. GDD 080 본문에 쓴다
