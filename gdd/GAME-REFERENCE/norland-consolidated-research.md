조사 범위: 2026-09-29 기존 게임 조사서·UI 기록과 2026-09-30 플레이 로그의 평가·통합. 빌드: `v0.5588.9777.0`. 기존 저장과 개발자 생성 상황을 분리했다. 이 통합본은 게임 맥락을 이해하기 위한 독립적인 조사서이며, 실제 전술 명령·피해·승패 검증은 미완료다. 기존 `GAME-REFERENCE/norland-combat.md`의 데이터 분석을 보존하되 재검증 여부를 명시한다.

## 1. 개요와 증거 범위

[관찰] 영주·주민·건물·경제를 관리하는 정착지맵과, 도시·영지·이동 군대를 다루는 월드맵이 구분된다. 군대 관리와 고용은 지도 위 패널이며 독립 공간 지도가 아니다.

[문서] 공식 Patch 41은 `-debug` 실행과 Ctrl+D 개발자 메뉴, 전투 시뮬레이터 제공을 설명한다. 시뮬레이터의 존재는 수동 전장 진입의 증거가 아니다. [S1]

## 2. 코어 루프와 전투 준비

[관찰] 초기 정착지는 5일 차 17:00, 금 3000, 음식 180/250이었다. 용병 Zhivobor의 초상화를 선택한 뒤 금 2888, 후보 12명으로 변했다. 가격은 112골드, 계약은 10일, 장비는 단검으로 표시됐다.

[관찰] 지불 완료 뒤에도 전사는 `Hired warrior en route` 상태였고 13시간 도착 예정이었다. 비용 지불, 도착, 분대 편성, 파견은 서로 다른 사건이다. 다음 날 시간이 됐다는 사실만으로 도착이나 편성이 끝났다고 판단하지 않았다.

[문서] 일반 공격 경로는 전사 확보 → 지휘관·장비가 있는 분대 생성 → 월드맵 대상 선택 → Attack/On Local Map → 분대 선택과 Send Army → 도착 후 교차검 표시에서 전투 선택이다. 이는 2024년 공략의 설명이며 현재 빌드 전체 경로가 재현된 것은 아니다. [S2]

## 3. 진행과 시간 맥락

[관찰] 군대 창이 열렸을 때 시계가 진행되지 않은 입력이 있었다. 창을 닫고 Space를 보내자 17:00에서 17:14로 진행됐다. 이후 6일 차 09:05에 다시 일시정지했다. 음식은 171/250으로 표시됐다.

[추론] 플레이 조사에서 공간 맥락뿐 아니라 최상위 창과 시간 상태를 함께 기록해야 한다. 반응 없는 입력이 항상 게임 규칙의 금지를 뜻하지는 않는다.

### 경제·캐릭터·압박

[관찰] 금은 모집 즉시 차감됐고 음식은 시간 진행 이후180/250에서171/250으로 표시됐다. 맥주5/100,전쟁 물자5/20,원자재300/300은 자원 HUD에 표시됐다. 원자재300/300을 인구로 기록한 이전 UI 설명은 재확인이 필요하다.

[기존 기록] 29일 군대 패널은 네 영주와 전사0명, 창5개를 기록했다. 모집 후보는 풀려난 수감자0명, 농민1명(전투2,40골드),용병13명(전투7~9)이었다. 29일 기록의 Boromil과 30일 관찰의 Zhivobor는 날짜별로 구분한다.

[관찰] 겨울까지 남은 일수, 경제 보고서, 이웃 통치자 서신, 영주관 시종 부재와 동맹 제안 알림이 시간·경제·정치 맥락을 함께 전달했다. 알림의 모든 후속 선택과 결과는 확인하지 않았다.

## 4. 지도와 세계 구조

[관찰] 도움말 창을 닫고 세계 지도 아이콘을 선택한 뒤 고르노·브라이트홀로와 도로·영지 경계가 표시됐다. 고르노 선택 패널에는 보유 전사 1명과 교차검 수치 7이 있었다. 수치 7의 계산식은 확인하지 않았다.

[관찰] 도시 패널의 병력 정보와 월드맵에 등장한 Faleros 13명·Vechensil 11명 표식은 별도 대상이다. 이 표식이 생겼다는 사실만으로 직접 편성한 용병이 파견됐다고 설명하지 않는다.

## 5. 개발자 도구로 만든 상황

[관찰·개발자 보조] 도시를 선택한 Pretty Debug Object 검사기에 `GlobalMapObject`와 `Add Player Defence Army`, `Attack By Forest Bandits`가 나타났다. 두 동작 이후 군대 표식과 적대 분대 알림이 표시됐다. 일반 분대 편성과 파견의 대체 테스트 상황이다.

[관찰] Global 탭에는 빠른 지도 이동·작업 완료, 안개 해제, AI 공격 허용, Faceless 도시 생성·제거 도구가 있었다. 표시된 모든 치트를 실행한 것은 아니다. Help 탭에서 분대 생성 도움말 해금은 확인됐다.

[기존 기록] 29일 도적 진영에는 도적7명과 전리품160골드·활4·창2가 기록됐다. 별도 이동 도적 고용 팝업은 무장하지 않은 도적7명·전투5·가격350·이웃 관계-7을 표시했고 실행하지 않았다. 진영 전리품과 이동 인물 장비는 다른 정보다.

## 6. 로컬 병력 등장과 전투의 경계

[관찰] 시간을 진행한 뒤 로컬 숲 지형에 개별 병사, 적측 해골 깃발, 이름과 기분 79, Faleros 13명·Vecheosil 11명 카드가 보였다. 정착지 자원 HUD와 건설 툴바도 유지됐고 개발자 격자가 표시됐다.

[미확인] 별도의 원정 전장으로 전환된 것인지, 정착지 방어 상황인지, 해당 표식의 플레이어 제어 가능 범위는 확정하지 못했다. 초기 전장 진입 설명은 정정한다. 직접 이동·공격 명령과 피해·퇴각·승패는 검증되지 않았다.

[관찰·정정] 6일 차 11:19에는 두 부대 카드의 숫자가 유지됐다. 초기 캡처에서는 병사 위치를 확인하지 못했지만, 후속 `norland-world-find-faleros.png`에는 로컬맵 진입 지점의 Vecheosil과 개별 병사가 보인다. 모든 병력이 카메라 밖에 있다는 설명은 정정한다. Faleros의 실제 위치는 여전히 확인하지 못했다. 카드의 존재나 숫자 유지는 교전 종료·승리의 증거가 아니다.

[관찰] 이후 직접 선택된 Vecheosil 부대의 정보 패널은 거동 가능 11명, 전투 스킬 10, 장비 값 3362, 사기 79, 전사의 기본 기분 +53, 지휘관 스킬 +25를 표시했다. 표시된 구성 요소의 합과 사기 값 사이의 계산·반올림은 확인하지 않았다. 교차검 탭을 선택하면 지휘관과 병사의 장비·구성 목록이 나타났다. 이것을 수락된 전술 명령으로 해석하지 않는다.

[사용자 보고·전환 미검증] 다른 위치의 부대를 선택하면 월드맵으로 이동한다는 설명을 받았다. 새 캡처 `norland-command-panel-user.png`와 `norland-selected-squad-orders.png`는 로컬맵의 적군 정보·병력 목록을 보여주므로, 원격 부대 선택과 현재 시야 안의 부대 선택을 구분해 재확인해야 한다. 부대 카드가 보인다는 사실만으로 그 부대가 현재 카메라에 있다고 판단하지 않는다.

## 6.1 최종 교전·패배·보강 관찰

이 후속 절은 초기 기록의 ‘피해·승패 미검증’ 범위를 갱신한다. 개발자 도구로 만든 정착지 방어 상황에서 실제 교전과 손실은 관찰했으며, 수락된 전술 이동·공격 명령과 별도 승리 결과창은 미검증이다.

[관찰] `norland-faleros-direct-panel.png`에는 Faleros 분대 ‘전투 중’, 거동 가능4명, 전투 스킬10, 장비1266, 사기9, 분대 손실-9, 지휘관 잃음-23이 표시됐다. Faleros 사망 알림과 쓰러진 병사·피도 확인됐다. 초기13명 카드와 거동 가능4명을 같은 척도로 취급하지 않는다.

[관찰] `norland-cheat-recovery-pause.png`의 금은1448이며 도적이1440골드를 훔쳤다는 알림이 표시됐다. 이 사건은 방어 실패·약탈로 기록한다. 승리 알림이나 되돌린 결과가 아니다. 자동저장 안내는 이후 화면에 나타났으나 수동 저장은 하지 않았다.

[관찰·개발자 보조] 사용자 요청으로 살아 있는 Mirosvet의 스킬 합계를47→65로 올렸고 일반 툴팁에서 전투·명령 각7을 확인했다. 직접 제어 옵션으로 Shirka와 Mirosvet 부대를 각각 생성했다. Mirosvet의 Battle Squad에서13–17 프리셋을 선택해 병사를 추가했으나, 프리셋 이름만으로 실제 병사 전체 능력을 단정하지 않는다.

[관찰] `norland-mirosvet18-power.png`의 Mirosvet 부대는 거동 가능18명, 전투 스킬7, 장비7720, 사기11이다. 지휘관 개인 강화와 분대의 최종 사기는 별개다. 기본 기분+33, 지휘관 보너스+18이 보였지만 계산식은 검증하지 않았다. 명령 없이 사격·궁수 조준·궁수 보호·후방 잔류·분대 편집 컨트롤의 존재를 확인했다. 토글 효과와 이동·공격 명령의 수락은 미검증이다.

[조사 종료 경계] 첫 방어 실패는 보존하고 보강 이후 승리를 만들지는 않았다. 사용자가 전투 조사 완료 후 종료를 지시해 추가 교전은 중단했다. 초기 문서의 미관찰 서술은 당시 범위로 읽고, 현재 결론은 이 후속 절을 우선한다.

## 7. 잔선 적용 검토

[추론] 고용·이동 대기·편성·파견·교전은 명시적인 상태로 분리할 필요가 있다. 지도상의 숫자에는 보유 전사 수인지 이동 분대 수인지 의미가 드러나야 한다. 명령 실패는 대상 상태, 최상위 창, 이동 중 여부와 함께 확인해야 한다.

이는 참고 게임에서 얻은 설계 검토 의견이며 잔선의 승인된 규칙이나 구현 변경이 아니다. Norland의 일시정지·속도 제어를 잔선 전투에 그대로 적용하는 제안도 아니다.
