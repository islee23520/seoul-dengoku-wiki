2026-09-28 조회. 최신 #296 본문과 [GDD #31 head 65e523f](https://github.com/islee23520/seoul-dengoku-gdd/blob/65e523f55ff62ec1142946d13b9c50e18c181445/canon/locales/ko-KR/rules/hero-squads-and-simultaneous-turns.json) source.b18–b24를 읽었다. 시간 기반 방향·다섯 태세·전체 경로 검사·AI 동일 계약은 디렉터 기준이다. 원천 PR은 미병합이다. 본 문서는 수학/이벤트 후보이며 정본 수치나 Unity Core 구현이 아니다. 카메라·초상 지시는 이동 물리식의 근거가 아니다. 원천의 source.b26에 남은 ‘턴’ 표기는 해당 정본 작업 소유자에게 넘기며 이 제안이 중복 수정하지 않는다.

## 단위·유도·출처 경계

도로/지상은 surface, 지하는 subway, 다른 층 이동은 명시 transfer만 허용한다. 모든 비용 합은 안전정수 범위를 검사한다. 0분모·음수비용·overflow는 COST 입력 실패이며 ‘일정 시간 안에 못 도착함’은 합법 진행 상태다. 턴 예산 부족을 시간 기반 실패로 바꾸지 않는다.

## 두 합성 분대 손계산

실제 인물이나 밸런스 수치가 아니다. fixture는 외부에서 지정한 분대 속도를 입력으로 받는다. A의 통상/강행군/매복은 4/2,6/2,2/2 W/T, B는 3/2,5/2,1/2 W/T. 양쪽 주둔·야영은 0/2다. 모든 태세를 입력하며 기본값이 없다. 강행군 공격·요격 개시 거부, 피격 가능; 야영 공격 개시 거부는 별도 검사다. 태세 변경·회복·매복 탐지는 구현하지 않는다.

지도: S0→S1 도로 8D×1/2=4W; S1→U0 출입 2D×1+2W=4W; U0→U1 지하 6D×2=12W. 합계20W.

| 입력 | ΔT=5 계산 | 위치/범위 |
|---|---|---|
| A 통상 | 4×5/2=10W, r0 | S1·U0 도달, 지하에2W 진척. 10T에 U1 도착 |
| B 통상 | 3×5/2=7W,r1 → 실제7.5W | S1 도달, 출입에3.5W 진척. 13T에19.5W,14T 관찰에서 U1 도착(연속 도착시각40/3T) |
| A 강행군 | 6×5/2=15W,r0 | 지하에7W 진척 |
| B 강행군 | 5×5/2=12W,r1 →12.5W | 지하에4.5W 진척 |
| A 매복/주둔/야영 | 2×5/2=5W /0W /0W | 출입1W /S0 /S0 |
| B 목표 교체 | t5에7.5W 유지; U0→U2를4W 경로로 교체; +3T×1.5=4.5W | t8에 총12W로 U2 도착. 원래 명령이면 같은12W이지만 U1 방향 지하 중간 |
| U0 통제권 | 경로를 U0에서 끝내면 총8W에 정지 | 통과 경로 전체 거부; 도착 후 보통 MOVE 재출발 거부 |
| 봉쇄/통행권 없음 | 새 경로 마지막 간선 blocked/allowed=false | 전체 거부, 기존 위치·명령·revision 불변 |
| 비용 실패 | 분모0,부가작업−1,2×MAX_SAFE 거리 | 정수/overflow 오류, 기존 위치·명령 불변 |

W는 물리 좌표가 아니다. 비용 구간의 W 진척을 지형 위 3D 좌표로 보간하는 계약은 이 연구에 없다. `reachableOnPath`는 지정된 합법 경로에서 horizonT 안에 새로 도달할 노드만 반환하며 지도 전체 최단경로/도달 영역 탐색은 미구현이다. 범위 표시는 도달 예측이지 이동허가나 턴 한도가 아니다.

## 명령 교체·AI·재생

권위 이벤트 시각까지 기존 명령을 먼저 전진시킨다. 새 MOVE는 controllerId 권한·전투 잠금·시각·expectedRevision·전체 경로를 검사하고 성공 시 orderId/revision/path만 교체한다. 현재 간선과 이미 지난 prefix의 비용/정체성을 정확히 보존해 도중 분수 진척을 복사한다. 실패 시 이미 유효하게 흐른 시간을 되감지 않고 이벤트 시점의 기존 명령·위치를 유지한다. 간선 안에서 즉시 뒤돌기, 현재 간선의 지형/권한 변경은 지원하지 않으며 승인 전 후보 범위를 넘지 않는다. 최신 ‘이동 중 교체 가능’ 방향의 제한된 증명이지 모든 재탐색 구현 완료가 아니다.

AI/플레이어가 같은 함수·권한·비용·속도를 사용한다. AI 표시는 권한을 우회하지 않는다. 원장에는 명령 ID·권위시각·revision·행위자, 비용/경로/태세/속도/진척의 의미 필드와 이전 SHA256을 포함한다. 키 정렬, 경로 배열 순서 보존, 표시용 메타데이터·hostOrder 제외. 동일 이벤트 기록은 동일 영수증 해시이며 비용변경은 해시를 바꾼다. 동일 시간 분할은 위치만 같게 만들며 이벤트 개수가 다른 원장의 해시까지 같다고 주장하지 않는다. 네트워크 중복 영수증·충돌 우선순위·승인 레코드 진위검증은 미구현.
