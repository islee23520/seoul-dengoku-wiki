# #291 공개 데모 검증

상태: **공개 접근 FAIL, F1–F4 최종 판정 및 플레이·시각·정산 검증 미실행**. 2026-09-28 확인. 배포를 변경하거나 Access 제한을 우회하지 않았다.

## 실제 관찰

- 익명 HTTP: `https://seoul-dengoku.linalab.io/tripothon/` 및 `/play/` 모두 302, Cloudflare Access 로그인으로 이동.
- Codex 실제 브라우저에서 /tripothon/을 열었을 때 제목은 “Sign in ・ Cloudflare Access”, 화면에는 “Log in to seoul-dengoku”와 이메일/로그인 코드 입력이 표시됐다. [실제 접근 차단 화면](../../../evidence/pr-308/tripothon-access-wall.png). 이 이미지는 로그인 제한의 증거이며 요청된 1920×1080 게임 플레이 캡처가 아니다.
- owned omowright 검사도 실행했으나 이 환경에서 새 탭이 about:blank에 머물며 스크린샷 타임아웃이 났다. [첫 실행](public-demo-evidence/report.json), [두 번째 실행](public-demo-evidence/report-second-attempt.json). 이 실패를 실제 게임 오류나 플레이 통과로 세지 않는다. 실제 접근 제한 화면은 별도 Codex 브라우저로 확인했다.
- 임시 owned 브라우저와 프로필을 정리했고, 접근 확인용 Codex 탭도 닫았다. 사용자가 열어 둔 위키 미리보기는 보존했다.
