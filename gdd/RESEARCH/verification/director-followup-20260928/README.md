- 판정은 GURPS 4판 공격3d6·능동 방어·DR·피해 유형·충격·주요 부상·HP0 이하 판정, 진행·UI는 노랜드다. 도주는 의지 기반 공포 판정에 기분·리더십을 보정한다. 보정 크기와 Core API는 미정이며 기존 POC 수치를 새 규칙으로 해석하지 않는다.
- 교전을 시작한 부대는 종료까지 새 명령을 받지 않는다는 최신 문구를 QA와 촬영 계약에 반영했다. 종전의 근접 교전만 잠그는 문구보다 범위가 넓다. 전투 전체 후퇴 명령과의 접점은 소유자 Core 계약으로 검증한다.
- 영웅 충성0~100, 군주100,25 미만 지속 시 후계 반란/이탈 방향과 기존 신뢰 `T[A,B]`의 친구≥25/적≤-25/숙적≤-50 구간을 구분한다. 보상·위협은 충성·기분만 바꾸며 신뢰T·정통성을 직접 바꾸지 않는다. 기간·일일 변화량·비용·효과 크기는 미정이다.
- Wiki304의 시연 긴장도T·세력점수F는 인물 신뢰 `T[A,B]`나 충성 입력이 아니다. 이동 fixture의 시간T도 다른 단위다. 자동 매핑·수치 채택은 하지 않는다. GDD32는 이동 제안만 다루므로 #33의 소유자 문서를 이 브랜치에 복제하지 않는다.
