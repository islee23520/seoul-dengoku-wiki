# Seoul-only web terrain preparation

The 184 `public/regional-*` raw terrain paths remain byte-for-byte Git inputs for the native GAME sync. They are not part of the reviewed wiki web artifact. The four checked-in `public/seoul-terrain*` outputs are derived from the pinned 427-polygon atlas in `snapshots/build-inputs/atlas-data.js` and these raw inputs.

To regenerate after an approved source change, use Python with exactly `requirements-terrain.txt` (NumPy 2.4.4, Pillow 12.2.0, Shapely 2.1.2, with `contains_xy`). Run `python3 -m pip install -r requirements-terrain.txt` in a dedicated environment, then `npm run prepare:terrain` and `npm run test:terrain`. The producer fails on changed atlas and raw input hashes; update source pins and review geometry independently before regenerating. Do not use an external workstation path or duplicate the 36 MB atlas. The generated PNG is written only by the projector.

`npm run build` does **not** install or invoke this Python toolchain. It validates the checked-in output hashes and the current `opening-territories.json` hash after the existing generator, then Vite selectively copies approved static assets to `dist`. Missing or stale Seoul outputs fail before publication. The tools release Docker image therefore continues to need only its existing dependencies for the default wiki build. Fresh checkouts that run the existing geography generator still need their LFS-backed geography files hydrated by the checkout provider; the terrain projector itself reads only the normal tracked atlas and raw terrain blobs. The final staged site and tar still require integration verification outside this increment.

`npm run dev` is the source development server, not reviewed web publication. Vite's `publicDir:false` prevents it from exposing the native raw files via the public middleware, while the reviewed publication surface is the `dist` copied into `/wiki/` by the tools staging script. `npm run preview` serves the most recently built dist; run `npm run build` and `npm run check:artifacts` first when reviewing it.
