# 강·구·동 건물 재사용

붕괴 뒤 서울에서는 더 이상 건물을 새로 짓지 않는다. 과거의 뼈대 위에 새로운 삶의 방식이 얹혀, 학교였다고 해서 지금도 학교로 쓰이지는 않는다. 면적은 427개 동으로 나뉘며, 각 권역은 십육국의 지배 아래 거점과 영토를 형성한다.

## 세력과 건물, 그리고 역

동은 지리적 구획일 뿐, 세력이 장악하는 실제 단위는 건물이다. 단순히 동 이름에 깃발을 꽂는다고 그곳을 지배하는 것은 아니다.

해당 동에 지하철역이나 철도역이 있다면, 생존자들은 그 역을 배급과 통행, 피난의 중심으로 삼는다. 영등포역 하역장이나 서울역 대합실, 제기동 환승 통로처럼 역이 삶의 입구가 되고, 주변의 학교나 주민센터, 병원은 이를 보조하는 시설로 편입된다.

특정 동은 다음 세 가지 상태 중 하나로 유지된다.

| 상태 | 뜻 |
|---|---|
| `held` | 한 세력이 지배력 50 이상으로 확고히 장악한 상태 |
| `contested` | 둘 이상의 세력이 다투거나, 지배력이 50 미만인 불안정한 상태 |
| `vacant` | 건방과 역은 존재하지만 장악한 세력이 없는 상태 |

영향력은 지배력과 같으며 0에서 100 사이의 수치를 가진다. 한 동에 들어선 세력들의 지배력 합은 100을 넘을 수 없다. 건물은 중추인 `core-station`과 보조인 `support`로 나뉘며, 과거 역으로 쓰이던 곳이 주로 중추 역할을 맡는다.

## 세 가지 층위

| 층 | 단위 | 역할 |
|---|---|---|
| 강 | 한강 남북, 지천 | 침수나 제방, 선박 접안 시설 등 수변 생태와 저층부 활용을 결정한다. |
| 구 | 25 자치구 | 과거에 남겨진 주요 시설에 따라 해당 구역이 어떤 직능을 가질지 정한다. |
| 동 | 427 행정동 | 관측된 앵커마다 과거의 용도와 현재의 새로운 쓰임새가 기록된다. |

## 한강과 지천

한강 이북의 구역은 종로, 중구, 용산, 성동, 광진, 동대문, 중랑, 성북, 강북, 도봉, 노원, 은평, 서대문, 마포, 강서이며, 이남 구역은 양천, 구로, 금천, 영등포, 동작, 관악, 서초, 강남, 송파, 강동이다.

지천은 구역의 경계를 가른다. 중랑천이 중랑, 동대문, 노원을 지나고, 안양천이 양천, 구로, 영등포 서부를 가른다. 탄천은 강남과 송파를, 청계천은 종로, 중구, 성동을, 홍제천은 서대문과 은평을 나눈다. 여의도, 이촌, 반포, 잠실, 망원, 합정, 암사, 구의, 자양 등의 지역은 본류 수변으로 분류된다.

수변의 환경은 가혹하다. 본류의 1층은 우기 때 물이 차오르는 창고이거나 버려진 공간이며, 거주지는 최소 3층 이상에 마련된다. 배급 창구 역시 제방 안쪽에 안전하게 둔다. 지천 변은 오수와 범람이 잦고 야생동물의 통로가 되며, 학교 운동장 등은 물길을 돌리는 우회 제방으로 쓰인다. 반면 관악, 도봉 같은 내륙 고지대는 침수는 피하지만 경사가 가파르고 전력 공급이 끊긴 상태다. 이곳의 학교들은 주로 대피용 대강당으로 쓰인다.

## 구가 가져가는 직능

십육국의 권역이 구 위에 자리 잡지만, 건물의 실제 직능은 과거 그곳에 있던 시설에서 비롯된다. 영등포의 정수장, 신정 기지, 방화 기지, 노량진 냉동창고, 제기동 약재시장 등이 해당 구역의 핵심 동력이 된다.

| 구 | 강 | 개막에 먼저 가져가는 건물 |
|---|---|---|
| 영등포 | 남, 한강·안양천 | 정수장과 역 하역장. 기존 시장은 예약제 배급 창구로 쓰인다. |
| 양천·구로·금천 | 남, 안양천 | 차량기지와 공단. 학교 건물은 부품 건조장으로 활용된다. |
| 강서 | 북, 한강 | 방화 기지와 연구동. 과거 공항의 흔적은 거대한 창고로 쓰인다. |
| 용산·마포 | 북, 한강 | 철도 창고와 선박 접안 시설. 방송국 건물은 기록 중계소다. |
| 종로·중구 | 북, 청계 | 행정동과 대학. 과거의 장부와 접근이 봉인된 서고가 남아 있다. |
| 성동·광진 | 북, 한강 | 공방과 교량 접근로. 학교는 기계 수리 실습장이다. |
| 강동 | 남, 한강 | 정수장과 동부 교량. 병원은 오염된 물을 마신 이들을 위한 탁수 격리 구역이다. |
| 송파·강남·서초 | 남, 탄천·한강 | 거대한 배급 타워와 잠실·수서 창구. 아파트 저층부는 봉인되어 있다. |
| 동작·관악 | 남 | 노량진 냉동창고와 남부 고지대 대피소. |
| 은평·강북·성북 | 북, 북한산 | 피난용 대강당과 고지대 창고. |
| 도봉·노원 | 북, 중랑천 | 창동 기지와 북부 철도망에 의존하는 숙영지. |
| 중랑·동대문 | 북, 중랑천 | 환승로와 제기동. 시장은 귀한 약재와 환승 화물을 분류하는 곳이다. |

## 과거 태그와 현재 쓰임

과거의 용도는 새로운 시대에 맞춰 변모했다. 수변 환경과 자치구의 특성이 이를 덮어쓴다.

| 관측 | 현재 쓰임 |
|---|---|
| 학교 | 지역 민병대의 숙영지. 운동장은 화물을 정렬하는 마당이며, 특별실은 봉인되어 있다. |
| 주민센터 | 장부를 관리하는 행정처이자 배급 창구. |
| 병원·의원 | 야전 의무소. 정수장 인근의 병원은 탁수 환자 격리소로 쓰인다. |
| 대학 | 낡은 기록을 베껴 쓰는 사본 공방. 실험동은 출입이 봉인되거나 부품 분해장으로 쓰인다. |
| 시장 | 허가받은 이들만 거래하는 장터. 예약분과 현장 판매분을 엄격히 나눈다. |
| 역 | 생활 화물을 인계받고 피난처로 쓰이는 핵심 층. 선로를 지날 때는 국가에 통행세를 내야 한다. |
| 아파트 | 3층 이상만 거주구로 쓰인다. 1~2층은 물에 잠긴 창고이거나 완전히 포기한 공간이다. |
| 공원·녹지 | 얕은 작물을 기르거나 가축을 방목하며, 우기에는 물을 빼는 배수로 역할을 한다. 묘지로 쓰이는 곳도 있다. |
| 상점·사무실 | 작은 공방으로 개조되거나 셔터가 굳게 봉인되어 있다. |

## 동 데이터 칸

각 동마다 핵심 거점(anchor)들이 기록된다. 이는 모든 건물이 아니라 대표적인 랜드마크에 해당한다.

| 필드 | 내용 |
|---|---|
| `anchor_ref` | 건물의 고유 식별자 |
| `name` | 과거의 이름. 흔적이 없다면 '이름 없는 건물'로 불린다. |
| `observed_use` | 붕괴 전 용도 (학교, 역, 주민센터 등) |
| `river` | 수변 위치 (`hangang-north`, `hangang-south`, `tributary`, `inland`) |
| `opening_use` | 현재 어떤 용도로 쓰이는지에 대한 간략한 설명 |
| `how` | 층, 마당, 봉인 구역을 세부적으로 어떻게 활용하는지 |
| `floors` | 층별 상세 상태 (`level`, `label`, `state`, `contents`, `condition`). 단층 구역도 최소 한 층의 기록을 남긴다. |

## 층마다의 상태

건물의 층수는 과거 기록에 의존하며, 지금의 기록은 각 층이 어떻게 쓰이는지를 담는다.

| 상태 (`state`) | 뜻 |
|---|---|
| `flooded` | 우기나 지천의 범람으로 물에 잠겨 거주가 불가능한 구역. |
| `sealed` | 판자나 쇠붙이로 굳게 막혀 허가 없이는 들어갈 수 없는 구역. |
| `occupied` | 사람들이 배급, 숙영, 물자 인계 등을 위해 활발히 사용하는 구역. |
| `abandoned` | 인적이 끊겨 비워진 공간. 조심스러운 탐색만 이루어진다. |
| `yard` | 천장이 없는 노천 공간. 운동장이나 화물을 정렬하는 공터로 쓰인다. |

용도별 활용 층은 다음과 같이 나뉜다.

| 관측 | 층 활용 |
|---|---|
| 역 | 지하 2층은 선로, 지하 1층은 승강장, 1층은 대합실, 옥상은 망루로 쓰인다. |
| 학교 | 1층과 운동장은 물류, 2층 교실은 숙영, 3층 특별실은 봉인, 옥상은 감시나 작업용이다. |
| 아파트 | 1~2층은 침수나 포기 상태, 3층부터 거주하며 옥상은 출입을 통제한다. |
| 주민센터 | 1층은 민원과 배급 창구, 2층의 서고는 접근이 봉인되어 있다. |
| 병원·의원 | 1층은 대기열, 2층은 침상이 놓여 있다. |
| 대학 | 1층은 사본 작업 공방, 실험동은 위험물로 인해 봉인된다. |
| 시장 | 지하는 서늘한 창고, 1층은 허가받은 장터다. |
| 공원·녹지 | 지표면 단층으로 관리된다. |
| 그 밖 | 기본적으로 1층을 쓰며, 필요 시 옥상을 추가로 쓴다. |

수변의 1층은 물에 잠기기 쉬워 거주하지 않으며, 사람들은 3층 이상으로 올라가 살아간다.
