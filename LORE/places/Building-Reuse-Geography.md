# 강·구·동 건물 재사용

붕괴 뒤 서울의 건물은 새로 짓지 않는다. 2026 관측 위치(OSM 태그)가 뼈대고, 개막일 쓰임은 그 뼈대 위에 얹은 창작이다. 태그가 `school`이라고 학교가 열린 것이 아니다.

면적 분모는 [서울 지역 설정 데이터](../regions/README.md)의 427동이다. 권역 깃발은 [십육국](../factions/Sixteen-States.md), 그래프 재료는 [월드맵 구성](../places/World-Map-Construction.md), 점령 수치는 [거점과 영토](../economy/Strongholds-and-Territory.md)다.

## 세력·건물·역

동은 면적 칸이다. 세력이 가져가는 최소 단위는 **건물**이다. 동 이름에 깃발을 꽂는 것으로 점령하지 않는다.

그 동에 지하철역(또는 철도역)이 있으면 그 역 건물이 **핵심 시설**이다. 배급·통행세·숙영·피난은 역을 먼저 본다. 학교·주민센터·병원은 지원 건물이다.

모든 동은 개막일에 다음 중 하나다.

| 상태 | 뜻 |
|---|---|
| `held` | 한 세력이 지배력 50 이상으로 가져간다. |
| `contested` | 둘 이상이 나눠 가지거나, 한 세력의 지배력이 50 미만이다. |
| `vacant` | 세력 깃발이 없다. 건물과 역은 있다. |

플레이 중 지역에 보이는 세력 정보는 이 칸이다. 영향력은 지배력과 같다. 지배력은 0–100이고, 한 동의 보유 세력 합은 100을 넘지 않는다.

데이터는 `content.territory`와 건물 칸의 `role`이다. `role`은 `core-station` 또는 `support`다. 관측 쓰임이 역이면 `core-station`이다.

## 세 층

| 층 | 단위 | 하는 일 |
|---|---|---|
| 강 | 한강 남북, 지천 | 침수·제방·선석이 1층을 먹을지 결정한다. |
| 구 | 25 자치구 | 어떤 직능이 그 구의 잔존 건물을 가져가는지 정한다. 구를 국가로 바꾸지 않는다. |
| 동 | 427 행정동 | 관측 앵커마다 붕괴 전 용도와 개막 쓰임을 적는다. 칸은 `content.buildings`. |

장소 이름·태그는 관측, 경계는 계산, 개막 운영은 창작이다.

## 한강과 지천

한강 **이북**: 종로, 중구, 용산, 성동, 광진, 동대문, 중랑, 성북, 강북, 도봉, 노원, 은평, 서대문, 마포, 강서.

한강 **이남**: 양천, 구로, 금천, 영등포, 동작, 관악, 서초, 강남, 송파, 강동.

지천은 구를 가른다. 중랑천(중랑·동대문·노원), 안양천(양천·구로·영등포 서부), 탄천(강남·송파), 청계(종로·중구·성동), 홍제(서대문·은평). 동 이름에 여의도·이촌·반포·잠실·망원·합정·암사·구의·자양이 들어가면 본류 수변으로 본다.

수변 규칙:

- 본류 1층은 우기 창고이거나 포기한 공간이다. 거주는 3층 이상, 배급 창구는 제방 안쪽.
- 지천 변은 오수·범람 멧돼지·너구리 회랑이다. 학교 운동장은 우회 제방으로 쓴다.
- 내륙 구(관악·도봉 고지)는 침수 대신 경사와 단전이다. 학교는 대피 대강당이 된다.

## 구가 가져가는 직능

십육국 권역을 구 위에 얹되, 건물 직능은 구의 관측 시설에서 나온다.

| 구 | 강 | 개막에 먼저 가져가는 건물 |
|---|---|---|
| 영등포 | 남, 한강·안양천 | 정수·역 하역장. 시장은 예약 배급 창구. |
| 양천·구로·금천 | 남, 안양천 | 차량기지·공단 동. 학교는 부품 건조. |
| 강서 | 북, 한강 | 방화 기지와 연구동. 공항 기억은 창고용. |
| 용산·마포 | 북, 한강 | 철도 창고·선석. 방송동은 기록 중계. |
| 종로·중구 | 북, 청계 | 행정동·대학. 장부와 봉인 서고. |
| 성동·광진 | 북, 한강 | 공방·교량 접근. 학교는 수리 실습. |
| 강동 | 남, 한강 | 정수·동부 교량. 병원은 탁수 격리. |
| 송파·강남·서초 | 남, 탄천·한강 | 배급 타워와 잠실·수서 창구. 아파트 저층은 봉인. |
| 동작·관악 | 남 | 노량진 냉동, 남부 경사 대피. |
| 은평·강북·성북 | 북, 북한산 | 피난 대강당, 고지 창고. |
| 도봉·노원 | 북, 중랑천 | 창동 차륜, 북부 철도 숙영. |
| 중랑·동대문 | 북, 중랑천 | 환승·제기동. 시장은 약재와 환승 화물을 나눈다. |

## 관측 태그 → 개막 쓰임

OSM `amenity`/`building`/`railway`는 붕괴 전 용도다. 개막 쓰임은 아래를 기본으로 하고, 강·구가 덮는다.

| 관측 | 기본 개막 쓰임 |
|---|---|
| 학교 | 동 민병 숙영. 운동장은 화물 정렬. 특별실은 봉인. |
| 주민센터 | 동 장부와 배급 창구. |
| 병원·의원 | 야전 의무. 정수 인근은 탁수 격리. |
| 대학 | 기록 사본 공방. 실험동은 봉인하거나 부품 분해. |
| 시장 | 허가 장터. 예약분과 판매분을 나눈다. |
| 역 | 생활 화물 인계와 피난 층. 선로는 국가 통행세. |
| 아파트 | 3층 이상만 거주. 1–2층은 침수 창고이거나 포기. |
| 공원·녹지 | 얕은 경작, 방목, 우기 배수. 묘지로 쓰지 않으면 명시한다. |
| 상점·사무실 | 공방이거나 셔터 봉인. 간판 상호는 본문에 올리지 않는다. |

같은 이름을 한 시설로 합치지 않는다. 동 밖의 시설을 이름만 보고 끌어오지 않는다.

## 동 데이터 칸

각 동 `content.buildings`는 한 개 이상이다. 대표 앵커(최대 4)만 적으며, 전수 시설 목록이 아니다.

| 필드 | 내용 |
|---|---|
| `anchor_ref` | 그 동 `profile.anchors`의 `source_object_id` |
| `name` | 관측 이름. 없으면 `이름 없는 건물` |
| `observed_use` | 붕괴 전 태그 해석(학교, 역, 주민센터 …) |
| `river` | `hangang-north` / `hangang-south` / `tributary` / `inland` |
| `opening_use` | 개막일 쓰임 한 줄 |
| `how` | 층·마당·봉인을 어떻게 쓰는지 |
| `floors` | 다층이면 층마다 `level`, `label`, `state`, `contents`, `condition`. 지상 단층(공원) 도 한 층은 적는다. |

## 층마다

OSM 시설 노드(학교·역 이름점)에는 `building:levels`가 거의 없다. 건물 폴리곤 9만 채에는 층수가 있으나, 이름점과 80m 최근접은 옆 빌딩을 붙이는 오류가 난다(경복궁역→적선현대빌딩). 관측 층수는 [조인 기록](../regions/sources/observed-levels-join.md)이다. OSM 이름 일치 건물만 `building:levels`를 붙인다. 거리 최근접은 쓰지 않는다. 지금 `floors[]`는 개막 쓰임이다. 역 내부 334곳은 `regions/station-interiors.json`이다.

| `state` | 뜻 |
|---|---|
| `flooded` | 우기·지천 물. 거주 금지. |
| `sealed` | 판자·쇠터. 허가 없이면 못 들어간다. |
| `occupied` | 사람이 쓴다. 배급·숙영·인계. |
| `abandoned` | 모서리 비웠. 낮은 탐색만. |
| `yard` | 노천. 운동장·화물 정렬. |

용도별 최소 층:

| 관측 | 층 |
|---|---|
| 역 | 지하 2 선로, 지하 1 승강장, 1층 대합실, 옥상 망루 |
| 학교 | 1층 현관·운동장, 2층 교실 숙영, 3층 특별실 봉인, 옥상 |
| 아파트 | 1–2층 침수 또는 포기, 3층 거주, 옥상 봉인 |
| 주민센터 | 1층 창구, 2층 서고 봉인 |
| 병원·의원 | 1층 대기, 2층 침상 |
| 대학 | 1층 사본 공방, 실험동 봉인 |
| 시장 | 지하 창고, 1층 허가 장터 |
| 공원·녹지 | 지표면 한 층 |
| 그 밖 | 1층, 필요 시 옥상 |

수변 1층은 `flooded` 또는 창고. 거주는 3층 이상.

검증은 `Tool/tools/regions/verify_region_atlas.py`가 빈 칸·외부 앵커·강 값·빈 층을 거절한다.

## 하지 않는 일

- OSM 태그를 가동 중인 학교·병원이라고 말하지 않는다.
- 구를 국가 이름으로 바꾸지 않는다.
- 427동 전수 건물 메시를 Unity에 넣지 않는다. 이 문서는 설정이다.
