# Pre-baked 3D objects

Place prepared `.glb`, `.gltf`, `.fbx` or `.blend` models here, or pass `portrait-gen serve --assets /absolute/path/to/models`.

Files are inputs, not generated 2D plates. glTF external buffers/textures stay beside their source. Do not overwrite owner assets. The server lists regular model files at this directory's top level; symlinks and unrelated files are not selectable.

No demo character is promoted automatically. PNG output from a successful real render is the current portrait PASS criterion.
