# Current completion contract

- CLI and browser select pre-baked 3D objects and render a real PNG.
- Valid rendered PNG is PASS; invalid/missing source or corrupted output fails explicitly.
- Old OpenAI/ComfyUI/2D contracts are inactive and historical files remain archived.
- Source objects and other workers' changes are preserved.
- Run current tests and real browser/Blender checks before claiming completion.

This is the current verification checklist, not a claim that a past roadmap's 2D gates still apply. Evidence from each run records its own result.
