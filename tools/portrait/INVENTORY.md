# Current inventory

- `assets/prebaked/` or explicit `--assets`: ready 3D model inputs.
- `work/portraits/<id>/`: actual rendered PNG and receipt/job metadata.
- `tools/character-tool/`: 3D game-art preparation and Unity staging.
- Old `assets/v2/` and databases: preserved history, not the active portrait library or current PASS authority.

Use `portrait-gen assets` and `portrait-gen list` for actual current inventory; no fixed slot or variant count is required.
