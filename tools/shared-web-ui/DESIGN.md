# Shared web UI implementation map

The governing contract is `TOOL/docs/Shared-Web-UI-Design-Contract.md`. The parent package exposes its named shell, discovery and service primitives, `suiTokens.bp`, and `tokens.css`. WIKI light is the baseline; hub dark and GDD light use the contract's site accent slots. No package component parses or renders article content.

Import `@seoul-dengoku/shared-web-ui/tokens.css` once per consumer and `styles.css` for component rules. Tokens apply under a `data-sui-theme="light|dark"` root with `data-sui-site="hub|wiki|gdd"`. `SiteShell` puts those attributes on its own root and accepts an optional navigation slot: when omitted the hub receives the 880px index shell; with navigation, documents receive the 220px sidebar and 1200px main. Routes and labels are consumer inputs. `CategoryTree` uses buttons and `aria-expanded`; the caller can pass `resolveHref` for existing route rules. The page owns vertical scrolling, except the desktop navigation may scroll. Only `TableViewport` owns horizontal scrolling. At 1024px the sticky contents region becomes static, at 768px navigation becomes a labeled disclosure, and at 640px service images stack above text. Long Korean titles wrap; 375px pages do not set a minimum width.

The package uses border-only depth, 4px spacing increments, 0/2px/4px radii, and 150ms color transitions disabled by reduced motion. Interactive elements have visible focus. The content renderer remains a separate dependency of consuming sites. There is no accepted package-level visual debt; adoption and screenshot parity belong to each consumer's integration lane.
