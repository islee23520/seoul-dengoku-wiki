# UI가 코드로 들어오는 길

![칸에 누가 서 있고 어느 쪽을 보는지 확인하는 기준](https://github.com/islee23520/seoul-kenshi/blob/main/docs/assets/wiki/isometric-grammar.svg?raw=true)

화면을 유니티부터 짜지 않습니다. HTML로 여러 안을 보고, 사람이 하나를 고르고, 그 목업이 실제로 움직인 뒤에야 uGUI로 옮깁니다. 에셋 권리·승격은 [에셋이 들어오는 길](/design/Asset-Pipeline)을 따릅니다. 색·간격·화면 이름은 [Design.md](/design/Design)가 계약입니다.

이 순서는 2026-09-11 레퍼런스([@nayuengin, 2097947806376014211](https://x.com/nayuengin/status/2097947806376014211))를 이 저장소 계약에 맞춘 것입니다. 유니티 런타임 UI는 uGUI와 TMP만 씁니다.

## 한 화면이 지나가는 단계

1. **의도.** 어떤 화면인지, 플레이어가 무엇을 고르는지, 어떤 Core 명령이 나가는지만 적습니다. 위젯부터 그리지 않습니다.
2. **스프라이트.** 아이콘·카드 그림·초상이 필요하면 이미지 생성을 명시적으로 켭니다. 권리는 `allowed`일 때만. 생성 결과는 후보입니다. BOM 승인 없이 런타임 슬롯에 넣지 않습니다.
3. **HTML 시안 여러 장.** 같은 의도로 레이아웃을 두세 장 만듭니다. AI는 HTML이 빠르므로 여기서 먼저 그립니다.
4. **사람이 고른다.** 에이전트가 고르지 않습니다. 고른 시안만 다음으로 갑니다.
5. **동작 목업.** 고른 시안을 브라우저에서 클릭해 봅니다. 선택, 취소, 재충전, 포커스 이동까지 이 단계에서 고정합니다. 규칙 계산은 넣지 않습니다. Core가 이미 가진 카드 ID와 단계 이름만 빌립니다.
6. **동결.** HTML/CSS/JS와 로컬 자산의 SHA-256, 1280×720과 1920×1080 캡처를 남깁니다. 이후 유니티는 이 바이트를 기준으로 봅니다.
7. **uGUI 이식.** 동결된 목업을 옆에 두고 `UguiHudBuilder`와 프레젠터에 옮깁니다. 안정 이름은 `UiElementNames`에만 둡니다. 클릭 대상은 목업과 같은 그림이어야 합니다. 디버그 버튼으로 우회하지 않습니다.
8. **증명.** EditMode는 치수와 이름, PlayMode는 실제 포인터 경로, 캡처는 동결 목업과 같은 해상도입니다. 클릭만 된다고 통과가 아닙니다.

## 이 저장소에서 이미 끝난 것과 남은 것

승인된 브라우저 목업은 `poc/browser/`에 있습니다. 지휘관 카드, 진형 편집, 실시간 전투 미리보기, 회수 캠페인 네 표면입니다. 카드 크기 132×180, 초상 32, 취소·줌 44, 선택 시 7px 상승은 그 목업에서 왔습니다.

유니티 쪽은 같은 숫자를 HUD에 넣었지만, 한동안 카드 그림은 장식이고 `사기 고무 사용`·`기동 재집결` 글 버튼이 실제 입력이었습니다. 파이프라인 7단계를 어긴 상태입니다. 첫 POC는 그 입력을 카드 그림으로 되돌리는 일입니다. 전투 규칙(`rtfc-owner-cards-v2`)은 건드리지 않습니다.

## 에이전트에게 맡길 때

- 유니티 스킬은 uGUI입니다. UI Toolkit과 IMGUI로 새 화면을 만들지 않습니다.
- 목업에 없는 카드, 덱, 드로우를 만들지 않습니다. Core `CardCatalog`에 있는 ID만 씁니다.
- 필그리미지 원본 아틀라스는 로컬 검토입니다. `RuntimeSlotCatalog`에 넣지 않습니다.
- 배치모드는 `-batchmode`입니다. 화면을 가로채지 않습니다.
- 금지 공개 용어(이 위키 빌더가 거르는 고유명)를 문서에 쓰지 않습니다.

## 한 화면의 완료

동결 해시와 캡처가 있고, 유니티 안정 이름이 목업 컨트롤과 대응하고, 같은 해상도 캡처가 목업과 같은 자리를 가리키면 그 화면은 끝난 것입니다. 다음 화면으로 넘어갑니다. 타이틀·거점·조우·정산을 이 파이프라인으로 다시 그리는 일은 별도 증분입니다.
