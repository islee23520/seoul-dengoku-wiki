# 회랑 인물 총람

16국 명부 바깥, [이주민 회랑](Diaspora-Corridors.md)과 [징집 잔존](Conscription-Remnants.md)에 이름이 있는 인물이다. 본문은 회랑 페이지다.

| 이름 | 회랑 | 직위 | 징집 이력 | 무장 접근 |
|---|---|---|---|---|
| 린샤오메이 (임소매) | 대림·가리봉 통역시장 | 이중장부 중개 | 없음 | 생업 공구 |
| 팜반득 (범반득) | 구로공단 기숙 잔존 | 야간 정비 조장 | 없음 | 공구·방호복 |
| 아미라 카심 | 이태원 통행 골목 | 다국어 통행증 판독 | 없음 | 없음 |
| 조엘 박 | 용산 울타리 용역 | 창고 열람 통역 | 병 만기 | 열쇠만 |
| 나르기즈 유수포바 | 자양·건대 고려인 하숙 | 두 말 피난 전령 | 없음 | 없음 |
| 최일석 | 신정·부평 동원잔존 | 동원 명부 서기 | 병 만기, 예비 서기 | 부키, 제식 봉 |
