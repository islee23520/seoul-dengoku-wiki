# 시스템 구조 보고

게임 디자인(`GDD/`)의 시스템 설계 도식을 모은 읽기 전용 폴더입니다. 제품 코드가 아닙니다.

부대 지휘 화면 초안은 [`total-war-ui/`](total-war-ui/)입니다. 2026-09-19 목표의 3D 자유 지휘 카메라와 닫힌 전투 안에서만 허용하는 일시정지 중 명령은 질문 만료 뒤 채택한 설계 기본값이며 소유자 명시 결정이 아닙니다. 노드별 상태와 그 흐름은 [`gdd-lore-node-states.lifecycle.html`](gdd-lore-node-states.lifecycle.html)과 [`gdd-lore-node-states.json`](../canon/locales/ko-KR/system-design/gdd-lore-node-states.json) 표에서 봅니다. 뷰어 UI는 영어 폴백입니다. 캠페인 POV·권한 전이 청사진은 [`campaign-pov-authority/`](campaign-pov-authority/)입니다. 그 도식들은 실제 게임 렌더가 아닙니다.

서울 전체 지도와 개막 영토는 [서울:전국 공식 위키](https://seoul-dengoku.linalab.io/wiki/world/World-and-Subway-Layers)에서 확인합니다.
