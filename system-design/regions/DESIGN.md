# 서울 지역 총람 화면 계약

기존 `system-design/index.html`의 종이색·녹색/남색 지도 팔레트와 한국어 편집형 문서를 따른다. 새 브랜드·프레임워크·폰트를 추가하지 않는다. 지역 데이터로 그린 지도가 주 시각 자료이며 장식 그림은 만들지 않는다.

## 목적과 사용자

사용자는 모든 지역이 실제로 있는지, 어떤 자료일과 근거를 썼는지, 각 동의 생활·시설·사건 내용이 무엇인지 확인한다. 427동을 한 번에 표로 쏟지 않고 지도, 구 선택, 지역 검색, 상세를 함께 제공한다. 구 전체/동 전체를 누락 없이 탐색할 수 있어야 한다.

## 토큰

- 종이 `--paper:#f4efe4`, 카드 `--card:#fffdf8`, 글자 `--ink:#1a1714`, 보조 `--muted:#6b6256`, 경계 `--line:#c9b896`.
- 관측/지도 녹색 `--green:#0f6b4c`, 선택/연결 남색 `--blue:#1d4e89`, 주의 `--amber:#d97706`, 오류 `--rust:#9b2c2c`.
- 본문 system Korean sans 16px/1.65; 큰 제목 명조 계열 28~44px, 표제 20~24px, 출처 12~14px. 작은 글자로 데이터를 우겨넣지 않는다.
- 간격 4/8/12/16/24/32px; 본문 최대 너비 1440px; 버튼 터치 높이 최소 44px.
- 카드의 기존 따뜻한 그림자와 경계 사용. 새로운 번쩍이는 효과 없음.

## 구조

상단에 제목·실제 데이터 기준일·창작 개막일·전수 검증 상태. 그 아래 구/동/역/시설 통합 검색과 분류 필터. 데스크톱에서 지역 목록·지도·상세를 두세 열로 배치하고 모바일에서는 지도/목록 다음 상세로 문서가 자연스럽게 이어진다. 페이지 스크롤이 소유자이며 작은 중첩 스크롤창을 남발하지 않는다.

## 반복 컴포넌트

- FilterBar: label이 있는 search/select, 초기화 버튼. 변경 즉시 실제 결과 목록/개수를 갱신한다.
- RegionList: 모든 동에 접근할 수 있는 버튼/링크. 선택 상태·키보드 focus·역 없음 표시. 결과 없을 때 명확한 빈 상태.
- GeographyMap: 실제 GeoJSON 지역 경계를 SVG로 그린다. 지도 클릭과 목록 선택이 동기화. SVG만 유일한 접근 수단으로 삼지 않는다.
- RegionDetail: 지역명/면적/구, 실측 앵커·역·시설, 지형·생활·산출/부족·위험·개막 상태, 행동/비용/결과/대가, 근거와 불확실성.
- DateAndCoverage: 경계 유효일·PBF 스냅샷·자료 확인일·창작 시점을 분리하고 744건 같은 격리 수치를 숨기지 않는다. 공식 현실 전수와 선택 자료 전수 구분.

## 동작과 접근성

hash로 선택 지역을 복원한다. native button/select/input을 사용하고 텍스트를 innerHTML에 삽입하지 않는다. focus-visible를 항상 표시한다. 검색은 한글 동명·역명·시설명으로 동작한다. 좁은 화면에서 긴 ID/이름을 줄바꿈하고 가로 overflow가 없어야 한다. prefers-reduced-motion을 지키며 별도 모션 라이브러리는 없다.

## 검증

Desktop 1280px, tablet 768px, mobile 390px에서 실제 Aside 브라우저 확인. 25구 선택 가능, 427지역 접근 가능, 역 없는 지역 선택, 실제 시설명 검색, 빈 검색 결과, hash 복원, 지도·목록 동기화, 이미지 대신 진짜 데이터 지도 확인. 허위 PASS나 텍스트 카운트만으로 시각 검증 완료 처리 금지.
