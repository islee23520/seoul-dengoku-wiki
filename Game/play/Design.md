# 플레이 가능한 코어 루프 POC

## 목적

플레이어가 원정 전 물자를 고르고 목적지를 정한 뒤 조우를 해결하며, 그 결과가 다음 원정에 남는 것을 직접 체험한다. 설명을 읽어야만 작동을 이해하는 보고 화면이 아니라 선택·비용·결과가 함께 보이는 게임 화면이다.

## 화면과 시각 기준

기존 보고와 지역 총람은 참고 링크로만 둔다. 플레이 화면은 서울 지하철 관제판을 연상시키는 짙은 남색 바탕, 따뜻한 백색 글자, 신호등 같은 주황·연두·파랑 강조색으로 구성한다. 배경은 장식보다 실제 지도/전장의 가독성을 위한 것이다. 새로운 폰트·프레임워크·이미지 생성 없이 CSS/SVG/Canvas로 구성한다.

- 최대 폭 1440px, 본문 15~16px, 제목 28~40px. 실제 숫자와 자원 배지는 가독성을 우선한다.
- 상단: 제목, 현재 단계, 자원 4개(물자·평판·원정 횟수·분대 상태), 새 게임/규칙.
- 왼쪽/중앙: 서울 실측 지역 지도와 위치 선택 또는 전투장. 지도 데이터는 427동을 모두 포함한다.
- 오른쪽: 현재 목적지와 지역 내용, 행동 비용/효과, 분대/진형, 결과 기록. 현재 해야 할 행동을 큰 버튼 하나로 강조한다.
- 하단: 최근 명령/결과 기록과 세 단계 목표(준비·원정·귀환). 정산 전후 숫자를 강조한다.
- 모바일 390px: 지도→현재 행동→분대/기록 순서로 한 열. 버튼 최소44px, 중첩 가로 스크롤 금지.
- 전투: 고정 아이소 느낌의 12×8 격자, 아군/적군 명확한 색상, HP와 피해 표기, 실제 카드와 쿨다운, 일시정지/후퇴. 장식으로 가린 게임 영역이 없어야 한다.
- 전투 순서는 4방향의 한 칸 이동을 마친 뒤 행동한다. 캠페인용 정치·신앙·문화 문법을 전투의 틱 체계나 UI로 옮기지 않는다. 포트레잇 2D와 메시 작업은 별개로 유지한다.

## 의도적으로 단순화한 점

- 25구427동의 날짜 고정 실제 경계를 탐색한다. 원정 이동은 지역 간 직선 거리로 비용을 산출한 웹 체험 규칙이며 실제 철도 운행/보행 경로를 계산했다는 뜻이 아니다.
- 분대는 대표 유닛3명, 전투는 웹용 결정론 모델이다. Unity 코어 전체 이식이나 모든 지역의 내부 공간 구현이 아니다.
- 선택의 결과는 현재 브라우저 세션에서 다음 원정으로 이어진다. 별도 계정·서버 저장·결제 없음.

## 행동 흐름

새 게임 → 거점(회복/물자 확인) → 원정 준비(지역 검색·선택) → 비용 확인 후 출발 → 조우(협상·우회·전투) → 전투라면 진형 편집 후 시작 → 실시간 자동 전투+소유 카드+일시정지/후퇴 → 결과 확인 → 정산(정확히 한 번) → 거점 복귀.

준비 비용·협상 확률·예상 위험을 선택 전에 보인다. 실패/패배에도 결과가 있고 재시작·복귀가 가능하다. 단순 승리 버튼은 없다.
