## 보존할 계약

병졸 최대20(영웅 별도), 지휘관 상실 시 임시 병졸 분대장, AI에도 동일 명령 계약, 제출시각·호스트 우선 금지, 턴 해결마다 세계시간 한 칸, 전투 참가 분대만 후속 전략 명령 잠금, 같은 노드·층에서만 분리·합류를 보존한다. 이동·공격·요격·증원·태세는 별도 명령이다. 강행군은 공격·요격 개시 불가이나 피격 가능하며 야영은 공격 개시 불가다.

## 제안 수치와 정수 계산

시간 한 칸을 시간/일/km로 환산하지 않는다. 추상 이동점 MP의 저장 단위는 1000u=1MP, Q=1000이다. 모든 계수와 단위 적용 방식은 신규 설계다. basicMove는 승인 캐릭터 입력의 비음수 정수이며 누락 시 기본값을 만들지 않는다. GURPS Basic Speed에서의 유도나 CP 수정을 자동 추정하지 않는다.

personalU=floor(basicMove×1000×encPermille×healthPermille×fatiguePermille/1000³). squadBaseU는 지휘관·배속 영웅·병졸을 포함한 모든 실제 보행 구성원의 personalU 최솟값이다. turnBudgetU=floor(squadBaseU×stancePermille/1000). 중간 내림 없이 마지막에 내린다. 보행 불가자를 계산에서 빼거나 승인되지 않은 운송수단에 태우지 않는다.

짐은 장비·무기·방어구·소모품·배정 공용짐을 개인별로 합산한다. 승인 BL과 같은 정수 단위로 비교하며 경계와 같으면 낮은 등급이다. 상한은 BL×[1,2,3,6,10], 계수는 [1000,800,600,400,200]. 10BL 초과는 OVER_CAPACITY로 거부한다. 원전 BL의 반올림을 이 제안이 확정하지 않는다.

상태 계수 후보: 건강 정상1000/보행부상750/자력보행불가0, 피로 정상1000/피로750/탈진500/이동불가0. HP·FP에서 이 상태로 매핑하는 임계값과 회복·피로 누적은 승인 전 미지원이다. 이 숫자는 GURPS 사실이 아니다.

태세 계수 후보: 통상1000, 강행군1500, 매복500. 주둔·야영 활성 상태는 이동을 거부한다. 첫 이동 전에 이동 태세를 잠그고 이동 후에는 종료 태세만 허용한다. 종료 태세를 해제해도 같은 턴 이동을 재개하거나 예산을 충전하지 않는다. usedForcedMarchThisTurn을 유지하여 통상 복귀로 공격·요격 제한을 지우지 않는다. 이 상태 전이는 별도 태세 명령 계약으로 승인·검증해야 한다.

## 간선·도달 범위·예약

간선 기본비용 후보(u): 지상도로750, 지상보통1000, 지상험지1500, 지하노선1000, 명시된 출입/환승1250. edgeCostU=ceil(baseCostU×terrainPermille/1000)+surchargeU. 기본 지형은 이미 비용에 반영하므로 추가 보정은 명시된 승인 입력만 적용한다(시험 입력1000/0). 한 간선의 현실 길이는 미정이며 긴 구간의 분할/비용 override 정책은 승인 대기다.

지상 간선은 같은 지상층, 지하 간선은 같은 지하층이어야 한다. 층변경은 지도에 명시된 연결쌍만 허용한다. 통행권 부재·봉쇄·잘못된 층은 비용 무한대가 아닌 불법이다. 모든 경로의 인접성→층→통행권→봉쇄→태세→ZOC→총비용 순서로 검사하고 같은 검사 단계에서는 경로 인덱스가 먼저인 실패를 반환한다. 형식·중복 ID·범위 오류는 경로 검사 전에 거부한다. 실패 시 위치·예산·구성은 그대로이고 prefix를 자동 실행하지 않는다.

적 ZOC 진입은 정상 비용을 내고 이동을 끝낸다. 끝점만 허용하며 중간 ZOC 뒤로 나가는 명령은 전체 거부한다. 남은 회계 예산을 0으로 바꾸지 않고 stop=ZOC를 기록한다. 시작점이 ZOC면 보통 MOVE는 불가하고 별도 후퇴·공격·허가된 우회 계약이 필요하다. 도달 범위는 양의 비용 Dijkstra로 계산하되 ZOC 노드를 확장하지 않고 동률은 ASCII edgeId 배열 사전식 순서를 사용한다. 이 탐색은 연구 계산기 구현 범위 밖이다.

다턴 예약은 비구속 목적지·의도 경로다. 매 턴 지도·권한·적·짐을 다시 검사하여 그 턴의 명령을 별도 확정한다. 당일 예산을 넘는 명령을 자동 잘라 실행하지 않는다. 남은 예산은 이월하지 않으며 한 간선이 턴 예산을 넘으면 부분 간선 진행도도 저장하지 않는다.

## 가상 분대 검산

실제 인물 카드의 수치가 아니다. A는 지휘관1(Basic Move6, BL20, 짐15)과 병졸8(각 Move5, BL20, 짐30), B는 지휘관1(Move6, BL45, 짐40)과 병졸12(각 Move5, BL20, 짐50)다. 정상 건강·피로1000 기준 A 통상4000/강행군6000/매복2000u, B 통상3000/강행군4500/매복1500u다. B 병졸 한 명 부상750이면2250u, 피로750까지 겹치면1687u다.

가상 지도는 S0→S1 도로750, S1→S2 도로750, S2→U0 출입1250, U0→U1 지하1000, U1→U2 지하1000이다. A 통상은 U1까지3750을 내고250, B 통상은 U0까지2750을 내고250이 남는다. B가 U1까지 명령하면 전체 거부되어 S0·3000을 유지한다. A 강행군은 U2까지4750을 내고1250, B 강행군은 U1까지3750을 내고750이 남는다.

U1이 ZOC면 A 통상은 U1에 도착 후 남은250과 정지 표지를 유지하고 U2까지 강행군 명령은 전체 거부된다. 출입 간선 봉쇄도 전체 거부다. 비용4000인 경로에 예산4000이면 성공,3999면 실패한다. B 다턴 예약은 첫 턴 U0, 다음 턴 U2로 예상할 수 있으나 실제 상태를 매 턴 다시 확인한다.

## 결정론·검증 범위

오프라인 패킷은 임의정밀도 BigInt 곱셈과 정수 floor/ceil을 사용한다. 외부 JSON 숫자는 안전한 비음수 정수만 받고 결과 상한을 넘으면 거부하며 clamp하지 않는다. 안정 ID는 ASCII로 제한하고 객체 키를 정렬한 UTF-8 JSON에 SHA-256을 적용한다. 지도 노드/간선, 분대 구성원, 명령처럼 의미상 집합인 배열은 명시 ID로 정렬하고 경로 배열 순서는 보존한다. 중복 ID는 hash 전에 거부한다. 비용·계수·입력·결과를 hash에 넣고 제출시각·호스트순·번역은 넣지 않는다. 패킷 hash는 Core 재생 해시가 아니다.

동시 해결은 같은 턴 snapshot에서 검증해야 한다. 안정 저장순서를 게임 승자 우선권으로 사용하지 않는다. 유효경로 충돌·교차이동·정보/매복·동적봉쇄·전투 컨텍스트는 별도 승인 conflictRuleVersion이 필요하다. 누적비용/예산 유리수 시간모델은 검토 후보일 뿐 이 문서에서 채택하거나 구현하지 않는다. 재전송 영수증·명령 DAG·충돌 해결·태세 전이·승인 레코드 진위검증도 이번 단일 MOVE 계산기의 완료 주장에 포함하지 않는다.

검증 패킷 위치: 로컬 연구 폴더 research/2026-09-28/tripothon/movement의 movement.mjs와 movement.test.mjs. Node 내장 test/crypto만 사용한다. 두 분대, 도로/지하/출입, 강행군, ZOC, 봉쇄, 경계·1u부족, 잘못된 형식·중복ID·overflow, 거부 시 불변, 배열순서 불변 hash를 실행한다. GDD와 별개 연구 자료이며 GDD PR만으로 배포되지 않는다.
