## 1. 개요

- **장르**: 오거 배틀 계보의 실시간 부대 이동 + 자동 교전 SRPG. 개별 유닛을 턴마다 조작하는 FE/FFT와 달리, 플레이어는 교전 **이전**의 편성·조건 설정과 교전 **외부**의 부대 지휘를 담당한다 [S-11][추론].
- **핵심 특징(설계 철학)**:
  1. **개인 행동의 조건문화**: 개인 스킬 사용은 우선순위 있는 조건부 설정(Tactics)으로 사전에 프로그래밍되고 교전 중엔 자동 실행된다 [S-01][S-08][문서].
  2. **해방이 성장 동력**: 적 점령지를 해방하면 시설·모집·명성이 열린다 [S-11][문서].
  3. **3가지 플레이 표면**: 여행 필드(탐색/대화/채집) → 작전 스테이지(실시간 부대 운용) → 자동 교전(편성·작전의 검증) [S-11][문서/추론].
  4. **부대 조합이 곧 전술**: 클래스 상성·전후열·리더 효과·어시스트의 조합이 승패를 결정 [S-02][S-11][문서/추론].
- **서사 전제**: 주인공 알레인이 유년기 피난 후 왕위 계승 반지를 받고 코르니아 해방군을 일으켜 제노이라 황제 갈레리우스와 그래코린 대전투로 진행. 최종 결전 분기(스칼렛 구출 여부, 반지 강화 여부, 현자 협력 여부)에 따라 후일담 기록이 달라진다 [S-09][문서].

## 2. 코어 루프

1. **여행 필드 탐색**: 알레인으로 마을·요새·채집점 방문, 인물 대화, 퀘스트 수주 [S-11][문서]
2. **작전 스테이지**: 최대 10개 부대를 실시간(일시정지 가능)으로 이동·출격·점령 지휘. 제한시간 존재(평균 3~5분) [S-01][문서]
3. **부대 접촉 → 자동 교전**: 양측 부대가 근접하면 행동속도(Initiative) 순 자동 전투. 편성·장비·Tactics가 곧 입력이다 [S-01][S-08][문서]
4. **전과 수집**: 격파·해방으로 Valor(브레이브) 축적, 퀘스트·재건으로 명성·훈장·골드 획득 [S-04][S-11][문서]
5. **조직 재투자**: 훈장으로 부대 확장·승격·용병 고용 → 다음 스테이지 [S-03][S-04][S-05][문서]

결정 지점은 두 곳: **스테이지 중**(어디에 출격하고 누굴 지원할지)과 **스테이지 밖**(훈장을 어디에 쓸지) [추론].

## 3. 진행 구조

- **대륙 5개국 순차 해방**: 코르니아(시작국) → 드라켄홀드 → 엘하임 → 바스토리아스 → 알비온 [S-02][S-07][문서].
- **명성(Renown) 등급이 진행의 뼈대**: E→D→C→B→A→S. 퀘스트·마을 재건으로 누적.

| 등급 | 필요 누적치 | 해금 |
|---|---|---|
| E | 0 | 기본 |
| D | 120 | 부대 수 3개까지 확장, 요새 용병 고용 |
| C | 450 | 부대 수 4개, 부대 인원 4명 |
| B | 1750 | 클래스 승격 |
| A | 3000 | 부대 인원 5명 |
| S | 5000 | 퀘스트 "왕가의 영묘" 해금 |

전투 보상 골드·훈장·명성 배율도 등급마다 상승(E=100% 기준 → S=200%) [S-04][문서].

- **부대 수·인원 확장은 훈장 소비**: 시작 3부대×2인. 10부대×5인까지 확장 가능 [S-05][문서].
- **투기장(콜리세움)**: 드라켄홀드 바움라테의 아레나. 별도 랭크전으로 동료 영입·전리품 교환 [S-10][문서].

## 4. 경제 시스템

| 통화 | 획득 | 용도 |

| 골드(G) | 전투·퀘스트·판매 | 무기·소모품 구입 |
| 훈장(Honors) | 퀘스트·납품·전투 보상 | 부대 슬롯/인원 확장, 용병 고용, 클래스 승격 |
| 천조각(Divine Shards) | 채집·보물 | 교환소 |

[문서: S-03, S-04, S-05, S-10, S-12]

### 4.2 승격 비용 (훈장) [S-03][문서]
- 하급 → 상급: 대부분 25~35 (파이터→뱅가드 25, 나이트→그레이트 나이트 35)
- 고유 클래스: 로드→하이로드, 프리스테스→하이프리스테스, 크루세이더→발키리 50
- 승격 효과: 스탯 상승 + 신스틸 습득 + 기본 AP/PP **영구 증가**. 명성 B 이상 필요

### 4.3 물자 납품·재건
해방한 마을에 자재(목재·광석·약초·어획)를 납품해 시설을 복구하고 명성을 얻는다. 여관·대장간·상점이 재건되면 파티(친밀도)·장비·물품 접근이 넓어진다 [S-11][문서].

## 5. 캐릭터/파티 시스템

### 5.1 부대(Unit) 구조 [S-01][S-05][S-11][문서]
- 최대 **10부대 × 5인**. 편성판은 전열 3칸 + 후열 3칸. 시작은 3부대 × 2인
- **리더가 이동을 결정**: 이동 타입(기병/보병/비행), 스태미나, 리더 효과(Flight=지형 무시, Quick Rest, Barrier Breaker 등)는 리더 클래스 기준. 이동속도는 부대원 전원 기반 → 최강 개인이 최적 리더가 아님
- **클래스 계열**(약 25+ 상급 포함):
  - 코르니아/드라켄홀드: 파이터·솔저·하우스칼·소드파이터·호플라이트·글래디에이터·워리어·헌터·시프·나이트·래디언트/다크 나이트·클레릭·위저드·위치·샤먼·와이번/그리핀 나이트 + 각 상급
  - 엘하임: 엘븐 펜서·엘븐 아처(고유: 아우구르/시빌)
  - 바스토리아스: 웨어울프·웨어폭스·웨어베어·웨어아울(고유: 웨어라이온·스노우 레인저) — 공통 Nightwalk
  - 알비온: 페더소드·페더보우·페더스태프·페더실드(천사형, Flight) + 프리스테스
  - 고유: 로드(알레인), 크루세이더(버지니아), 팔라딘(요제프), 프린스(길버트), 드레드노트(아말리아) 등

### 5.2 클래스 상성의 대표 축 [S-02][문서]
- 파이터 > 헌터(방어) / 워리어·마법에 약
- 솔저 > 기병 / 호플라이트·파이터에 약
- 워리어 > 호플라이트·파이터 / 시프·글래디에이터에 약
- 헌터 > 비행 / 파이터·호플라이트에 약
- 시프: 회피 기반. 정밀명중(Truestrike) 계열에 취약
- 나이트 > 보병 / 비행·고회피에 약
- 래디언트 나이트 > 캐스터(마법 장벽) / 비행에 약
- 비행(그리핀·와이번) > 기병 / 활·캐스터에 약
- "보병>기병>비행>궁수/보병…"의 원환 상성 + 마법/물리 방어 축이 교차 [추론]

### 5.3 모집 경로 [S-11][문서]
- 서사 동료 / 퀘스트·전장 대화 조건부 영입(예: 힐다는 프림 대화 후) / 초반 처분의 지연 효과(가멜 석방 여부) / 투기장 최종 랭크 / 요새의 범용 용병 고용(훈장 지불)
- 공식 소개 60명 이상 고유 인물. 리뷰 64명, 한국 위키 최대 71명 — 집계 경계 달라 전수 확정 보류 [S-11][문서]

### 5.4 친밀도(Rapport)
여관 등에서 파티 숙박으로 친밀도 상승 → 대화·보상·편성 시너지 [S-11][문서].

## 6. 전투 시스템

### 6.1 교전 규칙 [S-01][S-08][S-11][문서]
- 부대 접촉 시 자동 교전. **행동속도(Initiative) 순**으로 행동
- **AP(행동 포인트)**: 능동 스킬 비용. **PP(패시브 포인트)**: 조건 반응 스킬 비용. AP 소진 또는 한쪽 전멸로 종료
- 시간 종료 시 잔여 HP **비율**로 승패 판정(절대치 합계가 아님)
- 스태미나: 교전 1회당 1 소비, 0이면 이동 불가. 요새·거점에서 휴식 회복 [S-11][문서/충돌 기록]

### 6.2 Tactics = 행동 프로그래밍 [S-08][문서]
- 능동 예: Lean Edge(명중 시 HP 25% 회복), Smash(대상 물리방어 −20%), Heal(HP 75% 미만 아군), Long Thrust(열 관통, 기병 +50 위력)
- 패시브 예: Heavy Cover(후열 우선 아군 방호), Arrow Cover(원거리 물리 무효), Pursuit(아군 공격 후 추격), Parting Blow(교전 종료 시 공격)
- 발동 조건·우선순위를 플레이어가 사전 편집. 장비가 스킬을 추가하므로 장비 교체=행동 규칙 교체
- 어시스트: 원거리·마법·회복·저항 리더 효과를 가진 인접 부대가 교전에 지원 사격/치유 [S-02][문서]

### 6.3 스테이지 운용 [S-01][문서]
- 출격은 통제 거점 반경 내 + Valor 비용. 웨이포인트로 우회 경로 지정, 다중 부대 그룹 지정 가능
- **Valor(브레이브) 스킬**: 부대 출격 자체와 필드형 스킬(버프·부활 등)에 소비. 격파·해방으로 축적
- 승리 조건은 스테이지마다 상이(점령, 방어, 호위 등) + 실시간 제한

## 7. 지도/세계 구조

- **여행 필드(월드맵)**: 대륙 페브리스 전체를 알레인이 직접 이동해 탐색. 낮/밤 실시간 시계 — 시간대별 인물 배치·시설 이용이 달라진다 [S-11][문서].
- **지점 유형** [S-06][S-07][문서]:
  - 마을/도시(해방 대상): 상점·여관·재건. 규모 구분(항만/마을/촌락/성벽도시/수도)
  - 요새(Fort): 부대 확장·용병 고용·해고·모의전·승격의 **조직 관리 허브**
  - 채집점: 광석·목재·약초·어획
- **작전 스테이지**: 필드 위 특정 지점에서 시작되는 개별 전장. 필드 1 + 스테이지 1의 **2종 논리 표면** + 교전 표현이 세 번째 [S-11][문서/추론].
- **해방의 연쇄**: 점령 해방 → 시설 사용 → 자재 납품/복구 → 수비병 지정 → 채집 회수. 수비병으로 지정해도 출격 가능. 해방 마을 재습격은 없다 [S-11][문서].

## 8. 외교/세력

- **세력 구도는 정적**: 플레이어 진영(코르니아 해방군) vs 제노이라 제국의 단순 대립. 동적 국가 AI 없음 [S-11][문서].
- **외교 대신 '해방 서사'**: 각국의 협력 여부는 퀘스트·전장 선택으로 결정되며, 최종 결전의 후일담 분기에 반영 [S-09][S-11][문서].
- 결전 전 기록이 지원 세력 축적에 따라 분기 — 지원이 결전 난이도·엔딩 변주로 이어진다 [S-09][문서].
- 명성 시스템(Renown)이 사실상 '세력 평판' 역할 [S-04][문서/추론].

## 9. 이벤트/내러티브

- **Fevrith Archive**: 스토리 진행에 따라 축적되는 세계관 기록 장치. 결전 전후 분기마다 서로 다른 기록 생성 [S-09][문서].
- **조건부 영입이 서사 장치**: 전장 대화 영입, 초반 포로 처분 선택이 수십 시간 뒤 합류에 영향 — 선택의 지연 효과 [S-11][문서].
- **낮/밤 순환**: 필드 시간대에 따른 인물 배치 변화. 바스토리아스 Nightwalk 클래스는 밤에 기동력 상승 [S-02][S-11][문서].
- **엔딩 분기**: 최종 결전에서 갈레리우스 격파 후 알레인의 처분 선택에 따라 결말 갈림 [S-09][문서].

## 10. 난이도/압박

- **1차 압박 = 실시간 제한시간**: 평균 스테이지 3~5분. 정지 가능하지만 시계 자체가 자원 [S-01][문서].
- **2차 압박 = 스태미나 경제**: 교전마다 소모, 0이면 이동 불가. 다수 전선 운용 시 교대·휴식 설계 강요 [S-11][문서].
- **3차 압박 = 본거지 방어/다중 경로**: 거점 방어와 여러 이동 경로 선택이 동시 지휘 부담 [S-11][문서].
- **실패의 부담**: 개인 영구사망은 기본 아님. 교전 패배는 부대 후퇴로 처리되는 유연한 재시도 구조 [S-11][추론]. 난이도 모드 세부 수치는 [미확인].
