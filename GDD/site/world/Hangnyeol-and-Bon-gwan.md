# 본관과 항렬

성씨·본관·분파·가족관계·세수는 서로 다른 정보다. 같은 성을 쓴다는 이유로 같은 집안이나 같은 항렬을 부여하지 않는다. 항렬을 사용하지 않는 가족도 있으며, 특정 국가 출신이라는 사실만으로 사용 여부를 결정하지 않는다.

이 문서는 목표 작명 계약과 현재 생성기의 한계를 구분한다. 이번 문서 정정으로 생성기나 이름 풀 JSON이 바뀌지는 않는다.

## 문화권별로 구분할 것

| 전통 | 무엇을 표시하는가 | 생성 시 주의점 |
|---|---|---|
| 한국의 본관 | 성씨와 함께 조상의 출자지·계통을 구분 | 현재 주소나 소속 국가를 본관으로 쓰지 않음. 같은 성의 여러 본관·분파를 보존 |
| 한국의 항렬자 | 문중·분파가 정한 혈연 세대와 글자 | 나이대가 세수는 아님. 한글 발음뿐 아니라 한자와 자리, 대체자를 확인 |
| 중국의 자배 | 가계별 세대자 순서 또는 항렬시 | 한국의 본관 자료를 그대로 적용하지 않음. 적용 가계·세대·원문 글자를 확인 |
| 일본의 통자 | 가계에서 여러 세대에 걸쳐 물려 쓰는 글자 | 같은 세대만 공유하는 항렬과 동일한 규칙이 아님 |
| 일본의 편휘 | 윗사람의 이름 한 글자를 받는 관계 | 혈연 세대가 아니라 수여 관계를 기록. 모든 현대 일본인에게 강제하지 않음 |

일본 통자와 한국 항렬을 “같은 논리”라고 쓴 기존 설명은 철회한다. 여성의 사용 여부도 일괄로 정하지 않으며, 가족별 관습과 본인 이름을 우선한다. 다문화·혼합 가정은 복수의 작명 전통을 가질 수 있다.

## 출처 (열람 2026-09-12)

- [한국민족문화대백과사전: 본관](https://encykorea.aks.ac.kr/Article/E0023741): 성의 출자지 또는 시조 거주지에 관한 제도. 현재 거주지와의 차이를 설명한다.
- [항렬](https://ko.wikipedia.org/wiki/항렬): 문중·분파의 항렬자, 한자, 자리와 대체자에 관한 2차 개요. 특정 실존 문중의 실제 항렬표는 해당 문중 자료로 추가 확인해야 한다.
- [Generation name](https://en.wikipedia.org/wiki/Generation_name): 중국·한국·베트남의 세대자 개요. 모든 가족에 적용된다는 근거로 사용하지 않는다.
- [코토뱅크: 통자](https://kotobank.jp/word/通字-2066850) · [편휘](https://kotobank.jp/word/偏諱-626131): 세대 간 전승 글자와 수여된 글자를 구분하는 사전 자료.

## 현재 생성기의 한계

`tools/cast/generate_nemotron_roster.py`는 60세 이상·40~59세·25~39세·24세 이하를 네 칸에 대응시키고 이름 앞글자를 바꾼다. 성씨 하나에 본관 하나만 연결하며 가족관계나 분파, 한자, 실제 세수를 읽지 않는다. `keepRate`도 실측 통계가 아닌 임의 설정값이다.

따라서 현재 출력은 항렬처럼 보이는 이름 조합 시험이다. 형제·사촌이 같은 혈연 세대라는 검증이나 한국·중국·일본 작명 체계를 구현한 결과로 보고하지 않는다. “김석훈” 같은 예시도 실존 김해김씨 항렬의 증거가 아니다.

## 목표 생성 순서

1. 인물의 작명 전통과 성·이름 표기를 읽는다. 모르면 미확인으로 남기고 기존 이름을 유지한다.
2. 한국 계통이면 성·본관·분파를, 중국 계통이면 가계와 자배표를, 일본 계통이면 가계 통자 또는 수여 관계를 각각 선택한다.
3. 혈연 연결로 세수를 확인한다. 생년·연령·국가 ID·직업에서 세수를 계산하지 않는다.
4. 사용 여부, 원문 글자, 읽는 법, 이름 내 위치, 대체자와 예외를 가계 규칙에서 읽는다. 정해진 글자가 없으면 임의로 덮어쓰지 않는다.
5. 성씨 풀과 남성·여성 또는 개인이 선택한 이름 풀을 별도로 사용한다. 미리 완성된 이름의 한 음절을 무조건 교체하기보다 조합 후 표기·발음·동명이인 충돌을 검토한다.
6. 본관·가계 규칙 출처와 인물별 적용 사유, 미사용·미확인 사유를 함께 기록한다. 기존 캐스트 이름은 이 절차 때문에 자동 변경하지 않는다.

이 절차는 후속 구현의 수용 조건이다. 현재 후보 JSON에는 소급 적용되지 않았다.
