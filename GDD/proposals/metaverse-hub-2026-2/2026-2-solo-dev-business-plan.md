## 1. 개발 아이템 소개

**서울:전국**은 한 세계의 캐릭터 자산 위에서 여러 사업으로 뻗는 게이미피케이션 캐릭터 IP 플랫폼이다.

- **첫 제품은 게임.** 붕괴 110년 뒤 후세 서울. 지하철 노선·역으로 재편된 도시에서 무명 인물과 파티를 이끌며 4X(탐사·확장·개발·정복)를 벌이고 인물 성장·관계·생업(RPG)을 쌓는 PC용 4X+RPG. 전투는 전투 전 진형 편집과 전투 중 카드 타이밍으로 개입하는 실시간 전투.
- **캐릭터 자산이 플랫폼의 몸통.** 16개 역 사회 국가, 이름 있는 인물 1,001명(가치관·욕망·관계·출처 원장), 적대 집단 27, 서사 배치 47, 몬스터 배치 42. 게임을 넘어 캐릭터 챗·콘텐츠 전개의 원료.
- **에셋은 AI로 찍어낸다.** 초상 생성 툴·3D 생성·로스터 생성기 운영 중. 개발 과정은 X에 공개. [확인 필요: 링크]

게임의 다섯 특징: 실패가 세계에 남는다 / 인물이 정치의 단위다 / 노선이 영토이자 물류다 / 전투는 전략의 결과다 / 모든 상태 변화가 사건 원장으로 추적된다.

## 2. AI 생성 에셋 파이프라인 — 지원의 핵심 (기술수행능력)

**초상 생성 툴(직접 제작, 확장 중)** — 레이어 분리 합성 구조. 22슬롯 오서링 게이트웨이와 데모까지 완성(기여 브랜치 공개), 반려 후보는 게이트에서 잘리는 fail-closed. 이름 풀 분리·시드 고정 랜덤 생성기로 1,001명 로스터 생성·검증 경험.

- 3D·2D 생성: TRELLIS로 역사 소품 6종 출처 검증(BOM) 통과·런타임 승격, 3역할 캐릭터 동일 경로, UI 키트 9종 후보 대기
- 출처·권리 게이트: 생성물마다 출처·도구·변환 이력 BOM 통과만 런타임 승격(fail-closed)
- X 공개: 툴 개발 과정 포스팅 [확인 필요: 링크]

엔진·아키텍처: Unity 6000.7.0a5 + URP 17.7.0, Input System, TMP, VContainer DI / 엔진 비의존 Core·Foundation 2층 / 결정론 계약(같은 시드+명령 기록=같은 상태·원장 해시) / 30Hz 실시간 진형·카드 전투 Core(분대 명령·사기·항복·틱 스탬프).

검증 인프라: batchmode EditMode/PlayMode(동일 시드 재현·중복 정산 거부) / Node 도구셋(위키 드리프트·아트 BOM·지역 총람 전수 재대조 427동·원장 1,011,022건) / 기증 3D·SFX·VFX·Spine 통합 경험.

## 3. 확보된 게임 로직과 데이터 (개발완성도)

**대전략 축 — 서울 전역 데이터화.** 2026년 7월 행정구역 기준 25구 427동 전수, 지하철 334역·간선 435구간 이동 그래프, 동별 주민·생업·위험·행동 후보 원장 1,011,022건(전수 재대조 도구로 검증). 영토·노선·물류 관리가 이 데이터 위에서 돈다. 열람용 지역 총람 아틀라스 별도 구축.

확보 규칙:
- 캠페인 루프 6단계(교섭·우회 포함) — Unity POC 세 역 노선 구현, batchmode 재현성 검증 통과
- 실시간 진형·카드 전투 Core(30Hz) — 분대 명령·집계 사상자 표현만 잔여
- 결정론·세이브 계약
- 캐스트 원장 — 16국 1,001명, 관계 수 계약 검증 도구
- 웹 코어 루프 POC — 거점→목적지→조우→진형→실시간 전투→정산→귀환 브라우저 조작(공개 배포)

진행 중 설계(별도 머신 Codex 협업): 오너 캐릭터(거대 상단 수장) 딥인터뷰 기반 설계, 정보 판단 시스템(경험·소문·증언→보증 장부류 판단 축) 설계. 창작 지명→실존 역명 정규화는 main 반영 완료.
