# 영웅 분대와 동시 전략 턴

이 문서는 목표 캠페인의 전략 분대·영웅 지휘·최대 10인 동시 턴 계약이다. 현재 Unity POC가 이 규칙을 이미 구현했다는 뜻은 아니다.

## 결정 상태

| 구분 | 내용 |
|---|---|
| 사용자 확정 | 1,004명은 영웅 인물, 직업별 클래스와 특성, 전투·지원·치유·현실 원인의 마법 체감, 외교·암살·방해 공작·정보 활동 |
| 사용자 확정 | 영웅과 병졸은 별도이며 병졸 분대 최대 20명, 이동 분대에 영웅 지휘관 필요, 지휘관 상실 시 임시 병졸 분대장 선출 |
| 사용자 확정 | 플레이어 본체 위치는 하나, 소유한 모든 영웅 분대를 원격 직접 지휘, 각 분대는 독립 원정 |
| 사용자 확정 | Total War식 전략 이동, 명령 원장, 강행군의 공격·요격 금지, 결정론 매복, 통제권 진입 시 정지·이탈 제한 |
| 사용자 확정 | 최대 10인 동시 계획·일괄 해결, 미응답 AI 대행, 충돌은 이동력·태세·지형·정보로 해결 |
| 설계 제안 | 아래 여섯 클래스 이름과 분류 규칙, 임시 분대장의 세부 권한, 이동력·태세·통제권의 수치, 턴 제한 시간 |

설계 제안은 구현·밸런스 데이터로 고정하기 전에 사용자 확인과 데이터 사전 등록이 필요하다. 위키의 인물 설명에 제안 클래스를 자동 배정하지 않는다.

| 한국어 | 기계 ID | 뜻 |
|---|---|---|
| 영웅 | `Hero` | 인물 원장에 등록된 이름 있는 인물. 병졸과 별도 행위자다 |
| 병졸 분대 | `SoldierSquad` | 병졸 최대 20명. 영웅은 이 수에 들어가지 않는다 |

| 독립 요원 | `IndependentAgent` | 병졸을 데리지 않고 외교·암살·방해 공작·정보 활동을 수행하는 영웅 |
| 임시 분대장 | `TemporaryLeader` | 정식 영웅 지휘관을 잃은 분대가 병졸 중에서 선출한 제한 지휘자 |

## 영웅 클래스 제안

1,004명은 모두 영웅 카탈로그에 들어간다. 클래스는 Total War: Warhammer의 역할 분리를 참고하지만 명칭·능력·수치·아이콘을 그대로 가져오지 않는다. 아래 여섯 이름은 데이터 구조를 검토하기 위한 제안이다. 영웅마다 주 전투 클래스 하나를 둘지, 역할 태그만 조합할지도 최종 데이터 설계에서 확인한다.

| 클래스 | 주 역할 | 효과가 보이는 방식 |
|---|---|---|
| 전열수호 | 통로 유지, 엄호, 퇴로 방어 | 대열의 사기와 장비 방호를 유지한다 |
| 돌파선도 | 막힌 접근로 개방, 장비·시설 돌파 | 정비·도구·피지컬 에이아이 장비로 길을 연다 |
| 전장조율 | 진형 정돈, 표적 정보, 보급 조정 | 호명·기록·선동·정보로 같은 명령의 완성도를 높인다 |
| 회복지원 | 응급 처치, 장비 수리, 오염·피로 안정 | 의료·장비·사기 회복을 다룬다. 사망자를 되살리지 않는다 |
| 경로공작 | 정찰, 경로 통제, 은밀 공작 | 길·위험·시설 정보를 드러내고 조우 조건을 바꾼다 |
| 원정중추 | 전문성이 아직 잠기지 않은 영웅 | 원정의 연속성과 기본 사기를 지키며 추후 검토 대상으로 남는다 |

효과는 마법처럼 체감될 수 있으나 원인은 사기, 의술, 선동, 장비, 정보와 피지컬 에이아이 기술이다. 초자연 마법을 기본 원인으로 기록하지 않는다. 전투에서 영웅 개인을 직접 조작하지 않으며, 영웅 효과는 분대에 수락된 이동·공격·방향 전환·진형 변경·정지·철수 명령을 통해서만 드러난다.

## 캠페인 역할

| 역할 | 가능한 결과 | 반드시 남기는 기록 |
|---|---|---|
| 외교 | 통행 동의, 중재, 관계·정통성 변화 | 상대, 조건, 증인, 수락·거절 |
| 암살 | 목표 인물의 제거·부상·포획·폭로 시도 | 목표 상태, 발각, 보복·법적 결과 |
| 방해 공작 | 노선·시설·보급·피지컬 에이아이 인터페이스의 방해 또는 확보 | 자산 상태, 증거, 수리·대응 경로 |
| 정보 활동 | 정찰, 지도 작성, 사실 확인, 허위 정보 반박 | 범위, 최신성, 출처 신뢰도, 공개 결과 |

강한 전투 영웅이 자동으로 외교·암살·방해 공작·정보 활동에 능한 것은 아니다. 캠페인 역할은 전투 클래스와 별도로 배정한다.

## 분대 편성

- 이동 가능한 전략 분대에는 정식 영웅 지휘관이 한 명 필요하다.
- 병졸 분대는 최대 20명이다. 영웅 지휘관과 배속 영웅은 병졸 인원에 포함하지 않는다.
- 영웅 한 명은 한 시점에 하나의 상태만 가진다: 지휘관, 배속, 독립 요원, 사용 불가.
- 플레이어 본체 영웅은 정확히 한 분대에만 속한다. 플레이어 위치는 그 분대 위치에서 계산하며 별도 위치 값을 두지 않는다.
- 플레이어는 본체 위치와 무관하게 자신이 소유한 모든 영웅 분대의 전략 명령을 원격으로 직접 확정한다. 이 권한으로 본체가 여러 위치에 동시에 생기지는 않는다.
- 분리·합류는 같은 층과 같은 노드에서, 전투·요격이 열리지 않은 상태에서만 가능하다. 합류 뒤 병졸 20명 상한을 넘으면 거부한다.
- 지휘관을 잃으면 병졸 중 한 명을 임시 분대장으로 선출한다. 임시 분대장의 세부 권한은 미정이다. 정식 영웅 지휘관과 같은 클래스·캠페인 역할을 자동으로 받지 않는다는 점만 잠근다.

## Total War식 전략 이동

각 전략 분대는 턴마다 유한한 이동력을 가진다. 수치는 이 문서에서 잠그지 않는다. 지상 영토와 지하철 노선은 별도 이동 층이며, 층 전환은 정해진 환승·출입 노드에서 이동력을 사용한다.

| 태세 | 이동 | 전투·조우 |
|---|---|---|
| 통상 행군 | 기본 이동력 | 공격·요격·증원 가능 |
| 강행군 | 이동 범위 증가 | 공격·요격 개시 불가. 피격 시 준비도 불이익 |
| 매복 | 이동을 줄이고 은폐 | 지형·정찰·정보 상태를 비교한 결정론 규칙으로 탐지·요격 |
| 주둔(제안) | 거점 안으로 이동을 끝냄 | 회복·보급·모집 가능 여부는 거점 계약을 따른다 |
| 야영(제안) | 이동을 끝내고 현장 정비 | 거점보다 제한된 회복·정비. 공격 개시 불가 |

적 분대나 거점의 통제권에 진입하면 이동이 끝난다. 다음 명령은 후퇴·공격·허가된 우회 가운데 하나다. 이동 전에는 이동력, 태세, 지형, 통행권, 봉쇄, 층, 통제권을 전부 검사한다. 불법 경로는 중간까지 자동 이동하지 않고 명령 전체를 거부한다.

공격·요격·증원·분리·합류·태세 변경은 서로 다른 명령이다. 전투가 열리면 참가자·지휘관·태세·층·증원 후보를 확정해 닫힌 전투 컨텍스트로 넘긴다. 전투 결과는 원장에 한 번만 반영한다.

## 최대 10인 동시 턴

온라인 세션은 호스트를 포함해 최대 10명의 플레이어가 참가하도록 설계한다. 숫자 10은 동시 참여 플레이어 상한이며 영웅 수·분대 수·팩션 수 상한이 아니다. 이번 문서 작업은 백엔드의 현재 제한값을 변경하지 않는다.

1. 계획 단계에서 모든 플레이어는 소유 분대의 명령을 입력하고 확정한다.
2. 비플레이어 팩션은 시스템 AI가 같은 명령 계약으로 계획한다. AI 전용 순간 이동·무료 이동력·숨은 명령은 없다.
3. 제한 시간 안에 응답하지 않은 플레이어의 분대는 시스템 AI가 대행한다. 대행 여부와 생성한 명령을 원장에 남긴다.
4. 모든 명령이 확정되면 일괄 해결한다. 제출 시각이나 호스트 순서를 우선순위로 쓰지 않는다.
5. 같은 구간·거점에서 충돌하면 남은 이동력, 태세, 지형, 통제권, 정찰·매복·정보 상태를 비교한다. 같은 입력이면 같은 결과가 난다.
6. 플레이어 연결이 끊겨도 턴 원장은 유지한다. 재접속한 플레이어는 수락된 명령과 해결 영수증을 다시 받고 다음 계획 단계부터 직접 입력한다.

## 명령 원장

이동, 정지, 경로 변경, 태세, 분리, 합류, 지휘관 교체와 AI 대행은 모두 명령 ID·턴·행위자·대상 분대·원인·규칙 판본·전후 검사값을 갖는다. 같은 시작 상태와 같은 명령 원장을 재생하면 같은 분대 위치·편성·조우·전투 참가자가 나와야 한다.

백엔드 코디네이터는 명령 내용을 해석하지 않는다. 참가자 인증, 최대 인원, 세션·방 연결과 JSON 전달만 맡는다. 호스트 게임 클라이언트가 규칙 판본에 따라 명령을 검증·정렬·해결하고 영수증을 모든 참가자에게 전달한다.

## UI 계약

- 전략맵에는 소유 분대 목록, 영웅 지휘관, 병졸 수, 태세, 이동력 상태, 현재 층과 위치를 표시한다.
- 분대 선택 뒤 이동·태세·분리·합류·지휘관 교체를 각각 독립 행동으로 연다.
- 원격 지휘 중에도 플레이어 본체가 있는 분대를 항상 표시한다.
- 임시 분대장은 영웅 초상·영웅 클래스와 같은 표식을 쓰지 않는다.
- 계획 단계에는 미확정·확정·AI 대행 상태를 표시하고, 해결 단계에는 명령 입력을 막고 원장 영수증을 순서대로 보여 준다.
