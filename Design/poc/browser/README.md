# 동결된 브라우저 UI 목업

이 폴더는 [UI가 코드로 들어오는 길](../../../Wikis/game-logic/Ui-Implementation-Pipeline.md) 6단계의 동결본입니다.
원본은 승인된 HTML 진형·카드 POC이며, 유니티 이식의 시각·입력 기준입니다.

- 지휘관 카드: `avatar-preview/`
- 진형 편집: `formation-editor/`
- 실시간 전투 미리보기: `battle-preview/`
- 회수 캠페인: `recovered-campaign/`

필그리미지 원본 아틀라스는 여기 없습니다. 로컬 검토 URL만 `avatar-preview/SOURCE-PROVENANCE.md`에 적혀 있습니다.
바이트 해시는 `SHA256SUMS`입니다. 목업을 고치면 해시를 다시 만들고 유니티 이식을 다시 대조합니다.
