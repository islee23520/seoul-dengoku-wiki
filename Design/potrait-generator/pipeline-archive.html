Q05 재질 구분무광 피부·모발 광·직물·스트랩이 뚜렷 구분플라스틱 피부, 균일 매끄러운 천

리뷰 절차 (5단계)

R1
동결
참조·후보·기여 레이어·레시피/라이브러리 SHA 기록, 캐릭터 ID·성별·변형 ID·z순서
R2
네이티브 비교
동일 픽셀 스케일, 50%+UI 크기 전신, 얼굴/모발/깃 크롭 100%. 뷰어 자동축소 미인정
R3
분리·은면 검사
투명 파트를 검·회·백 배경, 오클루더 토글로 은면 노출
R4
행별 기록
Q01–Q10마다 PASS/FAIL/NOT VERIFIED + 크롭 경로 + 관찰 + 리뷰어·시간
R5
수치 분리 기록
수치 게이트 결과를 예술 판정과 별도 보관 — 상쇄 금지

리드가 직접 이미지를 열어 봐야 한다 — 워커 추천·연락시트 존재·테스트 통과·프로바이더명은 시각 PASS가 아니다. 미증거 = NOT VERIFIED.

필수 체크포인트 GQ1–GQ4

체크포인트시점요건

GQ3 교차 조합조합 단계실제 합성·4종 교차·저/고 깃·적대 조합. 카르테시안 전수 주장 금지
GQ4 캐릭터 인도납품 전실제 Design 도구(데스크톱/모바일) 선택·재현·PNG 검사·ID 바인딩. UI 테스트만으로 불가

③ 수정 루프REPAIR

"틀리면 어떻게 고치는가" — 마스크된 편집·프로바이더 재생성·강제 복원·VERDICT 판정의 닫힌 사이클.

01
결함 발견
VERDICT/진단 크롭에서 결함 정의 (예: envelope 초과, seam 갭)
02
HANDOFF 기술
결함 정의·바인딩 envelope·금지사항·품질 바닥 명시
03
입력 동결
input-receipt.json — 소스 SHA 기록
04
마스크 가이드
edit-alpha0 / edit-white / edit-reference — 편집 가능 영역만 개방
05
프로바이더 생성
provider.png (gpt-image-2 등, 호출 수·영수증 기록)
06
등록·배치
placement 좌표 지정, 리샘플은 명시된 경우만
07
enforce 강제 복원
지정 마스크 외 픽셀을 원본으로 복원 — 보호 픽셀 수치 검증
08
측정·VERDICT
measurement-receipt + 체크포인트별 PASS/FAIL 판정
↻ FAIL → 다음 라운드(02로 복귀) 또는 통합 보류(WITHHELD). 게이트 통과 전까지 frozen basis 대체 금지, 실패 결과의 추출·승격 금지.

무결성 원칙

바이트 복사 복원

프로덕션 판 교체는 무리샘플링 없는 바이트 복사 + library.json SHA 재바인딩 (예: 커밋 e9c43d77 outfit-off 복원).

알파 무결성

알파 byte-identical 보존, alpha=0 하 RGB 제로. 결정론적 시도가 색 끌림·고스트를 남기면 기각하고 클린스킨 재페인트로 대체.

이미지 절단 금지

슬롯 조합은 이미지를 자르지 않는다 — 통합 per-layer clip kernel + slot-relations 마스크로 교체 (커밋 2ba96bb3).
